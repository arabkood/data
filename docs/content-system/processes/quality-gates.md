# Quality Gates

Every challenge passes through 3 gates:

## Gate 1: Technical Correctness (You)

- [ ] Tests pass with solution
- [ ] Tests fail with starter code
- [ ] No bugs in test logic
- [ ] Solution is optimal/reasonable
- [ ] Arabic instructions are clear

Fail → Back to generation with notes

## Gate 2: Beginner Clarity (Tester)

Tester attempts challenge, notes:

- Time to understand problem
- Got stuck? Where?
- Tests made sense?
- Satisfaction after solving

Pass threshold: Completed in <30 min without external help

Fail → Revise instructions or add hint

## Gate 3: Staging Test (Live users)

Deploy to users, track:

- Completion rate
- Average time
- Submission attempts

Pass threshold: >60% completion rate

Fail → Adjust difficulty or rework
