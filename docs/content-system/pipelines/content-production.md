# Content Production Pipeline

## I. Initial

### 1. Planning (1 week)

1. Start with a track template, and fill relevant data
2. Research competitor websites and their content
3. Create track roadmap including all modules and items

## II. Recurring: 10 challenges/day

### 1. Batch Generation

1. Pick next 10 items from roadmap
2. Run item generator for each
3. Output: 10 draft item in correct format
4. Publish to DEV stage

### 2. Review & Refinement

Process each challenge through quality gates:

- Gate 1: Technical review (you)
- Gate 2: User test (by someone non-technical who matches user persona)

## III. Delivery & Refinement

### 1. Publish

1. Publish to production with proper tracking
2. Inform users through marketing channels

### 2. Refinement

1. Track performance in posthog
2. Based on performance, refine the items
