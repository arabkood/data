Imagine the computer is a super-fast assistant. To give it instructions, we need to speak its language.

Our first task is to make the computer display a message for us. Think of it as sending a text to the computer's brain. 🧠

We use a special command for this: `console.log()`.

Look at how it works. This command tells the computer to **display the text** inside the parentheses.

```javascript
// This line will print a greeting to the screen.
console.log("Ahlan, world!");
```

**Output:**
```
Ahlan, world!
```

See that? You've just read your first line of code. Now, let's try writing one.
