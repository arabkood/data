That was a great first step! Let's quickly look at the pieces of that command.

`console.log("some text");`

- `console`: This is the destination, like a developer's private message window.

- `.log()`: This is the specific **action we want to perform** (to log, or write, a message).

- `"some text"`: Any text inside quotation marks is called a `string`. The quotes are essential!

- `;`: This is like the period at the end of a sentence. It tells the computer the command is finished.
