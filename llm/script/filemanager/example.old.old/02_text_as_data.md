The first and most common type of data is for text. We've already seen it!

Any text wrapped in quotes, like `"Hello, Omar"` or `'Riyadh'`, is called a `string`.

### See It

```javascript
// This is a string
console.log("Fatima");

// This is also a string
console.log('مرحباً بالعالم');
```
