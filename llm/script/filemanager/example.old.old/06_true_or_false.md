Sometimes, you only need a simple "yes" or "no" answer. In programming, we have a special data type for this: the `boolean`.

A `boolean` can only have two values: `true` or `false`. Notice they are not in quotes.

### See It

```javascript
// Is the user an admin? Yes.
console.log(true);

// Is the item in stock? No.
console.log(false);
```
