Great work! We've just discovered the three core `data types`:

1.  `string`: For text, like filenames and cities. `"Amman"`
2.  `number`: For numerical values, like age or temperature. `30`
3.  `boolean`: For true or false states. `true`

These are the fundamental atoms of almost every program you will write or see.

### Do It Yourself
