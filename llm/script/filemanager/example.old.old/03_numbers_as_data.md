What about things we can count, like age or price? For that, we use the `number` data type.

Numbers are simple: **you just write them without any quotes**. This is a key difference from strings.

### See It

```javascript
// This is a number
console.log(2024);

// We can also log the output of calculations
console.log(25 + 5);
```

```text
// Output
30
```
