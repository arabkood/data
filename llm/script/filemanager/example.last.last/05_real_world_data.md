Look at how these data types represent a real person's information. Let's create a mini-profile for a user named Omar.

He is 28 years old and has an active subscription to our platform.

```javascript
// User's name (text)
console.log("Omar");

// User's age (a number)
console.log(28);

// Has an active subscription? (yes/no)
console.log(true);
```

**Output:**
```
Omar
28
true
```

See how each piece of information uses the right `data type`? This is the foundation of building useful programs.
