First, we have `string` data, which is just text. **Anything inside quotes is a string.**

```javascript
// A name is a string
console.log("Layla");

// A city is also a string
console.log("الرياض");
```

Next, we have `number` data for any kind of number, like age or temperature. **Numbers do not use quotes.**

```javascript
// An age is a number
console.log(30);
```

Finally, there's `boolean` data. It can only be one of two values: `true` or `false`. It's perfect for yes-or-no questions.

```javascript
// Is the user an admin?
console.log(true);
```
