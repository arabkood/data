# Lesson 2: Creating Memory Boxes

Printing the same message every time is okay, but what if we want our program to remember things? For that, we use **variables**.

Think of a variable as a labeled box where you can store information.

To create a variable (a box), we use the `let` keyword, give it a name, and use `=` to put something inside it.

```javascript
// This creates a box named 'playerName' and puts the text 'Echo' inside.
let playerName = "Echo";

// This creates a box named 'score' and puts the number 100 inside.
let score = 100;
```

Now, instead of just printing a message, we can store our developer identity in variables!
