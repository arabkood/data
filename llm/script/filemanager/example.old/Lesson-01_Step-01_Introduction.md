# Lesson 1: Your First Words

Welcome to the JavaScript Command Center! 🚀

Every great programmer needs a way to see the output of their code. Think of it as a direct line of communication with the computer. In JavaScript, our most trusted tool for this is `console.log()`.

It literally **logs** a message to the **console**.

Let's look at an example. This code tells the console to display the message "Hello, Coder!":

```javascript
console.log("Hello, Coder!");
```

Notice two things:
1.  The message is wrapped in double quotes `""` to tell JavaScript it's a piece of text (we call this a **string**).
2.  The line ends with a semicolon `;`. This is like the period at the end of a sentence.

In the next step, you'll get to run this command yourself!
