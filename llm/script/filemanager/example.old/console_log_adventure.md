# 🌌 Console Odyssey: Your First Space Transmission

You're the communications officer aboard Starship JavaScript. Your mission: **send messages back to Earth** using the `console.log` transmitter!

```javascript
// EMERGENCY TRANSMISSION PROTOCOL
console.log("Mayday! Engine failure!");
```

🔥 **Hot Tip**: In space, everything is case-sensitive! `Console.Log` won't work - it must be `console.log` exactly.
