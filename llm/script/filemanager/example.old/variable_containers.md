# 🧪 Nanotech Containers: Storing Cosmic Data

Zero-G Fact: **Variables** are molecular containers that hold information in memory.

```javascript
// Create container labeled 'fuelLevel'
let fuelLevel = 87.3; // Percentage

// Create permanent container (can't change)
const MAX_FUEL = 100;
```

🛸 **Container Types**:
- `let`: Flexible container (values can change)
- `const`: Titanium-sealed container (permanent value)

⚠️ **Quantum Rules**:
1. Container names CAN'T have spaces (`fuel Level` ❌)
2. Start with letters only (`2fuel` ❌)
3. Case matters (`FuelLevel` ≠ `fuelLevel`)
