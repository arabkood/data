# The Grand Finale: Variables in the Console

This is where it all comes together. We can tell `console.log()` to print the *contents* of a variable.

Watch this!

```javascript
let greeting = "Welcome to my world!";

// Notice there are NO quotes around 'greeting' here!
console.log(greeting);
```

If we put quotes around it (`console.log("greeting");`), it would just print the word "greeting". Without quotes, JavaScript knows to **look inside the variable box** and print what it finds.
