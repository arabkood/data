# مهمة جديدة: تحويل قائمة أسعار

تخيل أن لديك قائمة أسعار وتريد إضافة ضريبة القيمة المضافة (15%) لكل سعر. الطريقة التقليدية باستخدام حلقة `:for` قد تكون طويلة ومملة.

```javascript
const prices = [100, 200, 300];
const pricesWithTax = [];

for (let i = 0; i < prices.length; i++) {
  pricesWithTax.push(prices[i] * 1.15);
}
// pricesWithTax will be [115, 230, 345]
```

هل هناك طريقة أذكى وأكثر أناقة للقيام بذلك في سطر واحد؟ هيا نكتشف!
