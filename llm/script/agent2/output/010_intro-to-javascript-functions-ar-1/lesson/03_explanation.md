# ما هي الدالة؟

الدالة (`:function`) هي كتلة من الكود مصممة لأداء مهمة محددة. فكر فيها كأنها وصفة طبخ:

1.  **اسم الوصفة (اسم الدالة)**: `greet`
2.  **المكونات (المعاملات - `:parameters`)**: `(name)`
3.  **خطوات التحضير (جسم الدالة)**: `{ console.log("مرحباً يا " + name + "!"); }`

```javascript
// 1. تعريف الدالة
function greet(name) {
  console.log("مرحباً يا " + name + "!");
}

// 2. استدعاء الدالة
greet("أحمد");
greet("سارة");
```

عندما `نستدعي` الدالة، نحن ننفذ الكود الموجود بداخلها. القيمة التي نمررها (`"أحمد"`) تسمى `:argument`.
