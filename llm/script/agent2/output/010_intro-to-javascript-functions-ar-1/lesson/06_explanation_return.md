# إعادة القيم من الدوال

في بعض الأحيان، لا نريد فقط أن تنفذ الـ`:function` شيئًا ما، بل نريدها أن تعطينا نتيجة يمكننا استخدامها لاحقًا. هنا يأتي دور الكلمة المفتاحية `:return`.

عندما تصل `:function` إلى عبارة `:return`، فإنها تتوقف عن التنفيذ وتعيد القيمة المحددة.

```javascript
// هذه الدالة تحسب المجموع وتعيده
function add(num1, num2) {
  return num1 + num2;
}

// يمكننا تخزين النتيجة في متغير
let sumResult = add(5, 3); // sumResult الآن تساوي 8

console.log(sumResult);
```

> بإتقانك لعبارة `:return`، أصبحت قادراً على بناء دوال قوية تنتج بيانات يمكنك معالجتها في أجزاء أخرى من برنامجك!
