## المتغيرات و console.log: أساسيات التخزين والعرض

أحسنت! لقد تفاعلت بالفعل مع أهم مفهومين للمبتدئين.

### 1. المتغيرات (Variables)

الـ `:variable` هو حاوية أو صندوق له اسم فريد لتخزين البيانات. لإنشاء واحد، نستخدم الكلمة المفتاحية `:let`.

```javascript
// :let -> أنشئ متغيراً جديداً
// score -> هو اسم المتغير (الصندوق)
// = -> هي علامة الإسناد (ضع القيمة في الصندوق)
// 100 -> هي القيمة التي نخزنها
let score = 100;
```

### 2. الطباعة في الطرفية (Logging to Console)

لكي نرى ما بداخل "الصندوق"، نستخدم `:console.log()`.

`console` هو كائن يمثل طرفية المطور في المتصفح، و `log` هي `:function` (وظيفة) تقوم بطباعة ما نعطيها.

```javascript
let playerName = "بطل";
// هنا نطلب من الطرفية عرض قيمة المتغير playerName
console.log(playerName);
```

> بإتقانك هذين المفهومين، أصبحت قادراً على تخزين أي معلومة وعرضها، وهي خطوتك الأولى نحو بناء تطبيقات حقيقية!
