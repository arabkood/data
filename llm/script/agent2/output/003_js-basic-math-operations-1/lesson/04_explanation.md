# أدواتك الحسابية الأساسية

أحسنت! لقد استخدمت بالفعل الجمع (`+`) والضرب (`*`). توفر لك لغة جافاسكريبت مجموعة كاملة من العوامل الحسابية (`:arithmetic operators:`) تمامًا مثل الآلة الحاسبة.

- **الجمع (`+`)**: لجمع قيمتين.
- **الطرح (`-`)**: لطرح قيمة من أخرى.
- **الضرب (`*`)**: لضرب قيمتين.
- **القسمة (`/`)**: لقسمة قيمة على أخرى.

### مثال شامل:
```javascript
let a = 10;
let b = 5;

console.log(a + b); // يطبع 15
console.log(a - b); // يطبع 5
console.log(a * b); // يطبع 50
console.log(a / b); // يطبع 2
```

> ولكن ماذا لو أردنا معرفة *باقي القسمة*؟ على سبيل المثال، عند توزيع 10 تفاحات على 3 أشخاص، كم تفاحة ستبقى؟

هنا يأتي دور عامل باقي القسمة (`%`):

```javascript
console.log(10 % 3); // يطبع 1
```

بإتقانك هذه العوامل، أصبحت قادراً على إجراء معظم الحسابات التي تحتاجها في تطبيقاتك!
