## التعامل مع النجاح باستخدام `.then()`

عندما يتم الوفاء بالوعد (`:fulfilled`)، كيف نحصل على النتيجة؟ نستخدم الدالة `.then()`.

تخيل `.then()` كأنها تقول: "**عندما** ينجح الوعد، **إذن** قم بتنفيذ هذا الكود بالقيمة التي أعادها".

```javascript
const myPromise = new Promise((resolve, reject) => {
  // محاكاة عملية ناجحة بعد ثانيتين
  setTimeout(() => {
    resolve("القهوة جاهزة!");
  }, 2000);
});

// هكذا نستخدم القيمة عند النجاح
myPromise.then((message) => {
  console.log(message); // سيطبع: القهوة جاهزة!
});
```

الآن، أصبح لديك طريقة موثوقة لتنفيذ كود فقط بعد اكتمال مهمة غير متزامنة بنجاح.
