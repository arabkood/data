أحسنت! لقد قمت بأهم خطوة: **التخطيط**.

الآن، لننتقل إلى مرحلة **الكتابة**. سنترجم خطتنا (مدخلات ومخرجات) إلى كود برمجي باستخدام أداة قوية تسمى **الدالة** (`:function`).

الدالة هي قطعة من الكود يمكننا استدعاؤها مرارًا وتكرارًا. لنرى كيف نحول خطتنا إلى `:function`:

```javascript
// خطتنا: المدخلات هي الطول (length) والعرض (width)
// المخرج هو المساحة (length * width)

function calculateArea(length, width) {
  let area = length * width;
  return area;
}
```

بتحويل خطتك إلى `:function`، أنت لا تكتب كودًا فحسب، بل تبني أداة قابلة لإعادة الاستخدام!
