## مصنع الدوال (Function Factory)

مصنع الدوال هو ببساطة `:function` تقوم بإنشاء وإرجاع `:function` أخرى. فكر فيه كأنه مصنع حقيقي: أنت تعطيه مواصفات معينة، وهو ينتج لك منتجًا مخصصًا (في حالتنا، المنتج هو `:function` أخرى).

لنعد إلى مثال تسجيل الرسائل. يمكننا بناء مصنع واحد يسمى `createLogger`:

```javascript
// هذا هو مصنع الدوال الخاص بنا
function createLogger(prefix) {
  // هذا هو المنتج: دالة جديدة يتم إرجاعها
  return function(message) {
    console.log(`[${prefix}] ${message}`);
  };
}
```

الآن، بدلاً من كتابة ثلاث دوال منفصلة، يمكننا استخدام مصنعنا لإنتاج العدد الذي نريده من دوال التسجيل المخصصة. بإتقانك هذا المفهوم، أصبحت قادراً على بناء أدوات مرنة وقابلة لإعادة الاستخدام.
