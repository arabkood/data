تخيل أنك تبني تطبيقًا وتحتاج إلى تسجيل أنواع مختلفة من الرسائل: معلومات، تحذيرات، وأخطاء. قد ينتهي بك الأمر بكتابة كود متكرر كهذا:

```javascript
function logInfo(message) {
  console.log(`[INFO] ${message}`);
}

function logWarning(message) {
  console.log(`[WARNING] ${message}`);
}

function logError(message) {
  console.log(`[ERROR] ${message}`);
}
```

الكود يعمل، ولكنه متكرر. ماذا لو أردنا تغيير التنسيق؟ سنضطر لتعديل كل `:function` على حدة.

> قبل أن نكمل، هل يمكنك التفكير في طريقة لتجنب هذا التكرار باستخدام ما تعرفه بالفعل؟ في هذا الدرس، سنكتشف نمطًا قويًا يسمى "مصانع الدوال" لحل هذه المشكلة بالضبط.
