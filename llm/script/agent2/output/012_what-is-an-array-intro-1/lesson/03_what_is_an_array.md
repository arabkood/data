أحسنت! لقد أنشأت أول `:array` لك.

تخيل الـ `:array` كأنها رف كتب. يمكنك وضع عدة كتب (قيم) على هذا الرف الواحد.

- الرف بأكمله هو الـ `:array`.
- كل كتاب على الرف هو `:element` (عنصر).
- كل مكان على الرف له رقم ترتيب، وهذا هو الـ `:index` (الفهرس).

```javascript
// هذا الـ :array يمثل رف الكتب
let bookshelf = ["كتاب العلوم", "كتاب التاريخ", "كتاب الرياضيات"];
```

بإتقانك هذا المفهوم، أصبحت قادراً على تنظيم كميات كبيرة من البيانات بسهولة.
