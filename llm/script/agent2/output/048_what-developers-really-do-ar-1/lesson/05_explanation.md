# من الخطة إلى الواقع

رأيت كيف يمكن لخطة خاطئة أن تؤدي إلى نتيجة كارثية. الآن، لنرَ كيف تبدو الخطة الصحيحة عند تحويلها إلى كود.

**الخطة الصحيحة:**
1.  إنشاء `:function` تستقبل معاملين: `firstName` و `lastName`.
2.  دمج `firstName` مع مسافة ثم مع `lastName`.
3.  إرجاع الاسم الكامل.

**الكود المقابل:**
```javascript
function getFullName(firstName, lastName) {
  let fullName = firstName + " " + lastName;
  return fullName;
}
```

> بإتقانك لهذه الدورة (التخطيط ثم البرمجة)، أصبحت تفكر الآن مثل مبرمج حقيقي، وليس مجرد شخص يكتب الكود.
