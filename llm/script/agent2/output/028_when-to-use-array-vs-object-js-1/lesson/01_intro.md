# تخزين البيانات: قائمة تسوق أم بطاقة شخصية؟

تخيل أن لديك قائمة تسوق: حليب، خبز، بيض. الترتيب مهم، أليس كذلك؟

والآن تخيل أن لديك بطاقة تعريف لمستخدم: الاسم، العمر، البريد الإلكتروني. هنا، كل معلومة لها اسم يميزها.

في البرمجة، كيف نختار الطريقة المثلى لتخزين كل نوع من هذه البيانات؟ هذا ما سنكتشفه.
