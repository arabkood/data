# لقد أتقنت الوصول إلى البيانات!

أحسنت! الآن أنت تفرق بوضوح بين:

- **تدوين النقطة (`.`):** للاستخدام السريع والمباشر مع الأسماء البسيطة.
- **تدوين الأقواس (`[]`):** للقوة والمرونة مع الأسماء المعقدة أو عند الحاجة للوصول الديناميكي عبر المتغيرات.

بإتقانك لهاتين الطريقتين، أصبحت قادراً على التعامل مع أي بنية `:object` في `:javascript` بمرونة وثقة!
