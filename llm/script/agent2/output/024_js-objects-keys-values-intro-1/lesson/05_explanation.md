للوصول إلى قيمة (`:value`) داخل كائن (`:object`), نستخدم "علامة النقطة" (`.`).

فكر فيها كأنك تسأل: "يا كائن، ما هي قيمة المفتاح كذا؟"

```javascript
let product = {
  name: "لابتوب",
  price: 4000
};

// للوصول إلى السعر
console.log(product.price);
```

> قبل أن نرى الناتج، ماذا تتوقع أن يطبع هذا الكود؟ بالضبط، سيطبع `4000`.
