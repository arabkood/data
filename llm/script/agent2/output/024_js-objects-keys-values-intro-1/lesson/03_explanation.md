الكائن (`:object`) هو حاوية لتخزين الخصائص (`:property`). كل خاصية تتكون من زوج: `:key` و `:value`.

- **المفتاح (`:key`)**: هو مُعرّف فريد (مثل اسم الحقل في بطاقة التعريف)، ويكون عادةً نصًا.
- **القيمة (`:value`)**: هي البيانات المرتبطة بالمفتاح، ويمكن أن تكون أي نوع من البيانات (نص، رقم، إلخ).

```javascript
// هذا كائن يمثل مستخدمًا
let user = {
  name: "علي", // المفتاح هو name والقيمة هي "علي"
  age: 28      // المفتاح هو age والقيمة هي 28
};
```

لاحظ أننا نفصل بين كل زوج `:key` و `:value` بفاصلة `,`.
