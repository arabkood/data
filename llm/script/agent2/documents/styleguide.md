# الدليل النفسي لإنشاء دروس البرمجة 

## 1. قواعد التنسيق والتواصل النفسي

### 1.1. تنسيق المصطلحات (يُطبق بدقة)

- في ملفات Markdown، يجب استخدام كتل الكود لعرض الأمثلة البرمجية للمستخدم.
- **في نصوص Markdown وحقول YAML (question/options/explanation)**:
  - المصطلحات التقنية تُحاط بــ`:term`
  - مثال: `:variable` , `:function`
- **في حقل الكود (code)**:
  - يُستخدم __@@INPUT@@__ فقط للإدخال (for placeholders)
  - يُمنع استخدام تنسيق المصطلحات

## 3. هيكل الدروس النفسي

### 3.1. البنية المرنة — Psychology-Driven Variants (Flexible Number of Files)

#### Variant A: Gradual Engagement & Mastery

```markdown
[مرحلة 1] - إثارة الفضول (سؤال تحفيزي أو مشكلة واقعية)
[مرحلة 2] - اختبار معرفة أولي (مفهوم بسيط مع خيارات)
[مرحلة 3] - شرح مركز مع أمثلة واضحة
[مرحلة 4] - تمرين تطبيقي لتعميق الفهم
[مرحلة 5+] - تمارين متقدمة أو تحديات تكاملية حسب الحاجة
```

#### Variant B: Scaffolded Learning

```markdown
[خطوة 1] - تقديم تحدي بسيط لجذب الانتباه
[خطوة 2] - تمرين سريع لتعزيز المفهوم الأساسي
[خطوة 3] - شرح مركّز لدعم التعلم
[خطوة 4] - تمرين تطبيقي مع تدرج في الصعوبة
[خطوة 5] - مراجعة الربط مع المفاهيم السابقة
[خطوة 6+] - تعميق أو توسيع التطبيق حسب تقدم المتعلم
```

#### Variant C: Cognitive Load Management

```markdown
[جزء 1] - سؤال أو موقف بسيط لجذب الانتباه
[جزء 2] - نشاط تدريبي محدود الحجم (لتجنب الإرهاق)
[جزء 3] - شرح مختصر ومحدد مع دعم بصري/كودي
[جزء 4] - تمرين عملي متدرج الصعوبة
[جزء 5] - نشاط تكاملي لجمع وتطبيق المعلومات المكتسبة
[جزء 6+] - فرص لممارسة إضافية حسب الحاجة
```

#### Variant D: Spaced Repetition & Active Recall

```markdown
[جلسة 1] - مشكلة أو سؤال يحفز التفكير
[جلسة 2] - اختبار سريع للمراجعة
[جلسة 3] - شرح موجز لتثبيت الفكرة
[جلسة 4] - تطبيق عملي لتفعيل المعرفة
[جلسة 5] - مراجعة وتكامل بين الأفكار السابقة
[جلسة 6+] - تكرار الدورة مع تحديات جديدة
```

---

* **لا حاجة لعدد ملفات محدد**، المهم هو التدرج في الصعوبة والتنوع في نوع التمرين.
* **تبدأ بفتحات تحفيزية** لجذب الانتباه.
* **تعزز المفاهيم بأسئلة وتمارين بسيطة**.
* **تقدم شرح مركز وواضح**.
* **تتدرج في التمارين التطبيقية حتى المتقدمة**.
* **توفر تكاملًا مع المفاهيم السابقة** لتحفيز الربط المعرفي.
* **تسمح بمرونة إضافة أو حذف مراحل حسب الحاجة والوقت**.


### 3.2. قواعد التتابع الذهبية

1. البدء بتمرين استكشافي للمفاهيم الجديدة
2. لا أكثر من ملف شرح واحد بين تمرينين
3. الختام بتطبيق عملي يربط المفاهيم


## 5. إستراتيجيات التحفيز النفسي

### في الشرح (MD فقط):

- **أسئلة استباقية**:
  > "قبل أن نكمل، ما الذي تتوقعه أن يحدث؟"
- **ربط بالإنجاز**:
  > "بإتقانك هذا المفهوم، أصبحت قادراً على..."

## 6. المحظورات النفسية

1. **الشرح المجرد**: يمنع تقديم مفاهيم بدون أمثلة عملية
2. **التمارين المتشابهة**: يمنع تكرار نفس النمط في تمرينين متتاليين
3. **الإرهاق الذهني**: يمنع تجاوز 300 كلمة في ملف الشرح الواحد

## إلهام نفسي من منصات تعليمية

1. **بداية سريعة** (مثل Duolingo):

   - تقديم التمرين قبل الشرح
   - نجاح سريع لبناء الثقة

2. **أمثلة واقعية** (مثل HackerRank):

   - مشاكل من سيناريوهات حقيقية
   - كود عملي قابل للتطبيق

3. **ربط المفاهيم** (مثل Brilliant):
   - توضيح كيف يبنى كل مفهوم على سابقه
   - رؤية الصورة الكبيرة
