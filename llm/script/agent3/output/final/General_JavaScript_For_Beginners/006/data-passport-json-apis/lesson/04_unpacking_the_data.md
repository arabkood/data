رائع! يمكننا إرسال البيانات. ولكن ماذا عن استقبالها؟

عندما يرسل لنا نظام آخر بيانات، فإنها تصل عادةً كسلسلة نصية بصيغة `JSON`. نحتاج إلى **فك حزمتها وإعادتها إلى كائن جافاسكريبت** يمكننا استخدامه.

لهذا الغرض، نستخدم الأداة المعاكسة: `JSON.parse()`.

```javascript
// تصل البيانات كسلسلة نصية من الخادم
const productJSON = '{"id": 451, "name": "تقويم هجري 1446"}';

// نقوم بتحليلها لإعادتها إلى كائن قابل للاستخدام
const productObject = JSON.parse(productJSON);

// الآن يمكننا الوصول إلى خصائصه!
console.log(productObject.name);
```

**الناتج:**
```
تقويم هجري 1446
```
