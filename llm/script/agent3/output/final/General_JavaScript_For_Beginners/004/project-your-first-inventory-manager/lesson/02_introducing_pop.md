في جافاسكريبت، نستخدم **الدالة (`method`)** `pop()` لإزالة آخر عنصر من **المصفوفة (`array`)**.

إنها بسيطة لكنها قوية. الدالة `pop()` لا تزيل العنصر فحسب، بل تعيده إلينا أيضًا في حال احتجنا لمعرفة ما تم إزالته.

### شاهد بنفسك

لنشاهد الدالة `pop()` أثناء عملها مع قائمة من البهارات.

```javascript
let spices = ['كمون', 'فلفل أسود', 'كركم'];
console.log('البهارات الأصلية:', spices);

// لنزيل آخر نوع من البهارات
let soldSpice = spices.pop();

console.log('البهارات المحدثة:', spices);
console.log('البهار المباع:', soldSpice);
```

### المخرجات
```
> البهارات الأصلية: [ 'كمون', 'فلفل أسود', 'كركم' ]
> البهارات المحدثة: [ 'كمون', 'فلفل أسود' ]
> البهار المباع: كركم
```

لاحظ كيف أصبحت `المصفوفة` `spices` الآن **أقصر**، وكيف احتفظنا بالقيمة المحذوفة في **المتغير (`variable`)** `soldSpice`.
