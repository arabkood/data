بدلاً من كتابة `console.log` ثلاث مرات، يمكننا استخدام حلقة `for` للقيام بالعمل نيابة عنا.

```javascript
let students = ["Fatima", "Omar", "Layla"];

for (let i = 0; i < students.length; i++) {
  console.log("أهلاً، " + students[i] + "!");
}
```

**الناتج:**
```
"أهلاً، Fatima!"
"أهلاً، Omar!"
"أهلاً، Layla!"
```

لاحظ كيف يصل `students[i]` إلى اسم كل طالب مع دوران الحلقة. يتغير العداد `i` تلقائيًا من `0` إلى `1`، ثم إلى `2`.
