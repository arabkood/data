انظر كيف يمكن للتعليقات أن تضع الخطوط العريضة لخطة برنامج ما. هنا، نحن نخطط لبرنامج محول للتاريخ الهجري.

```javascript
// المبرمجة: فاطمة
// الهدف: تحويل تاريخ ميلادي إلى هجري

/*
  الخطوات التالية:
  ١. الحصول على تاريخ اليوم
  ٢. إيجاد معادلة للتحويل
  ٣. عرض التاريخ الهجري الجديد
*/

console.log("بدء تحويل التاريخ...");
```

**التعليقات الجيدة تجعل هدف شيفرتك واضحًا.** هذه مهارة أساسية لأي مطور!

الآن بعد أن أصبحت قادرًا على ترك ملاحظات في شيفرتك، أنت مستعد لتعلم كيفية تخزين المعلومات التي يمكن أن تتغير. الدرس التالي: **المتغيرات (`variables`)**!
