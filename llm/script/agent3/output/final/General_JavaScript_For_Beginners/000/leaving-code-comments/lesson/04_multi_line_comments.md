ماذا لو كانت ملاحظتك طويلة جدًا لسطر واحد؟ استخدام `//` في كل سطر قد يكون مملاً بعض الشيء.

للملاحظات الطويلة، يمكنك استخدام تعليق متعدد الأسطر. يبدأ بـ `/*` وينتهي بـ `*/`.

**كل شيء بينهما يتم تجاهله**، بغض النظر عن عدد الأسطر التي يشغلها.
```javascript
/*
  خطة ملف المستخدم:
  - عرض اسم المستخدم: عمر
  - إظهار مدينته: الرياض
  - التأكد من أنه مستخدم مسجل
*/
console.log("عمر");
console.log("الرياض");
console.log(true);
```
