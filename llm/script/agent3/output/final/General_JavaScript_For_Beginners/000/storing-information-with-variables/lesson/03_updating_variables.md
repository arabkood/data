رائع! القوة الحقيقية `للمتغيّرات` المعرّفة بـ `let` هي أن محتوياتها يمكن تغييرها.

تخيّل نقاط لاعب في لعبة. تبدأ من 0 وتزداد. `المتغيّر` مثالي لهذا الغرض.

**لتحديث قيمة `متغيّر`**، نشير إليه باسمه ونُسند إليه قيمة جديدة. لا نحتاج إلى استخدام `let` مرة أخرى.

```javascript
// لنتتبع عدد الأهداف التي سجلها لاعب اسمه زياد
let goalsScored = 1;
console.log(goalsScored);

// زياد يسجل هدفًا آخر!
// نحدّث القيمة
goalsScored = 2;
console.log(goalsScored);
```

**الناتج**
```
1
2
```

هل رأيت كيف تغيّرت القيمة؟ 'الصندوق' الآن يحتوي على رقم جديد. لنرَ ما إذا كنت قد استوعبت الفكرة.
