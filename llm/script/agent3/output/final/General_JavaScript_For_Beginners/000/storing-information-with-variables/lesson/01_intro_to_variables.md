في الدروس السابقة، رأينا أنواعًا مختلفة من البيانات (`data types`) مثل النصوص والأرقام.

لكن مجرد رؤيتها لا يكفي. نحتاج إلى طريقة **لتخزين وتصنيف بياناتنا** حتى نتمكن من استخدامها لاحقًا.

فكّر في **المُتغيّر (`variable`)** كصندوق مُعنوَن يمكنك حفظ المعلومات فيه. يمكننا وضع البيانات بداخله، ثم العثور عليها مرة أخرى بالبحث عن العنوان.

لنرى كيف نُنشئ أحد 'صناديق الذاكرة' هذه في جافاسكريبت باستخدام الكلمة المفتاحية `let`. ✨

```javascript
// الصيغة: let variableName = value;

let studentName = "Layla";

console.log(studentName);
```

**الناتج**
```
Layla
```

هنا، أنشأنا `متغيّرًا` باسم `studentName` وخزّنّا فيه النص `"Layla"`. سهل، أليس كذلك؟ لنجرّب ذلك.
