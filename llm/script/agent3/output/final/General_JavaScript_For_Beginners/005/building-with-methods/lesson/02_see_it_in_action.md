لنلقِ نظرة على كائن لمستخدم اسمه `عادل`. يمكننا أن نمنحه `طريقة` ليقدّم بها نفسه.

الـ`طريقة` هي مجرد خاصية تكون قيمتها عبارة عن دالة.

```javascript
let userProfile = {
  name: "Adel",
  age: 25,
  // هذه هي الطريقة!
  sayHello: function() {
    console.log("مرحبًا، أنا عادل!");
  }
};

// لتشغيل الطريقة، نستدعيها هكذا:
userProfile.sayHello();
```

**المُخرجات:**
```
مرحبًا، أنا عادل!
```

لاحظ أننا نستخدم `ترميز النقطة` كما في السابق، ولكن مع الأقواس `()` في النهاية **لتشغيل الدالة**.
