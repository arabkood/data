الـ `كائن` هو مجموعة من أزواج **المفتاح (`key`): القيمة (`value`)**، وتكون محاطة بقوسين معقوصين `{}`.

فكّر في **الـ `مفتاح` كأنه عنوان** (مثل 'الاسم')، و**الـ `قيمة` كأنها المعلومة** نفسها (مثل 'ليلى').

```javascript
// هذا الكائن يصف طالبة
let student = {
  name: "Layla",
  age: 15,
  isEnrolled: true
};

// لنلقِ نظرة على كائننا الجديد!
console.log(student);
```

```
// الناتج:
{ name: 'Layla', age: 15, isEnrolled: true }
```
لاحظ كيف يمكننا تخزين أنواع بيانات مختلفة مثل **النصوص (`String`)**، و**الأرقام (`Number`)**، و**القيم المنطقية (`Boolean`)** كلها في مكان واحد.
