محاولة رائعة في التمرين السابق! لكن ماذا يحدث لو طلبنا معلومة من درج غير موجود؟

لنجرّب الوصول إلى خاصية `age` للطالب زيد، وهي خاصية لم نقم بتعريفها.

```javascript
let student = {
  name: "Zayd",
  field: "Computer Science"
};

console.log(student.age);
```

**الناتج:**
```
undefined
```

عفوًا! يبدو أننا طلبنا شيئًا غير موجود. عندما لا تكون الخاصية موجودة، تُرجع جافاسكريبت القيمة `undefined` بدلاً من إظهار خطأ. من المهم تذكّر هذا الأمر! ✨
