في درسنا السابق، تعلمنا كيفية تخزين النصوص في `سلاسل نصية` (`strings`). ولكن ماذا لو أردنا ربط نصين معًا؟

تخيل أن لديك اسمًا أول واسمًا أخيرًا مخزنين بشكل منفصل. نحتاج إلى طريقة لدمجهما لإنشاء اسم كامل.

هذه العملية لربط السلاسل النصية تسمى **الدمج (`concatenation`)**.

في جافاسكريبت، نستخدم العامل `+` لدمج السلاسل النصية. قد يبدو كرمز للجمع، ولكنه يعمل كالصمغ مع النصوص!

لنرى ذلك عمليًا. هنا ندمج تحية مع اسم.

```javascript
let greeting = "أهلاً، ";
let name = "فاطمة";

let welcomeMessage = greeting + name;

console.log(welcomeMessage);
// المخرجات: أهلاً، فاطمة
```

هل رأيت كيف "جمعنا" السلسلتين النصيتين معًا لإنشاء واحدة جديدة؟ **حان دورك الآن للتجربة.**
