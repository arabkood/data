كانت تلك محاولة أولى رائعة! هذا فخ شائع وقعت فيه عندما بدأت.

ماذا يحدث إذا نسيت إضافة مسافة بين الكلمات؟

```javascript
let firstName = "ليلى";
let lastName = "خالد";

let fullName = firstName + lastName;

console.log(fullName);
// المخرجات: ليلىخالد
```

الحاسوب ينفذ بالضبط ما نطلبه منه. هو لا يعرف تلقائيًا أننا بحاجة لمسافة.

لإصلاح هذا، يجب علينا **إضافة سلسلة نصية تحتوي على مسافة `" "`** بشكل صريح بين المتغيرات.

لنكتشف الخطأ في التمرين التالي.
