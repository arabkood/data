رائع! الآن بعد أن أصبح لدينا بيانات نظيفة، لنبني رسالة تخبر المستخدم بعمره بعد 5 سنوات.

لنجرب إضافة `5` إلى المتغير `age`.

```javascript
let age = "22";
let message = "In 5 years, you will be: " + age + 5;

console.log(message);
```

انظر إلى المخرجات: `In 5 years, you will be: 225`. ياه، هذا ليس صحيحًا! لماذا حدث هذا؟
