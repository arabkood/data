جملة `if` هي أول أداة لاتخاذ القرار لدينا. تتحقق من صحة شرط معين، وإذا كان صحيحًا، تُنفّذ مقطعًا برمجيًا محددًا.

لنَرَها قيد التنفيذ. سنستخدم متغيرًا للتحقق مما إذا كان الطالب `عادل` قد نجح.

```javascript
let hasPassed = true;

if (hasPassed === true) {
  // تهانينا! لقد نجحت في الامتحان.
  console.log("مبروك! لقد نجحت في الاختبار.");
}
```

**ركّز على هذا**: الكود الموجود داخل `{}` يعمل فقط لأن قيمة `hasPassed` هي `true`.
