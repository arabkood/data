لنعد إلى مشروعنا، **بوابة الدخول الذكية**.

نحتاج إلى منح حق الدخول فقط إذا كان المستخدم يمتلك بطاقة دخول **و** كان عضوًا نشطًا.

إليك إحدى طرق كتابة الكود، باستخدام معاملات المقارنة التي نعرفها بالفعل.

```javascript
let hasCard = true;
let isMember = true;

// الطريقة 'الأطول'
if (hasCard === true && isMember === true) {
  console.log("تم منح الدخول.");
} else {
  console.log("تم رفض الدخول.");
}
```

الآن، لنستخدم معرفتنا الجديدة بالقيم `الصائبة` لجعل هذا الكود أكثر تنظيمًا واحترافية. ✨
