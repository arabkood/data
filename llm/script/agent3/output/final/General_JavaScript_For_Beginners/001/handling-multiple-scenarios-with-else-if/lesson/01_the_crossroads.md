تتذكر كيف أعطتنا جملة `if/else` خيارًا بين طريقين؟ هذا رائع للقرارات البسيطة التي تقتصر على نعم أو لا.

لكن ماذا لو كنت عند مفترق طرق به أكثر من مسارين؟ لهذا، نحتاج إلى `else if`.

تسمح لك `else if` بإضافة **المزيد من الشروط** بين جملة `if` و `else`. الأمر أشبه بإضافة خيارات أكثر لقرارات برنامجك.

دعنا نرى كيف تعمل من خلال نظام لتقدير درجات طالبة اسمها ليلى.

```javascript
let laylasGrade = 85;

if (laylasGrade > 90) {
  console.log("ممتاز - Excellent!");
} else if (laylasGrade > 80) {
  console.log("جيد جدًا - Very Good!");
} else {
  console.log("تحتاج إلى تحسين - Needs Improvement");
}

// المخرجات:
// جيد جدًا - Very Good!
```

تتحقق الشفرة أولاً إذا كانت الدرجة أكبر من 90 (وهي ليست كذلك). ثم تنتقل إلى `else if` وتتحقق إذا كانت الدرجة أكبر من 80 (وهي كذلك!). فتقوم بتنفيذ ذلك المقطع وتتوقف.
