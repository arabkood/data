ماذا يحدث لو قدمنا مناسبة لا تعرفها الـ`دالة`، مثل 'عيد ميلاد'؟ حاليًا، سيكون المتغير `message` غير معرّف (`undefined`)!

لنصلح هذا بإضافة **رسالة افتراضية**. يتم تشغيل كتلة `else` النهائية عندما لا يتحقق أي من شروط `if` أو `else if`.

هذا يجعل دالتنا أكثر قوة ويمنع السلوك غير المتوقع. من الجيد دائمًا التخطيط للمدخلات غير المعروفة!

```javascript
// ... (كتل if/else if) ...
} else {
  message = 'أطيب التمنيات في هذا اليوم المميز!';
}
```
