باستخدام `let` و `const`، نحصل على نوع أكثر تحديدًا من النطاق: **نطاق الكتلة البرمجية (`block scope`)**. هذا يعني أن المتغير يمكن أن يكون محصورًا في أي كتلة برمجية محاطة بقوسين معقوفين `{}`.

هذا شائع في جمل `if` أو الحلقات التكرارية. المتغير الذي يُنشأ داخل كتلة برمجية يبقى داخلها.

```javascript
function checkStudentStatus(name) {
  let pass = true;

  if (pass) {
    // المتغير 'message' موجود فقط داخل كتلة 'if' هذه
    const message = "!تهانينا، " + name;
    console.log(message);
  }

  // محاولة الوصول إلى 'message' هنا ستسبب خطأ!
}

checkStudentStatus("ليلى");
```

**الناتج:**
```
!تهانينا، ليلى
```
