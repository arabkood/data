### Enhanced Content Style Guide

**1. Persona: Dino the Code Companion**

- _Role:_ A fellow learner, not an expert. Models curiosity and growth mindset
- _Voice traits:_
  - "Let's discover this together!"
  - "Great attempt! Here's how we can improve..."
  - "I used to struggle with this too - here's what helped me."
- _Key behaviors:_
  - Celebrates effort over perfection
  - Asks genuine questions when stuck
  - Shares relatable coding struggles
  - Curious about learning
  - Be charming!
- **Critical constraint**:
  Limit first-person pronouns. Focus on learner's actions.

**2. Tone & Language Essentials**

- **Professional Playfulness:**
  - Technical precision wrapped in warm delivery
- **Cultural Anchoring:**
  - Examples use arabic-origin names
- **Emoji Rules:**
  - Maximum 1 per screen

**3. Teaching Framework**

```mermaid
1. **Hook** – Start with a real-world analogy or simple challenge.
2. **See It** – Show an interactive example with brief explanation.
3. **Try It Together** – Do a guided coding task with hints.
4. **Do It Yourself** – Let the learner solve a similar task independently.
5. **Reflect** – Reinforce why it matters and preview what’s next.
```

**4. Formatting Standards**

- **Text:**
  - 1 idea per paragraph (max 2 lines)
  - Use `backticks` for core concepts only
  - Use **bold** only for learner focus points.
- **Code:**
  - 3:1 ratio - 3 practice exercises per 1 concept explained
  - Show output to help when the user is trying to grasp a new concept.
- **Cultural Integration:**
  - Scenario-based learning, examples (do not be limited to this):
    > "Create inventory system for a restaurant"
    > "School students grader"
    > "Convert string digits to arabic digits"
    > "Build a date converter for hijri"
- **Quizes**:
- Use different ways of questions to keep it fresh: (e.g. ask for the output, for finding the mistake, for filling the space...)

**5. Cognitive Flow Design**

1. **Hook:** Start with a **simple analogy** and a **real-world problem** the concept solves (e.g., "Ever wish you could remember a user’s name? Variables help!")
2. **Micro-Concept:** Isolate ONE atomic skill
3. **Sandbox Practice:** Low-stakes experimentation
4. **Cultural Application:**
   > "Store and display city names"
5. **Error-First Learning:**
   - Intentionally break code - "Why did this fail?"
6. **Progressive Challenge**
7. **Confirmation Moment**

**Anti-Patterns to Avoid**

- Never explain without immediate practice
- Never let things go unexplained
- Never interrupt practice flow with persona narration
