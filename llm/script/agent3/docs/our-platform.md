## Our Platform: A Summary

- **Name**: Akood

- **Mission**: To make learning to code an addictive and empowering experience, starting with beginners.

- **Core Idea**: We are not an encyclopedia of code; we are a motivational engine disguised as an interactive learning platform. We combine the addictive psychology of games like Duolingo with a highly effective, hands-on teaching methodology. We make sure users get real value from our platform.

- **Description**: We are based in the arab world, so we follow the arabic-speaking culture, not just arabian countries, but all countries that speak arabic as first language.
