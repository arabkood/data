## هل تريد تشغيل جافاسكربت على حاسوبك الشخصي؟ اتبع هذه الخطوات السريعة!

### تثبيت `:nodejs`

👈 اذهب إلى [https://nodejs.org](https://nodejs.org)

1. قم بتنزيل إصدار الدعم طويل الأمد (`:LTS`)
2. افتح الملف وانقر على التالي (Next) حتى ينتهي التثبيت

### تحقق

1. افتح `:terminal`, قد يُسمى حسب نظامك: `Command Prompt` أو `Terminal` أو `PowerShell`.

2. ثم اكتب:

```bash
node -v
```

يجب أن ترى رقم إصدار مشابه لـ:

```
v22.16.0
```

هذا يعني أنه يعمل!
