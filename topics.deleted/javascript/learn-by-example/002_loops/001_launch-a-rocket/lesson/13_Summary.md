## ملخص درس الحلقات

تعلمت في هذا الدرس مفهوماً مهماً جداً في البرمجة: **التكرار** (`:loops`). إليك أهم النقاط:

## حلقة for

- **الاستخدام**: عندما تعرف كم مرة تريد التكرار
- **البنية**: `for (البداية; الشرط; التحديث) { ... }`
- **مثال**: العد من 1 إلى 10

```javascript
for (let i = 1; i <= 10; i++) {
  console.log(i);
}
```

## حلقة while

- **الاستخدام**: عندما تريد التكرار حتى يتحقق شرط معين
- **البنية**: `while (الشرط) { ... }`
- **تحذير**: تأكد من تحديث المتغير لتجنب الحلقة اللانهائية

```javascript
let count = 1;
while (count <= 5) {
  console.log(count);
  count++;
}
```

## الأخطاء الشائعة

- نسيان تحديث المتغير في `while`
- الخطأ في شرط الإيقاف
- الخلط بين `++` و `--`

## ما يأتي بعد ذلك

في الدروس القادمة، سنتعلم كيفية التعامل مع **القوائم** (`:arrays`) والتكرار عبر مجموعات من البيانات. هذا سيفتح لك آفاقاً جديدة في البرمجة!

**تذكر**: الممارسة هي المفتاح. جرب إنشاء حلقات مختلفة وانظر ماذا يحدث!
