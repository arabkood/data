## متى نستخدم for ومتى نستخدم while؟

## استخدم `for` عندما:

- تعرف **بالضبط** كم مرة تريد التكرار
- تريد العد بطريقة منتظمة (1, 2, 3... أو 10, 8, 6...)

```javascript
// مثال: طباعة جدول الضرب للرقم 3
for (let i = 1; i <= 10; i++) {
  console.log(`3 × ${i} = ${3 * i}`);
}
```

## استخدم `while` عندما:

- **لا تعرف** كم مرة ستحتاج للتكرار
- التكرار يعتمد على شرط قد يتغير

```javascript
// مثال: قراءة الأرقام حتى نجد رقم زوجي
let randomNumber = 1;

while (randomNumber % 2 !== 0) {
  randomNumber = Math.floor(Math.random() * 10) + 1;
  console.log(`جرب الرقم: ${randomNumber}`);
}
console.log(`وجدت رقم زوجي: ${randomNumber}`);
```

## ملخص سريع

| الحلقة  | متى تستخدمها          | مثال                |
| ------- | --------------------- | ------------------- |
| `for`   | عدد معين من التكرارات | العد من 1 إلى 100   |
| `while` | تكرار حتى يتحقق شرط   | البحث عن قيمة معينة |

**كلاهما مفيد، والاختيار يعتمد على الموقف!**
