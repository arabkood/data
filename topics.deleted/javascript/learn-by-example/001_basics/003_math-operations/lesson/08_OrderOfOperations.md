## 🚦 ترتيب العمليات: من يأتي أولاً؟

هل تتذكر من المدرسة "أولوية العمليات الحسابية"؟ (أحيانًا تسمى PEMDAS أو BODMAS). جافاسكريبت تتبع قواعد مشابهة!

بشكل عام:

1.  **الأقواس `()`** لها الأولوية القصوى. ما بداخل الأقواس يُحسب أولاً.
2.  **الضرب `*` والقسمة `/` وباقي القسمة `%`** تأتي بعد ذلك، ويتم حسابها من اليسار إلى اليمين.
3.  **الجمع `+` والطرح `-`** تأتي أخيراً، ويتم حسابها أيضاً من اليسار إلى اليمين.

### أمثلة لتوضيح الفكرة:

```javascript
let result1 = 2 + 3 * 4;
// الضرب أولاً: 3 * 4 = 12
// ثم الجمع: 2 + 12 = 14
console.log("2 + 3 * 4 = " + result1); // 14
```

```javascript
let result2 = (2 + 3) * 4;
// الأقواس أولاً: 2 + 3 = 5
// ثم الضرب: 5 * 4 = 20
console.log("(2 + 3) * 4 = " + result2); // 20
```

```javascript
let result3 = 10 - 4 / 2;
// القسمة أولاً: 4 / 2 = 2
// ثم الطرح: 10 - 2 = 8
console.log("10 - 4 / 2 = " + result3); // 8
```

```javascript
let result4 = (10 + 5) % 4; // 15 % 4
// الأقواس أولاً: 10 + 5 = 15
// ثم باقي القسمة: 15 % 4 = 3
console.log("(10 + 5) % 4 = " + result4); // 3
```

### نصيحة ذهبية ✨

عندما تشك في ترتيب العمليات، أو لجعل الكود أوضح، **استخدم الأقواس `()`**!
الأقواس تجبر الحاسوب على حساب ما بداخلها أولاً، وتجعل الكود أسهل للقراءة والفهم لك وللآخرين.

مثلاً، `(a + b) / c` أوضح من `a + b / c` إذا كنت تقصد جمع `a` و `b` أولاً.
