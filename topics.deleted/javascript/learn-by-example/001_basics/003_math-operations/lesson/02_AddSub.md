## ➕ الجمع و ➖ الطرح

لنبدأ بالعمليتين الأساسيتين: الجمع والطرح. جافاسكريبت تتعامل معهما تمامًا كما تتوقع!

### 1. الجمع (`+`)

تستخدم علامة `+` لجمع رقمين أو أكثر.

```javascript
let score1 = 10;
let score2 = 20;
let score3 = 5;
let totalScore = score1 + score2 + score3;
console.log("النتيجة النهائية: " + totalScore);
// النتيجة النهائية: 35
```

> 💡 **ملاحظة سريعة**: علامة `+` تُستخدم أيضاً لدمج النصوص (كما رأينا في `console.log` أعلاه)، لكن عندما تكون بين رقمين، فإنها تقوم بعملية الجمع الحسابي.

### 2. الطرح (`-`)

تستخدم علامة `-` لطرح رقم من آخر.

```javascript
let budget = 100;
let expense = 30;
let remaining = budget - expense;

console.log("كان معي: " + budget);
// كان معي: 100
console.log("صرفت منها: " + expense);
// صرفت منها: 30
console.log("المتبقي معي: " + remaining);
// المتبقي معي: 70
```

سهل جداً، أليس كذلك؟ هيا نختبر معلوماتك!
