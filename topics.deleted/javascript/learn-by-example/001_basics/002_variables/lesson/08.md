`console.log()` هي نافذتك لمعرفة ما يحدث في الكود الخاص بك. تعرض هذه الدالة معلومات في `:console` الخاصة بالمتصفح أو `:terminal` في حالة `:nodejs`، مما يساعدك على رؤية القيم، و**تصحيح الأخطاء** (`:debug`)، وفهم كيفية عمل برنامجك.

```javascript
// يطبع: مرحبا
console.log("مرحبا");
// يطبع: 42
console.log(42);
// يطبع: true
console.log(true);
```

## عرض المتغيرات

يمكنك إظهار ما هو مخزن في `variable`:

```javascript
let name = "هانا";
let age = 25;

// يطبع: هانا
console.log(name);
// يطبع: 25
console.log(age);
```

## قيم متعددة

اطبع عدة أشياء مرة واحدة عن طريق فصلها بفواصل:

```javascript
let score = 100;
// يطبع: score: 100
console.log("score:", score);

let x = 5;
let y = 10;
// يطبع: x = 5 and y = 10
console.log("x =", x, "and y =", y);
```
