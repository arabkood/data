**المتغيرات** (`:variable`) هي مثل صناديق تحمل اسمًا معينًا داخل برنامجك، تُخزن بداخلها البيانات والمعلومات. تتيح لك هذه الصناديق إمكانية حفظ المعلومات، واسترجاعها، وتغييرها في أي وقت خلال تنفيذ البرنامج، مما يجعلها عنصرًا أساسيًا لإدارة البيانات في البرمجة.

## 1. إنشاء المتغيرات

استخدم كلمة **`let`** أو **`var`** لإنشاء متغير

```javascript
// متغير فارغ
let nothing;
// متغير يحمل اسم محمد
let name = "محمد";
// متغير يحمل رقم
let age = 20;
```

## 2. استخدام المتغيرات

بمجرد إنشاء متغير يمكنك استخدام اسمه للوصول إلى قيمته:

```javascript
// متغير يحمل اسم محمد
let name = "محمد";
// متغير يحمل رسالة مرحبا يا محمد
let message = "مرحبا يا " + name;
// يطبع الرسالة المخزنة في المتغير
console.log(message);
```

## تغيير قيمة المتغيرات

يمكنك تحديث ما هو مخزن في متغير

```javascript
// متغير يحتوي على 10
let score = 10;
// نغير قيمته الى 15
score = 15;
// نظيف الى قيمته 5 ليصبح 20
score = score + 5;
```

## قواعد تسمية المتغيرات

- يجب أن يبدأ اسم المتغير بحرف، أو شرطة سفلية (`_`)، أو علامة الدولار (`$`)
- يمكن أن يحتوي على حروف، وأرقام، وشرطات سفلية، وعلامات الدولار
- لا يمكن أن يكون من **الكلمات المحجوزة** (`:keyword`) في جافاسكربت مثل `let`، `if`، `for`, `var`...
- حساس لحالة الأحرف: `name` و `Name` هما متغيران مختلفان
