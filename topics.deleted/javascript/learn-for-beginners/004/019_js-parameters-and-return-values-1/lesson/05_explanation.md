## القيم المُعادة (Return Values): مخرجات الدالة

رائع! لكن ماذا لو أردنا استخدام الناتج في مكان آخر بدلاً من مجرد طباعته؟ هنا يأتي دور الكلمة المفتاحية `:return`.

عندما تستخدم `:return`، فإن الـ `:function` تتوقف عن التنفيذ فوراً وتعيد القيمة التي تليها.

```javascript
function add(num1, num2) {
  // الـ :function الآن تعيد قيمة بدلاً من الطباعة
  return num1 + num2;
}

let sum = add(5, 3); // قيمة 'sum' الآن هي 8
console.log(sum); // يطبع: 8
```

بإتقانك هذا المفهوم، أصبحت قادراً على بناء دوال كقطع بناء صغيرة يمكنك تركيبها معًا لإنشاء برامج معقدة.
