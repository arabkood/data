## المعاملات (Parameters): مدخلات الدالة

الـ `:parameter` هو متغير خاص تعرّفه في رأس الـ `:function` لاستقبال البيانات عند استدعائها. فكر فيه كصندوق بريد للدالة.

```javascript
// 'personName' هو الـ :parameter
function sayHello(personName) {
  console.log('أهلاً ' + personName);
}

// 'خالد' و 'سارة' هي القيم (arguments) التي نمررها
sayHello('خالد'); // يطبع: أهلاً خالد
sayHello('سارة'); // يطبع: أهلاً سارة
```

بفضل الـ `:parameter`، أصبحت دالة `sayHello` قابلة لإعادة الاستخدام ومرنة. قبل أن نكمل، هل يمكنك تخمين كيف يمكن للدالة أن تعطينا قيمة بدلاً من طباعتها فقط؟
