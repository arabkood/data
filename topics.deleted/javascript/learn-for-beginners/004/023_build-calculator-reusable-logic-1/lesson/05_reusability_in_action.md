# القوة الحقيقية: إعادة الاستخدام

الآن بعد أن أنشأنا وصفتنا (`add` :function)، يمكننا استخدامها بقدر ما نريد وبمدخلات مختلفة. هذا هو جوهر **المنطق القابل لإعادة الاستخدام**.

```javascript
function add(number1, number2) {
  return number1 + number2;
}

// استخدامها مرارًا وتكرارًا
let finalPrice = add(100, 20);      // الناتج 120
let totalUsers = add(53, 11);      // الناتج 64
let newScore = add(1000, 500);   // الناتج 1500
```

لاحظ كيف أننا لم نكرر منطق الجمع `number1 + number2` أبدًا. لقد كتبناه مرة واحدة فقط داخل الـ `:function`. هذا يجعل الكود أنظف وأسهل في الصيانة.
