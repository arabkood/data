اسم الـ`:function` هو بمثابة عقد بينها وبين من يستخدمها. اسم واضح يخبر المبرمجين الآخرين (ونفسك في المستقبل!) بالغرض منها دون الحاجة لقراءة الكود الداخلي.

فكر فيه كعنوان لكتاب. اسم جيد يخبرك بالقصة.

> بإتقانك للتسمية الواضحة، أصبحت قادراً على كتابة كود يسهل فهمه وتطويره بشكل أسرع.

```javascript
// غير واضح: ماذا يعني 'p'؟ وماذا تفعل الدالة؟
function p(d, r) { 
  return d * r;
}

// واضح: الأسماء تصف الغرض والمعاملات
function calculateDiscount(price, rate) {
  return price * rate;
}
```
