# الطريقة الذكية للبحث: دالة `:find`

بدلًا من كتابة حلقة `:for` طويلة للبحث في `:array`، يقدم `:javascript` دالة مدمجة أنيقة تسمى `:find`.

فكر في `:find` كأنها محقق خاص ترسله إلى `:array`. أنت تعطي المحقق شرطًا (عبر `:function`)، وهو يبحث عن **أول عنصر** يطابق هذا الشرط ويعيده لك.

```javascript
const users = [
  { id: 1, name: 'نورة' },
  { id: 2, name: 'خالد' }
];

// ابحث عن المستخدم الذي يملك id يساوي 2
const foundUser = users.find(user => user.id === 2);

console.log(foundUser); // { id: 2, name: 'خالد' }
```

> لكن ماذا يحدث لو لم يجد المحقق أي شخص يطابق الشرط؟ في هذه الحالة، ستعيد الدالة `:find` القيمة `:undefined`.
