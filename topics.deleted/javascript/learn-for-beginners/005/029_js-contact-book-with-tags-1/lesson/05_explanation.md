## إضافة الوسوم (Tags) للتنظيم

لجعل دفتر العناوين الخاص بنا أكثر قوة، سنضيف لكل جهة اتصال قائمة من الوسوم. يمكن أن يكون لكل شخص عدة وسوم (مثل "صديق" و "زميل عمل" في نفس الوقت).

سنقوم بتعديل بنية الـ `:object` لتشمل `:property` جديد اسمه `tags`، وسيكون عبارة عن `:array` من النصوص (`:string`).

```javascript
{
  name: 'علياء',
  phone: '111-222',
  tags: ['work', 'client'] // مصفوفة وسوم
}
```

> بإتقانك هذا المفهوم، أصبحت قادراً على تصميم هياكل بيانات أكثر تعقيدًا وواقعية.
