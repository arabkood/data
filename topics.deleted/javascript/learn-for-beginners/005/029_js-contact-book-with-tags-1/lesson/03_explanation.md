## من جهة اتصال واحدة إلى قائمة كاملة

رائع! لقد أنشأنا أول `:object` لجهة اتصال. ولكن كيف نخزن عدة جهات اتصال معًا؟

نستخدم `:array` (مصفوفة) لتكون بمثابة الحاوية لجميع جهات الاتصال. كل عنصر في الـ `:array` سيكون `:object` يمثل جهة اتصال واحدة.

```javascript
const contacts = [
  { name: 'علياء', phone: '111-222' },
  { name: 'بدر', phone: '333-444' }
];
```

> الآن، أصبحت `contacts` هي دفتر العناوين الخاص بنا.
