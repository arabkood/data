## القوة الكاملة: كائنات داخل مصفوفات

السيناريو الأكثر شيوعًا وقوة هو تنظيم قائمة من العناصر المعقدة. بدلًا من مصفوفة نصوص بسيطة، يمكننا إنشاء `:array` يحتوي على عدة `:object`.

**مثال: قائمة منتجات**

تخيل متجرًا إلكترونيًا. كل منتج له اسم وسعر. يمكننا تمثيل قائمة المنتجات كـ `:array` من الـ `:object`.

```javascript
const products = [
  { name: "لابتوب", price: 4000 },
  { name: "شاشة", price: 1500 },
  { name: "فأرة", price: 100 }
];
```

هذا الهيكل يسمح لنا بتخزين بيانات غنية ومنظمة بشكل لا يصدق. للوصول إلى سعر الشاشة، سنحتاج إلى خطوتين: تحديد الـ`:object` الصحيح داخل الـ`:array`، ثم تحديد الـ`:property` الصحيح داخل ذلك الـ`:object`.
