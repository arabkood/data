# الدليل لاختيار أسماء رائعة

اختيار أسماء جيدة هو مهارة. القاعدة بسيطة: **يجب أن يصف الاسم ما يفعله أو ما يحتويه.**

**مثال سيء:**
```javascript
let d = 10; // ما هو 'd'؟ أيام؟ دولارات؟
let arr = ["أحمد", "علي"]; // مصفوفة ماذا؟
```

**مثال ممتاز:**
```javascript
// استخدام camelCase هو التقليد المتبع في JavaScript
let discountPercentage = 10; // واضح! إنها نسبة الخصم
let userNames = ["أحمد", "علي"]; // واضح! إنها مصفوفة لأسماء المستخدمين
```

> بإتقانك لهذه المهارة، أصبحت قادراً على كتابة كود يمكن لزملائك (ولنفسك في المستقبل) فهمه بسهولة.
