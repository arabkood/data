## التعامل مع الفشل باستخدام `.catch()`

ماذا لو حدث خطأ؟ ماذا لو نفد الحليب في مثال القهوة؟ لهذا السبب، لدينا الدالة `.catch()`.

تخيل `.catch()` كأنها تقول: "في حال فشل الوعد، **التقط** الخطأ وقم بتنفيذ هذا الكود".

```javascript
const errorPromise = new Promise((resolve, reject) => {
  // محاكاة عملية فاشلة
  reject("عذراً، حدث خطأ في الشبكة.");
});

// هكذا نتعامل مع الخطأ
errorPromise.catch((error) => {
  console.error(error); // سيطبع: عذراً، حدث خطأ في الشبكة.
});
```

> بإتقانك لـ `.then()` و `.catch()`، أصبحت قادراً على التعامل مع السيناريوهين الرئيسيين لأي عملية غير متزامنة: النجاح والفشل، بطريقة واضحة ومنفصلة.
