رائع! الآن أنت تعرف كيف تؤخر تنفيذ مهمة. ولكن في تطبيقات حقيقية، لا نريد فقط الانتظار. نريد أن نعرف متى تكتمل العملية بنجاح (لنعرض البيانات) أو تفشل (لنعرض رسالة خطأ).

هنا يأتي دور الـ`:Promise`. الـ`:Promise` هو كائن يمثل نتيجة عملية غير متزامنة، سواء كانت ناجحة أو فاشلة.

فكر فيه كوعد: "أعدك بأنني سأعطيك البيانات عندما تصل، أو سأخبرك إذا حدث خطأ ما."

الـ`:Promise` له حالتان أساسيتان:
- **`resolved` (تم الوفاء بالوعد)**: العملية نجحت.
- **`rejected` (تم رفض الوعد)**: العملية فشلت.
