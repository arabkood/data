رائع! لقد تعلمت كيف "تلتقط" الأخطاء. ولكن ماذا لو أردت تنفيذ كود معين *دائماً*، سواء حدث خطأ أم لا؟

هنا يأتي دور كتلة `:finally`.

تُنفذ كتلة `:finally` دائماً بعد انتهاء `:try` (و`:catch` إذا لزم الأمر). هذا مفيد جداً للمهام التي يجب أن تحدث دائماً، مثل إغلاق اتصال بقاعدة بيانات أو تنظيف الموارد.

```javascript
try {
  // ... كود قد يفشل
} catch (error) {
  // ... التعامل مع الخطأ
} finally {
  // هذا الكود يُنفذ دائماً!
  console.log("مهمة التنظيف اكتملت.");
}
```
