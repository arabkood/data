# المؤقت الزمني: دليلك لتأجيل الكود

نقدم لك `:setTimeout`! إنها `:function` مدمجة في `:javascript` تسمح لك بتنفيذ كود معين بعد فترة زمنية تحددها أنت.

فكر فيها كأنك تعطي مساعدك وصفة (دالة) وتخبره أن يبدأ في طهيها بعد 5 دقائق (فترة التأخير).

```javascript
// الدالة التي نريد تنفيذها لاحقًا
function showMessage() {
  console.log("ظهرت الرسالة بعد ثانيتين!");
}

// نطلب من جافاسكريبت استدعاء showMessage بعد 2000 مللي ثانية
setTimeout(showMessage, 2000);
```

تأخذ `:setTimeout` مُعاملين أساسيين:
1.  **دالة الاستدعاء (`:callback function`)**: الـ`:function` التي سيتم تنفيذها.
2.  **التأخير (`:delay`)**: المدة بالمللي ثانية التي يجب انتظارها قبل التنفيذ. (`1000` مللي ثانية = 1 ثانية).

> لكن، هل يتوقف البرنامج بأكمله عن العمل خلال فترة الانتظار هذه؟ الإجابة هي لا! وهذه هي قوة البرمجة غير المتزامنة.
