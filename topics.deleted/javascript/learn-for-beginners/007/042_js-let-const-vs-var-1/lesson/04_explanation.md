## الصناديق الحديثة: `let` و `const`

رأيت بنفسك الفرق! لنلخص الأمر:

- **`:let` (الصندوق القابل للتعديل):**
  تُستخدم لتعريف متغيرات تتوقع أن تتغير قيمتها. مثل نقاط اللاعب في لعبة، أو عمر المستخدم.
  ```javascript
  let level = 1;
  level = 2; // ممتاز! يمكن تغييرها
  ```

- **`:const` (الصندوق المختوم):**
  تُستخدم لتعريف ثوابت لا يُفترض أن تتغير قيمتها أبدًا بعد إعطائها قيمة أولية. مثل اسم التطبيق، أو تاريخ الميلاد.
  ```javascript
  const appName = "MyCoolApp";
  // appName = "NewName"; // خطأ! لا يمكن تغييرها
  ```

> بإتقانك هذا المفهوم، أصبحت قادراً على كتابة كود أكثر أمانًا ووضوحًا، مما يقلل من الأخطاء غير المتوقعة!
