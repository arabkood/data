# سلسلة القرارات: تعرف على `else if`

عندما يكون لديك أكثر من شرطين، يمكنك استخدام `:else if` لإنشاء سلسلة من التحققات.

فكر فيها كأنها حارس يسأل عدة أسئلة بالترتيب:
1.  **`if` (الشرط الأول)**: هل هذا صحيح؟ إذا نعم، نفذ الكود وتوقف.
2.  **`else if` (الشرط الثاني)**: إذا لم يكن الأول صحيحًا، فهل هذا الشرط صحيح؟ إذا نعم، نفذ الكود وتوقف.
3.  **`else if` (شرط آخر)**: يمكنك إضافة أي عدد من `:else if`.
4.  **`else` (الخيار الأخير)**: إذا لم تتحقق أي من الشروط السابقة، نفذ هذا الكود.

```javascript
let score = 85;

if (score >= 90) {
  console.log("ممتاز");
} else if (score >= 80) {
  console.log("جيد جدًا"); // هذا ما سيتم تنفيذه
} else if (score >= 70) {
  console.log("جيد");
} else {
  console.log("بحاجة لتحسين");
}
```

بإتقانك هذا المفهوم، أصبحت قادرًا على بناء منطق برمجي أكثر تعقيدًا وواقعية.
