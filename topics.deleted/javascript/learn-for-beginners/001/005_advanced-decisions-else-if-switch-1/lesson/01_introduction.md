# كيف تتعامل مع أكثر من خيارين؟

تخيل أنك تبني نظامًا لتقدير درجات الطلاب. باستخدام `:if` و `:else` يمكنك تحديد ما إذا كان الطالب ناجحًا أم راسبًا. ولكن ماذا لو أردت تحديد تقديرات مثل "ممتاز"، "جيد جدًا"، "جيد"، و"مقبول"؟

هنا، لم يعد الخياران كافيين. أنت بحاجة إلى أداة تمكنك من التحقق من عدة شروط بالترتيب. لنكتشف كيف نفعل ذلك!
