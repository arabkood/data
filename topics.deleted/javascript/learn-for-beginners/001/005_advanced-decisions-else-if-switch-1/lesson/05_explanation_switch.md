# بديل أنيق: جملة `switch`

قبل أن نكمل، ما الذي تتوقعه أن يحدث لو كان لديك 10 شروط `:else if`؟ سيصبح الكود طويلاً ومربكًا!

عندما تريد التحقق من قيمة **متغير واحد** مقابل عدة قيم محتملة، فإن جملة `:switch` هي الخيار الأفضل والأكثر تنظيمًا.

```javascript
let day = 3;
let dayName;

switch (day) {
  case 1:
    dayName = "الأحد";
    break; // مهمة جدًا!
  case 2:
    dayName = "الاثنين";
    break;
  case 3:
    dayName = "الثلاثاء"; // هذا ما سيتم تنفيذه
    break;
  default:
    dayName = "يوم غير صالح";
}
console.log(dayName);
```

- `:switch(variable)`: نضع المتغير الذي نريد فحصه.
- `:case value:`: نقارن قيمة المتغير مع هذه القيمة.
- `:break;`: تمنع تنفيذ الحالات التالية (cases).
- `:default:`: تعمل مثل `:else`، وتُنفذ إذا لم تتطابق أي حالة.
