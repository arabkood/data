## تسجيل أدلة واضحة

المحقق الذكي لا يكتفي بجمع الأدلة، بل يقوم بتصنيفها وتسميتها لتكون واضحة.

يمكنك فعل نفس الشيء مع `:console.log()` عن طريق إضافة نصوص توضيحية بجانب القيم التي تطبعها. هذا يجعل مخرجات التحقيق أسهل في القراءة.

```javascript
let user = "Aya";
let score = 250;

// طباعة القيمة فقط (جيد)
console.log(score);

// طباعة القيمة مع تسمية (أفضل!)
console.log("Score for user:", score);
// سيطبع: Score for user: 250
```

هذه التقنية لا تقدر بثمن عندما تتعقب العديد من المتغيرات في نفس الوقت.
