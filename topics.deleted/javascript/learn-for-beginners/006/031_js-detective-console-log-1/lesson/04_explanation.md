## عدستك المكبرة: `:console.log()`

أحسنت! لقد استخدمت الأداة بنجاح. فكر في `:console.log()` كنافذة تطل منها على عالم الكود الخاص بك أثناء تشغيله.

عندما تضع `:variable` داخل قوسي `:console.log()`، فإنك تطلب من `:javascript` أن يخبرك بقيمته في تلك اللحظة بالضبط.

```javascript
let level = 5;
// لنرَ ما هي قيمة level الآن
console.log(level); // سيطبع: 5

level = level + 1;
// وما هي قيمته بعد التحديث؟
console.log(level); // سيطبع: 6
```

بإتقانك لهذه الأداة البسيطة، أصبحت قادراً على تتبع أي تغيير يحدث للمتغيرات وفهم تدفق برنامجك بشكل أفضل.
