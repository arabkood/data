# تهانينا! لقد أتقنت أساسيات الدوال

لقد قطعت شوطًا كبيرًا! الآن يمكنك:

- **تعريف** `:function` خاصة بك لتنظيم الكود.
- **استدعاء** `:function` لتشغيلها عند الحاجة.
- **تمرير** `:parameters` لجعل دوالك مرنة وقوية.
- **استخدام** `:return` للحصول على نتائج من دوالك.

الدوال هي عمود أساسي في البرمجة. باستخدامها، أنت تكتب كودًا أكثر نظافة، وأسهل في الصيانة، وأكثر احترافية. أنت الآن جاهز لمواجهة تحديات برمجية أكثر تعقيدًا.
