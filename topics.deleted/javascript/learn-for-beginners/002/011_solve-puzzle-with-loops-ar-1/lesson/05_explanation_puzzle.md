### دمج المهارات لحل اللغز

الآن لدينا كل الأدوات اللازمة! سنجمع بين `:for loop` ومفهوم تعلمته سابقًا، وهو `:if statement`، للعثور على الكنز.

إليك الخطة:
1.  نُعرّف `:variable` لتخزين عدد الكنوز، ولنبدأه بـ `0`.
2.  نستخدم `:for loop` للمرور على كل رمز في `map`.
3.  داخل الحلقة، نستخدم `:if statement` لنسأل: "هل الرمز الحالي هو '💰'؟".
4.  إذا كانت الإجابة "نعم"، نزيد عداد الكنوز بواحد.

```javascript
const map = "🌲🌲💰🌲🌳💰🌲💰";
let treasureCount = 0;

for (let i = 0; i < map.length; i++) {
  if (map[i] === '💰') {
    treasureCount++;
  }
}
// الآن، treasureCount يحتوي على العدد الصحيح!
```
