# تطبيق عملي: من البيانات إلى الواجهة

أنت الآن تملك أداة قوية. يمكن استخدام `:map` لتحويل مصفوفة من البيانات (مثل منتجات) إلى مصفوفة من عناصر HTML لعرضها على الصفحة.

```javascript
const products = ["لابتوب", "ماوس", "شاشة"];

const productListItems = products.map(function(product) {
  return `<li>${product}</li>`;
});

// productListItems will be:
// ["<li>لابتوب</li>", "<li>ماوس</li>", "<li>شاشة</li>"]
```

لقد تجاوزت مجرد التلاعب بالأرقام والنصوص، وأصبحت قادراً على تحويل البيانات إلى مكونات مرئية. هذه هي قوة البرمجة الوظيفية!
