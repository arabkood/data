# سر مهم: `:map` لا تُعدّل الأصل!

واحدة من أهم خصائص الدالة `:map` هي أنها **لا تغير المصفوفة الأصلية أبدًا**. إنها دائمًا تُرجع مصفوفة جديدة.

هذا المبدأ يسمى "عدم القابلية للتغيير" (Immutability) وهو مهم جدًا لكتابة كود آمن ويمكن التنبؤ بسلوكه.

```javascript
const numbers = [5, 10, 15];
const doubled = numbers.map(function(num) {
  return num * 2;
});

// doubled is [10, 20, 30]
// numbers is still [5, 10, 15] <-- لم تتغير!
```

قبل أن نكمل، ما الذي تتوقعه أن يحدث لو حاولنا استخدام `:map` بدون `return` داخل الدالة؟ فكر في الأمر!
