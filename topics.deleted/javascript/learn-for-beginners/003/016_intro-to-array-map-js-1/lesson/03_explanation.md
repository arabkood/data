# تعرف على الأداة السحرية: `:map`

دالة `:map` هي أداة مدمجة في المصفوفات (`:array`) تقوم بإنشاء **مصفوفة جديدة** بناءً على تحويل كل عنصر في المصفوفة الأصلية.

فكر فيها كخط إنتاج:
1.  تُعطيها مصفوفتك الأصلية (المواد الخام).
2.  تُعطيها `:function` (آلة التحويل) لتطبيقها على كل عنصر.
3.  تُرجع لك `:map` مصفوفة جديدة تمامًا (المنتج النهائي).

```javascript
const originalArray = [1, 2, 3];

const newArray = originalArray.map(function(item) {
  return item * 2; // ضاعف كل عنصر
});

// newArray is now [2, 4, 6]
```

بإتقانك هذا المفهوم، أصبحت قادراً على معالجة البيانات بكفاءة واحترافية!
