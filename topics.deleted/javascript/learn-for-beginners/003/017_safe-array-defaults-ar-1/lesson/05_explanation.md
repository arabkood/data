## الحل الأنيق: معامل OR المنطقي (`||`)

يمكننا استخدام معامل OR المنطقي (`||`) كطريقة مختصرة وفعالة لتوفير قيمة افتراضية.

**كيف يعمل؟**

يتحقق معامل `||` من القيمة على يساره. إذا كانت القيمة "falsy" (مثل `:undefined` في حالتنا)، فإنه يتجاهلها ويُرجع القيمة التي على يمينه.

```javascript
const scores = [90, 85];

// إذا كان scores[2] غير موجود (undefined)، استخدم 0 كقيمة افتراضية
const thirdScore = scores[2] || 0;

console.log(thirdScore); // سيطبع: 0
```

بهذه الطريقة البسيطة، نضمن أن المتغير `thirdScore` سيحتوي دائمًا على قيمة رقمية، مما يمنع الأخطاء المحتملة.
