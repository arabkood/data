## مشكلة القيمة `:undefined`

كما رأيت في التمرين السابق، عند محاولة الوصول إلى `:index` غير موجود في `:array`، نحصل على القيمة `:undefined`.

هذه القيمة يمكن أن تسبب أخطاء غير متوقعة في برنامجك، خاصة إذا حاولت استخدامها في عمليات حسابية.

```javascript
const scores = [90, 85];
let finalScore = scores[2] + 5; // undefined + 5 = NaN
```

هنا، الناتج سيكون `NaN` (Not-a-Number)، وهو خطأ منطقي قد يصعب اكتشافه.

> إذن، كيف يمكننا حماية الكود وتوفير قيمة بديلة آمنة؟
