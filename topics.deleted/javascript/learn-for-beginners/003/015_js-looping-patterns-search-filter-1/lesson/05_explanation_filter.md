# نمط التصفية: جمع كل التطابقات

رائع! لقد عثرت على العنصر الأول. ولكن ماذا لو أردت العثور على *كل* العناصر التي تطابق شرطًا معينًا؟ (مثلاً، كل الأرقام الزوجية في قائمة).

هنا يأتي دور **نمط التصفية (Filtering)**:

1.  **إنشاء `:array` فارغ**: نبدأ بـ `:array` جديد لتخزين النتائج.
2.  **حلقة تكرارية (`:for`)**: للمرور على كل عنصر كالعادة.
3.  **شرط (`:if`)**: للتحقق مما إذا كان العنصر الحالي يطابق شرطنا.
4.  **إضافة للنتائج (`.push`)**: إذا تطابق الشرط، نضيف العنصر إلى `:array` النتائج.

```javascript
const numbers = [1, 2, 3, 4, 5, 6];
const evenNumbers = []; // 1. إنشاء مصفوفة فارغة

for (let i = 0; i < numbers.length; i++) {
  // 3. التحقق من الشرط (هل الرقم زوجي؟)
  if (numbers[i] % 2 === 0) {
    evenNumbers.push(numbers[i]); // 4. إضافة للنتائج
  }
}

console.log(evenNumbers); // سيطبع: [2, 4, 6]
```
