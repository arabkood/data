# نمط البحث: العثور على العنصر الأول

البحث عن عنصر في `:array` يشبه البحث عن كتاب معين على رف. أنت تفحص كل كتاب حتى تجده، ثم تتوقف.

في الكود، هذا يترجم إلى:
1.  **حلقة تكرارية (`:for`)**: للمرور على كل عنصر في الـ `:array`.
2.  **شرط (`:if`)**: للتحقق مما إذا كان العنصر الحالي هو ما نبحث عنه.
3.  **إيقاف (`:break`)**: للخروج من الحلقة فور العثور على العنصر لتوفير الوقت والجهد.

```javascript
const fruits = ["تفاح", "موز", "برتقال", "مانجو"];
const fruitToFind = "برتقال";
let isFound = false;

for (let i = 0; i < fruits.length; i++) {
  if (fruits[i] === fruitToFind) {
    isFound = true;
    break; // وجدناه! لا حاجة لإكمال البحث
  }
}

console.log(isFound); // سيطبع: true
```

> بإتقانك هذا النمط، أصبحت قادراً على تحديد وجود أي معلومة في مجموعة بيانات!
