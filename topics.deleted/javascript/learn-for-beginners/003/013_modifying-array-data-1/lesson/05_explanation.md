ممتاز! الـ `:method` الذي استخدمته هو `:pop()`.

- **دالة `:pop()`**: هي عكس `:push()`. تقوم هذه الدالة بحذف العنصر الأخير من الـ `:array`.

> قبل أن نكمل، ما الذي تتوقعه أن تُرجعه دالة `:pop()`؟ هل تُرجع الـ `:array` الجديد أم شيئًا آخر؟

في الواقع، دالة `:pop()` لا تُرجع الـ `:array` بعد التعديل، بل تُرجع **العنصر الذي تم حذفه**. هذا مفيد جدًا إذا أردت استخدام هذا العنصر المحذوف في مكان آخر.

```javascript
let users = ["علي", "سارة", "أحمد"];
let removedUser = users.pop();

console.log(removedUser); // سيطبع "أحمد"
console.log(users);      // سيطبع ["علي", "سارة"]
```
