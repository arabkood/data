## الاختصار الأقوى: الإرجاع الضمني (Implicit Return)

ماذا لو كانت دالتك تحتوي على سطر واحد فقط مهمته هي إرجاع قيمة؟

دوال السهم تسمح لك باختصار مذهل:

-   يمكنك إزالة الأقواس المعقوفة `{}`.
-   يمكنك إزالة الكلمة المفتاحية `:return`.

ستفهم :javascript أنك تريد إرجاع نتيجة هذا السطر الوحيد تلقائياً.

```javascript
// دالة سهم مع إرجاع صريح
const double_explicit = (n) => { return n * 2; };

// نفس الدالة مع إرجاع ضمني
const double_implicit = (n) => n * 2;
```

**حالة خاصة:** إذا كان لديك معامل واحد فقط، يمكنك حتى إزالة الأقواس `()` حوله!

`const double = n => n * 2;`

> قبل أن نكمل، ما الذي تتوقعه أن يحدث إذا كانت الدالة لا تحتاج لمعاملات؟
