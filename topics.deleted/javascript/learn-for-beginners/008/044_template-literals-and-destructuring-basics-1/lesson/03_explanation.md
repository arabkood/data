# الحل السحري: قوالب النصوص (`Template Literals`)

بدلاً من استخدام علامات `+` المزعجة، تقدم `:javascript` طريقة أفضل تسمى `:template literals`.

تُكتب هذه القوالب باستخدام الفاصلة العلوية المائلة (` `` `) بدلاً من علامات الاقتباس العادية. الميزة الأقوى هي إمكانية إدراج متغيرات أو أي `:expression` داخل النص مباشرة باستخدام `${...}`.

**مثال:**

```javascript
const name = "سارة";
const age = 25;

// لاحظ استخدام `` وكيفية إدراج المتغيرات
const message = `اسم المستخدم: ${name}، والعمر: ${age}`;

console.log(message); // الناتج: اسم المستخدم: سارة، والعمر: 25
```

> بإتقانك هذا المفهوم، أصبحت قادراً على كتابة نصوص ديناميكية مقروءة وواضحة، وهو ما يميز المطور المحترف!
