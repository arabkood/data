# كيف تحول الفوضى إلى نظام؟

تخيل أنك تستقبل أسماء المستخدمين في تطبيقك بأشكال مختلفة: `'  ali '`، `'FATIMA'`، أو `'saRah'`. عرض هذه الأسماء كما هي يبدو غير احترافي.

في هذا الدرس، ستتعلم كيف تبني `:function` بسيطة وقوية لتنظيف وتنسيق هذه الأسماء تلقائيًا، لتحويلها دائمًا إلى صيغة نظيفة مثل `'Ali'`، `'Fatima'`، و `'Sarah'`. لنبدأ!
