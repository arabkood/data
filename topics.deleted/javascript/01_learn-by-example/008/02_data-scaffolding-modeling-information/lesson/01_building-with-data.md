في الدرس السابق، تعلمنا عن **تجزئة المشكلة** (`problem decomposition`)، وهي تقسيم هدف كبير إلى أجزاء أصغر يمكن إدارتها.

الآن، لِنفكر في المعلومات، أو **البيانات**، التي يحتاجها كل جزء. الأمر يشبه جهة اتصال في هاتفك؛ فأنت لا تحفظ الاسم فقط، بل تهيكله برقم هاتف وبريد إلكتروني، وغير ذلك.

هذه هي **نمذجة البيانات** (`data modeling`)! في البرمجة، نستخدم غالبًا **الكائن** (`object`) لتجميع المعلومات المترابطة. لنقم بنمذجة بيانات ضيف في تجمع عائلي.

```javascript
let guest = {
  name: "فاطمة",
  city: "الرياض",
};

console.log(guest);
```

**OUTPUT**

```
{ name: 'فاطمة', city: 'الرياض' }
```

هل ترى كيف تجمع الأقواس المعقوفة `{}` كل تفاصيل فاطمة معًا؟ لنكتشف هذا الأمر. 🤔
