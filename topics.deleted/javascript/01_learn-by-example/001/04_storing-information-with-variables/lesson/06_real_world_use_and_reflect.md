أداؤك رائع! لنجمع كل هذا معًا في سيناريو بسيط من واقع الحياة.

تخيّل أننا نبني جزءًا صغيرًا من نظام لدرجات الطلاب في مدرسة.

```javascript
// يمكننا استخدام التعليقات لشرح الكود
let studentName = "Noura";
let subject = "Math";
let grade = 85;

// الآن يمكننا عرض هذه المعلومات
console.log("تقرير الطالب");
console.log(studentName);
console.log(grade);

// لاحقًا، تم تحديث الدرجة بعد إعادة الاختبار
grade = 92;
console.log("الدرجة المحدثة:");
console.log(grade);
```

**الناتج**
```
تقرير الطالب
Noura
85
الدرجة المحدثة:
92
```

انظر إلى هذا! لقد استخدمت للتو **التعليقات (`comments`)**، و`أنواع البيانات`، و`المتغيّرات` لإنشاء جزء صغير وديناميكي من برنامج. ✨

الآن نعرف كيف نخزن المعلومات التي يمكن أن تتغير. لكن ماذا عن البيانات التي **لا يجب أن تتغير أبدًا**، مثل تاريخ ميلاد شخص ما؟ لنكتشف ذلك في الدرس التالي.
