أولًا، لدينا النصوص. في البرمجة، أي جزء من النص يسمى **سلسلة نصية (`string`)**.

لإنشاء `سلسلة نصية`، يجب عليك وضع النص بين علامتي اقتباس (`""`). هذا يخبر الحاسوب: **"تعامل مع هذا كنص عادي."**

```javascript
// هذه سلسلة نصية
console.log("Fatima Al-Fihri");

// وهذه أيضًا سلسلة نصية
console.log("مرحبا بالعالم");
```

**الناتج:**
```
Fatima Al-Fihri
مرحبا بالعالم
```
