أخيرًا، لدينا نوع البيانات **المنطقي (`boolean`)**. وهو أبسط الأنواع على الإطلاق ولا يمكن أن يأخذ إلا إحدى قيمتين: `true` أو `false`.

فكر فيه كمفتاح إنارة (يعمل/لا يعمل) أو كإجابة بنعم أو لا. الأنواع `المنطقية` ضرورية لاتخاذ القرارات في الكود الخاص بك.

على سبيل المثال، يمكننا طرح سؤال مثل: **"هل حساب المستخدم نشط؟"**

```javascript
console.log(true);
```

**الناتج:**
```
true
```
بسيط، أليس كذلك؟ ✨
