لنَرَ هذه 'المسطرة' قيد التنفيذ. يمكننا الوصول إلى الخاصية `length` بإضافة نقطة `.` بعد متغير السلسلة النصية، تليها كلمة `length`.

```javascript
let driverName = "Amal";
console.log(driverName.length);
```

**الناتج:**
```
4
```
