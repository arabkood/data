بالنظر إلى البيانات، تبدو فوضوية بعض الشيء. الاسم يحتوي على مسافات إضافية وهو بأحرف صغيرة.

هذا أمر شائع جدًا في تطبيقات العالم الحقيقي! يمكننا استخدام دوال النصوص (`string methods`) التي تعلمناها لتنظيفها قبل عرضها.

لنستخدم الدالة `trim()` لإزالة المسافات البيضاء والدالة `toUpperCase()` لتنسيق الاسم من أجل ترحيب جميل ونظيف. هل ترى كيف يمكننا ربطهما معًا؟

```javascript
let messyText = "  some data  ";
let cleanText = messyText.trim().toUpperCase();

console.log(cleanText);
// المخرجات: SOME DATA
```
