حتى الآن، استخدمنا علامات الاقتباس المزدوجة (`" "`). ولكن يمكنك أيضًا استخدام علامات الاقتباس المفردة (`' '`).

كلاهما يعمل بشكل ممتاز!

```javascript
let friendName = "Amir";
let favoriteDish = 'Mansaf';
```

القاعدة الأهم هي أن **تكون متّسقًا في أسلوب كتابتك للكود**.

ماذا لو كانت سلسلتك النصية بحاجة لاحتواء علامة اقتباس؟ يمكنك استخدام النوع الآخر من علامات الاقتباس لتغليفها. على سبيل المثال، لتخزين النص `Layla's book`، يمكننا استخدام علامات الاقتباس المزدوجة في الخارج.

```javascript
let bookTitle = "Layla's book"; // هذا يعمل بنجاح!

console.log(bookTitle);
```

**الناتج:**

```
Layla's book
```
