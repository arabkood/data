تخيّل أننا ندير قائمة طلاب لأحد الفصول. كل طالب هو عبارة عن `كائن` له خصائصه الخاصة.

تبدو `مصفوفة الكائنات` هكذا. هي `مصفوفة` `[ ]` يكون كل عنصر بداخلها عبارة عن `كائن` `{ }`.

```javascript
let students = [
  { name: "Laila", grade: 85 },
  { name: "Karim", grade: 92 },
  { name: "Fatima", grade: 78 },
];
```
