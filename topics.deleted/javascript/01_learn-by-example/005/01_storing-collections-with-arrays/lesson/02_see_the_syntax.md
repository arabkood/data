إنشاء `مصفوفة` أمر بسيط. نستخدم الأقواس المربعة `[]` ونفصل بين كل عنصر بفاصلة.

إليك `مصفوفة` لأسماء أفراد العائلة في تجمع عائلي:

```javascript
let familyMembers = ["Aisha", "Karim", "Fatima", "Youssef"];

console.log(familyMembers);
```

**ستكون النتيجة:**
```
[ 'Aisha', 'Karim', 'Fatima', 'Youssef' ]
```

لاحظ كيف يعرض الأمر `console.log` القائمة بأكملها، بالأقواس وكل شيء. **حان دورك الآن** لتجربة إنشاء واحدة.
