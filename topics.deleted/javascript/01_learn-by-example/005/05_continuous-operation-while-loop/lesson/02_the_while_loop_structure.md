لنلقِ نظرة على بنيتها الأساسية. إنها تشبه حارسًا عند بوابة يسمح للناس بالدخول فقط *طالما* أن شرطًا معينًا مُتحقِّق.

```javascript
let ticketsLeft = 3;

while (ticketsLeft > 0) {
  console.log("تم بيع تذكرة! مرحبًا بك.");
  ticketsLeft = ticketsLeft - 1; // هذا الجزء ضروري جدًا!
}

console.log("عذرًا، لقد نفدت التذاكر!");
```

**هنا يكمن السر**: يجب أن تتغير قيمة `ticketsLeft` داخل الحلقة. إذا لم تتغير، ستعمل الحلقة إلى الأبد! ♾️
