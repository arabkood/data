أنشئ أو أكمل دالة `ageCalculator(name, birthYear)` التي:

- تأخذ `name` (نص) و `birthYear` (رقم) كمعاملات.
- تحدد متغير `const` يسمى `currentYear` وتضعه للسنة الحالية (مثلاً، 2024).
- تحسب `age`.
- ترجع نصاً باستخدام قوالب النصوص بالتنسيق: "(الاسم) عمره (العمر) سنة."

_مثال: _`ageCalculator("Alice", 1990)`_ يجب أن ترجع _`"Alice is 34 years old."`_ (إذا كانت السنة الحالية 2024)._
