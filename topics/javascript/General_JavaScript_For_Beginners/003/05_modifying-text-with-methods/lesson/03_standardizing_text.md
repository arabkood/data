عمل رائع! والآن لنجرّب العكس. غالبًا ما نحتاج إلى تحويل النص إلى أحرف صغيرة لمقارنة الأشياء بشكل متسق.

على سبيل المثال، إذا كتب المستخدم "Cairo" وكانت قاعدة بياناتنا تحتوي على "cairo"، فيجب أن يتطابقا. تساعدنا دالة `toLowerCase()` هنا.

```javascript
let userInput = "Jeddah";
let savedCity = userInput.toLowerCase();

console.log(savedCity);
```

**الناتج**
```
jeddah
```

هذه مهمة شائعة جدًا **لجعل البيانات موحّدة** قبل حفظها أو التحقق منها.
