لقد رأينا كيف نجد `طول` النص باستخدام **خاصيّة (`property`)**.

ولكن ماذا لو أردنا *تغيير* النص نفسه؟

لهذا الغرض، نستخدم **الدوال (`methods`)**. فكّر في `الدوال` كإجراءات أو أوامر خاصة يمكننا تنفيذها على نصوصنا.

لنبدأ بواحدة شائعة. تخيّل أنك تريد أن تجعل اسم مستخدم يبدو كصيحة. يمكننا استخدام دالة `toUpperCase()`.

```javascript
let studentName = "farah";
let loudName = studentName.toUpperCase();

console.log(loudName);
```

**الناتج**
```
FARAH
```

لاحظ الأقواس `()` في النهاية. هكذا نعرف أنها **إجراء (دالة)**، وليست مجرد وصف (`خاصيّة` مثل `.length`).
