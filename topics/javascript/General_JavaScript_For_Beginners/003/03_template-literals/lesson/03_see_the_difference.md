لنلقِ نظرة على الطريقة القديمة مقابل الطريقة الجديدة.

**قبل (الدمج التقليدي):**
```javascript
let name = "ليلى";
let city = "بيروت";
console.log("أهلاً بكِ، " + name + "، من " + city + "!");
```

**بعد (القالب الحرفي):**
```javascript
let name = "ليلى";
let city = "بيروت";
console.log(`أهلاً بكِ، ${name}، من ${city}!`);
```

كلاهما يُنتج نفس المخرجات، لكن لاحظ كم أن **الطريقة الثانية أكثر تنظيمًا**.

> **المخرجات:**
> أهلاً بكِ، ليلى، من بيروت!
