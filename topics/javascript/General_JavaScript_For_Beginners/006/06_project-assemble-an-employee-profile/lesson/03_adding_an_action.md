بداية رائعة! `كائن` الـ `employee` الخاص بنا يحتوي الآن على بيانات عمر الأساسية.

لكن `الكائنات` ليست فقط لتخزين المعلومات، بل هي أيضًا لتنفيذ المهام.

لِنُضِف `دالة`. `الدالة` هي وظيفة (`function`) تعيش داخل `كائن`، مما يمنحه قدرة محددة.

سنضيف `دالة` باسم `greet` تطبع رسالة ترحيب. هذا يجعل `الكائن` الخاص بنا أكثر تفاعلية.
