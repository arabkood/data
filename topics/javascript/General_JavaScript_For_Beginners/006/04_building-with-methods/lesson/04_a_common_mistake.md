نسيان الأقواس `()` هو خطأ شائع جدًا!

دعنا نرى ما سيحدث. إنها طريقة رائعة لفهم ما يجري في الكواليس.

```javascript
let car = {
  type: 'Sedan',
  honk: function() {
    console.log('Beep beep!');
  }
}

// مع الأقواس (صحيح):
car.honk();

// بدون أقواس (ماذا يفعل هذا؟):
console.log(car.honk);
```

**المُخرجات:**
```
Beep beep!
[Function: honk]
```

بدون `()`، أنت تشير فقط إلى الدالة نفسها، ولا **تُنفّذ الإجراء**. 💡
