إذا كانت بعض القيم `صائبة`، فمن المنطقي أن تكون هناك قيم أخرى `خاطئة`. **القيمة الخاطئة (`falsy`)** هي قيمة تتصرف مثل `false` في الشرط.

لحسن الحظ، هناك عدد قليل فقط من القيم `الخاطئة` (`falsy`) التي يجب تذكرها!

القيم `الخاطئة` الرئيسية هي: `false`، `0`، `""` (نص فارغ)، `null`، و `undefined`.

**شاهد المثال:**

```javascript
let userMessage = "";

if (userMessage) {
  console.log("تم استلام رسالة جديدة!");
} else {
  console.log("لا توجد رسائل جديدة.");
}
```

**الناتج:**
```
لا توجد رسائل جديدة.
```

لأن `userMessage` هو نص فارغ، فهو قيمة `خاطئة`. هذا يجعل كتلة `else` تعمل. هذا نمط شائع ومفيد جدًا!
