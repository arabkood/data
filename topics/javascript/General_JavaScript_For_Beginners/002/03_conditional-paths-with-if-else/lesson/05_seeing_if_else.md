لنعد إلى نتيجة امتحان `عادل`. هذه المرة، سنتعامل مع كلتا النتيجتين.

```javascript
let adelGrade = 55;
let passingGrade = 60;

if (adelGrade >= passingGrade) {
  console.log("مبروك! لقد نجحت.");
} else {
  console.log("واصل المحاولة، يمكنك فعلها!");
}
```

**الناتج:**
```
واصل المحاولة، يمكنك فعلها!
```

لأن `55 >= 60` نتيجتها `false`، يتم تنفيذ الكود الموجود داخل **كتلة `else`**.
