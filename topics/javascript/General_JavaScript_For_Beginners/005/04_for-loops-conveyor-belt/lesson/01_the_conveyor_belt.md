سابقًا، أضفنا عناصر إلى قوائمنا. لكن فحص كل عنصر على حدة أمر بطيء، تمامًا مثل فحص المنتجات في صندوق خشبي يدويًا.

لنبنِ آلة للقيام بذلك بدلًا عنا! هنا يأتي دور حلقة `for` التكرارية (`for loop`)، حزامنا الناقل الآلي. 🤖

تخبر الحاسوب بتكرار إجراء معين لكل عنصر في مصفوفة. **هكذا نقوم بأتمتة المهام.**

هذه هي بنيتها الأساسية. قد تبدو غريبة بعض الشيء، لكننا سنكتشفها معًا.

```javascript
let cities = ["Riyadh", "Cairo", "Beirut"];

for (let i = 0; i < cities.length; i++) {
  // الإجراء المُراد تكراره يوضع هنا
  console.log(cities[i]);
}
```

**الناتج:**
```
"Riyadh"
"Cairo"
"Beirut"
```
