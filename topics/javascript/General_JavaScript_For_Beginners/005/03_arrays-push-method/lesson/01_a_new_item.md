نتذكر كيف قمنا بتخزين قائمة من العناصر في مصفوفة؟ كان الأمر أشبه بوضع الأغراض في صندوق.

ولكن ماذا يحدث عند وصول عنصر جديد؟ نحتاج إلى طريقة **لإضافته إلى قائمتنا** دون أن نبدأ من جديد.

دعنا نرى كيف يمكننا إضافة صديقة جديدة، 'ليلى'، إلى قائمتنا الحالية. نستخدم أمرًا خاصًا يسمى **الطريقة (`push`)**.

```javascript
let friends = ["Nadia", "Omar"];

// لنضف ليلى في النهاية
friends.push("Layla");

console.log(friends);
```

**الناتج:**
```
[ "Nadia", "Omar", "Layla" ]
```

أرأيت؟ لقد أضافت الطريقة `push` 'ليلى' إلى نهاية القائمة تمامًا. سهل جدًا! ✨
