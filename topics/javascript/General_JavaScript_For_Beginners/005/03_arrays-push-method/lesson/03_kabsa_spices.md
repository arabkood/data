كانت تلك محاولة أولى رائعة! يبدو أن `push` تشبه إضافة كتاب جديد إلى نهاية الرف.

لنجرب مثالًا عمليًا أكثر. تخيل أننا نُعد قائمة بهارات لوصفة *الكبسة* وتذكرنا بعض البهارات الإضافية.

يمكننا **استخدام `push` عدة مرات** لمواصلة إضافة العناصر.

```javascript
let kabsaSpices = ["قرفة", "هيل"];

kabsaSpices.push("لومي");
kabsaSpices.push("قرنفل");

console.log(kabsaSpices);
```

**الناتج:**
```
[ "قرفة", "هيل", "لومي", "قرنفل" ]
```

كل استدعاء للطريقة `push` يضيف عنصرًا جديدًا في نهاية الصف. أصبح الأمر مفيدًا الآن! 🤔
