محاولة رائعة! للدوال السهمية بعض الصيغ المختلفة المفيدة التي تعتمد على عدد `المُعاملات`.

**مُعامِل واحد:** الأقواس اختيارية.
`const greet = name => `أهلاً، ${name}``;

**بلا مُعاملات:** يجب استخدام أقواس فارغة `()`.
`const sayHello = () => "أهلاً وسهلاً!";`

**أسطر متعددة:** إذا كانت دالتك تحتاج لأكثر من سطر، يجب استخدام **الأقواس المعقوفة (`curly braces`)** `{}` وكلمة `return` بشكل صريح.
```javascript
const getFullName = (firstName, lastName) => {
  const fullName = `${firstName} ${lastName}`;
  return `مرحباً بك، ${fullName}`;
};
```
**ركّز على هذا:** تكون `return` تلقائية فقط عندما لا توجد `أقواس معقوفة` `{}`.
