بعد ذلك، لدينا نوع البيانات **رقم (`number`)**. نستخدمه للعد، والحسابات، وأي نوع من العمليات الرياضية.

على عكس السلاسل النصية، **يجب ألا تحتوي الأرقام على علامات اقتباس**. بهذه الطريقة يعرف الحاسوب أنه يمكنه إجراء عمليات حسابية عليها.

```javascript
// لنحسب المجموع لمنتجين في سلة التسوق
console.log(150 + 25);
```

**الناتج:**
```
175
```

لاحظ كيف طبع نتيجة العملية الحسابية، وليس النص `"150 + 25"`. هذه هي قوة نوع البيانات `رقم`! ✨
