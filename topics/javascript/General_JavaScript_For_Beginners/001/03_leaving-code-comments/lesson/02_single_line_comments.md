النوع الأكثر شيوعًا من التعليقات هو التعليق أحادي السطر. يبدأ بشرطتين مائلتين للأمام `//`.

أي شيء يأتي بعد `//` على نفس السطر يُعتبر `تعليقًا` ولن يقوم الحاسوب بتنفيذه.

**لنرى ذلك عمليًا:**
```javascript
// هذا السطر يطبع رسالة ترحيب لخالد
console.log("أهلاً، خالد!");

console.log(25); // هذا يوضح عمر خالد
```

لاحظ كيف أن الحاسوب ينفّذ أجزاء `console.log` فقط.
