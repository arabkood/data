إليك مثال شائع: ملف تعريف المستخدم. المستخدم لديه اسم، لكن عنوانه عبارة عن مجموعة تفاصيل خاصة به.

**شاهد المثال:**
```javascript
const user = {
  name: "خالد",
  email: "khaled@example.com",
  address: {
    city: "الرياض",
    country: "المملكة العربية السعودية"
  }
};
```

لاحظ كيف أن خاصية `address` تحتوي على كائن آخر `{}` كقيمة لها. هذا هو `الكائن المتداخل`!
