Right now, your process for seeing changes probably looks like this:

1.  Make a change in your `script.js` file.
2.  Save the file.
3.  Switch to your browser window.
4.  Press the refresh/reload button.
5.  Check the result.

> This works, but it's slow and repetitive. Every professional developer uses tools to automate this process. In the next lesson, we will set up a professional environment that makes coding much faster and more enjoyable.
