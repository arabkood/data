### مشكلة التكرار المزعج

تخيل أنك تبني برنامجًا لحساب مساحة مستطيلات مختلفة. قد تبدأ بكتابة كود مثل هذا:

```javascript
// حساب مساحة المستطيل الأول
let width1 = 10;
let height1 = 5;
let area1 = width1 * height1;
console.log(area1); // الناتج: 50

// حساب مساحة المستطيل الثاني
let width2 = 8;
let height2 = 4;
let area2 = width2 * height2;
console.log(area2); // الناتج: 32
```

لاحظ أن منطق حساب المساحة (`width * height`) مكرر. ماذا لو أردت تغيير طريقة الحساب؟ ستحتاج لتغييرها في كل مكان!

> قبل أن نكمل، هل يمكنك التفكير في طريقة لتجنب هذا التكرار؟
