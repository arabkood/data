### الحل السحري: الدوال (`:function`)

الـ`:function` هي وصفة قابلة لإعادة الاستخدام. أنت تعرفها مرة واحدة، ثم تستدعيها كلما احتجت إليها، تمامًا مثل استدعاء طاهٍ ماهر لإعداد طبقك المفضل.

دعنا نعيد كتابة مثالنا باستخدام `:function`:

```javascript
// 1. تعريف الوصفة (الدالة)
function calculateArea(width, height) {
  return width * height;
}

// 2. استخدام الوصفة (استدعاء الدالة)
let area1 = calculateArea(10, 5); // نمرر المكونات (الوسائط)
let area2 = calculateArea(8, 4);

console.log(area1); // الناتج: 50
console.log(area2); // الناتج: 32
```

الآن، إذا أردنا تغيير منطق الحساب، نغيره في مكان واحد فقط: داخل الـ`:function`!

> بإتقانك هذا المفهوم، أصبحت قادراً على كتابة كود أكثر نظافة واحترافية.
