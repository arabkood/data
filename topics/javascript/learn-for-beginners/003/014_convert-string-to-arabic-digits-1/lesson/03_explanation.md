# خريطة التحويل السحرية

كما استنتجت، أفضل طريقة هي بناء "خريطة" أو `:object` يربط بين الأرقام. 

```javascript
const arabicDigitsMap = {
  '0': '٠', '1': '١', '2': '٢', '3': '٣', '4': '٤',
  '5': '٥', '6': '٦', '7': '٧', '8': '٨', '9': '٩'
};
```

هذا الـ`:object` هو أساس الحل. الخطوة التالية هي المرور على كل حرف في الـ`:string` المدخل. إذا كان الحرف رقمًا موجودًا في خريطتنا، نستبدله. وإذا لم يكن رقمًا (مثل مسافة أو حرف أبجدي)، نتركه كما هو.

> قبل أن نكمل، ما الذي تتوقعه أن يحدث لو أدخلنا النص `'id-123'`؟
