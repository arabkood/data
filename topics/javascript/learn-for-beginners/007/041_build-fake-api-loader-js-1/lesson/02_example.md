قبل أن نتعمق في محاكاة الشبكة، لنبدأ بمفهوم أساسي: تأخير تنفيذ الكود.

في `:javascript`، يمكننا استخدام `:function` اسمها `:setTimeout` لتنفيذ كود بعد فترة زمنية محددة. انظر إلى هذا المثال الذي يطبع رسالة بعد ثانيتين (2000 ميلي ثانية):

```javascript
console.log("بدأت العملية...");

setTimeout(() => {
  console.log("تم استلام البيانات!");
}, 2000);

console.log("العملية مستمرة...");
```

> لاحظ كيف تُطبع "العملية مستمرة..." قبل "تم استلام البيانات!". هذا لأن `:setTimeout` لا توقف تنفيذ بقية الكود.
