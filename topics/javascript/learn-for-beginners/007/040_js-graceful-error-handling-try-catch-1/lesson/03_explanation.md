لحل هذه المشكلة، نستخدم ما يسمى بـ "شبكة الأمان البرمجية": كتلة `:try...catch`.

- **كتلة `:try`**: نضع الكود الذي قد يسبب خطأً داخلها.
- **كتلة `:catch`**: نضع الكود الذي نريد تنفيذه *فقط* في حال حدوث خطأ في كتلة `:try`.

بهذه الطريقة، إذا فشل الكود الموجود في `:try`، ينتقل التنفيذ مباشرة إلى `:catch` بدلاً من إيقاف البرنامج. 

```javascript
try {
  // جرب هذا الكود المحفوف بالمخاطر
  let result = riskyOperation(); 
  console.log("نجحت العملية!");
} catch (error) {
  // إذا حدث خطأ، نفذ هذا الكود
  console.log("فشلت العملية، ولكن البرنامج لم يتوقف!");
}
```
بإتقانك هذا المفهوم، أصبحت قادراً على كتابة كود أكثر صلابة وموثوقية.
