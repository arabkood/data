## لماذا `var` صندوق قديم وخطير؟

قبل `:let` و `:const`، كانت `:var` هي الطريقة الوحيدة لتعريف المتغيرات. لكن لديها مشكلة كبيرة تتعلق بـ"النطاق" (`:scope`).

تخيل أنك عرفت متغيرًا بـ `:var` داخل كتلة كود صغيرة (مثل حلقة `for`). تتوقع أن يبقى المتغير داخل تلك الكتلة، أليس كذلك؟

المشكلة أن `:var` "يتسرب" خارج كتلته، ويمكن الوصول إليه من أي مكان في الدالة. هذا يسبب أخطاء مربكة ويجعل تتبع المتغيرات صعبًا.

```javascript
for (var i = 0; i < 3; i++) {
  // ...
}
console.log(i); // يطبع 3! تسرب المتغير خارج الحلقة
```

لهذا السبب، `:let` و `:const` هما الخيار الأفضل دائمًا في جافاسكريبت الحديثة. إنهما يحترمان `:block scope`، مما يجعل كودك أكثر توقعًا وأسهل في الصيانة.
