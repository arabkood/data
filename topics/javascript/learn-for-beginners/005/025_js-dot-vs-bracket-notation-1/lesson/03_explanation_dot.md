# الطريقة الأولى: تدوين النقطة (`.`)

رائع! لقد استخدمت للتو **تدوين النقطة**.

إنها الطريقة الأكثر شيوعًا وسهولة للوصول إلى خصائص الـ`:object`.

```javascript
const car = {
  type: "Sedan",
  color: "Blue"
};

// للوصول للون السيارة
console.log(car.color); // Output: Blue
```

تذكرها هكذا: `objectName.propertyName`.

> لكن، ماذا لو كان اسم الخاصية غير تقليدي؟ مثلاً لو كان يحتوي على مسافة؟ هل ستعمل النقطة؟ لنرَ في التمرين التالي.
