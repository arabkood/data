# من الفوضى إلى الوضوح: شاهد الفرق

دعنا نصلح الكود الغامض من بداية الدرس باستخدام أسماء واضحة.

**قبل (صعب الفهم):**
```javascript
let a = 60;
let b = 40;
let c = a - b;
let d = c * 365;
```

**بعد (سهل الفهم):**
```javascript
const retirementAge = 60;
const currentAge = 40;
let yearsToRetirement = retirementAge - currentAge;
let daysToRetirement = yearsToRetirement * 365;
```

الآن الكود يشرح نفسه! يمكنك على الفور معرفة أننا نحسب عدد الأيام المتبقية للتقاعد. الأسماء الواضحة تحول الكود من مجرد ألغاز إلى قصة منطقية.

> بإتقانك لهذه المهارة، أنت الآن تبني أساسًا قويًا لكتابة تطبيقات معقدة وخالية من الأخطاء.
