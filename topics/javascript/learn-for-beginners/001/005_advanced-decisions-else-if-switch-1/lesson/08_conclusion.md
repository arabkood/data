# أصبحت صانع قرارات محترف!

تهانينا! لقد أضفت الآن أداتين قويتين لاتخاذ القرارات في جعبتك البرمجية:

- **`:else if`**: لإنشاء مسارات منطقية متسلسلة ومعقدة.
- **`:switch`**: لتنظيم الكود عندما تعتمد القرارات على قيمة متغير واحد.

أنت الآن جاهز للتعامل مع سيناريوهات برمجية أكثر تنوعًا وكتابة كود أكثر ذكاءً وفعالية.
