### كيف تفكر الآلة: `:if` و `:else`

رائع! لقد جعلت الكود الخاص بك يتخذ قرارًا. الأمر بسيط جدًا:

- **`if (شرط)`**: يسأل الكود سؤالاً. "هل هذا الشرط صحيح؟". إذا كانت الإجابة "نعم" (أي `true`)، فإنه ينفذ الكود الموجود بالداخل.

- **`else`**: هذه هي الخطة البديلة. إذا كانت إجابة السؤال "لا" (أي `false`)، فإن الكود يتجاهل كتلة `:if` وينفذ الكود الموجود داخل `:else`.

```javascript
let userAge = 20;

if (userAge >= 18) {
  console.log("مرحباً بك، يمكنك الدخول.");
} else {
  console.log("عذراً، الدخول للبالغين فقط.");
}
```

> قبل أن نكمل، ما الذي تتوقعه أن يحدث لو غيرنا `userAge` إلى `16`؟ فكر في الأمر!
