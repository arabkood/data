# مقدمة: لماذا نكرر أنفسنا؟

تخيل أنك تبني تطبيقًا يحتاج إلى جمع رقمين في أماكن مختلفة. قد تكتب:

```javascript
let sum1 = 5 + 10;
let sum2 = 20 + 30;
let sum3 = 100 + 50;
```

ألا يبدو هذا متكررًا؟ ماذا لو أردنا تغيير عملية الجمع إلى ضرب؟ سيتعين عليك تغيير كل سطر!

> قبل أن نكمل، ما الذي تتوقعه أن يكون الحل لهذه المشكلة؟ الحل يكمن في مفهوم برمجي قوي يسمح لنا بكتابة المنطق مرة واحدة واستخدامه في أي مكان.
