# تحدي التكامل: الآلة الحاسبة المتكاملة

لقد تعلمت الآن كيفية إنشاء منطق فردي قابل لإعادة الاستخدام. الخطوة التالية هي دمج هذه الدوال معًا لبناء آلة حاسبة بسيطة.

يمكنك الآن إنشاء دوال لـ `multiply` و `divide` بنفس الطريقة. من خلال تقسيم المشكلة الكبيرة (آلة حاسبة) إلى مشاكل أصغر (دوال فردية)، يصبح الكود أكثر قابلية للإدارة والفهم.
