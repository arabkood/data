# شرح: وصفتك البرمجية الخاصة - الـ `:function`

الـ `:function` (الدالة) هي مثل وصفة طبخ قابلة لإعادة الاستخدام في البرمجة. لديها:

1.  **اسم (Name):** لكي تتمكن من استدعائها (مثال: `add`).
2.  **مكونات (Parameters):** المدخلات التي تحتاجها الوصفة (مثال: `number1`, `number2`).
3.  **خطوات (Body):** الكود الذي يتم تنفيذه داخلها.
4.  **نتيجة (Return Value):** القيمة النهائية التي تعيدها الوصفة بعد التنفيذ.

```javascript
// تعريف الدالة
function add(number1, number2) {
  let sum = number1 + number2;
  return sum; // إعادة النتيجة
}
```

بإتقانك هذا المفهوم، أصبحت قادراً على تنظيم الكود وتجنب التكرار، وهي خطوة أساسية لتصبح مبرمجًا محترفًا.
