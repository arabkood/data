# ما هو الكلوجر (Closure)؟

ببساطة، الـ`:closure` هو عبارة عن `:function` تتذكر "بيئتها المعجمية" (`:lexical environment`) التي أُنشئت فيها. هذا يعني أنها تستطيع الوصول إلى المتغيرات من الدالة الخارجية التي تحتويها، حتى بعد انتهاء تنفيذ تلك الدالة الخارجية.

لنعد إلى مثال العداد. يمكننا إنشاء `:function` خارجية مهمتها فقط إنشاء العداد، وهذه الدالة ستُعيد `:function` داخلية أخرى هي العداد الفعلي.

```javascript
function createCounter() {
  let count = 0; // هذا المتغير جزء من بيئة createCounter

  // هذه الدالة الداخلية هي الكلوجر
  return function() {
    count++; // تستطيع الوصول إلى 'count' وتعديله
    return count;
  };
}

const myCounter = createCounter(); // استدعاء الدالة الخارجية
```

الآن، المتغير `myCounter` يحمل الدالة الداخلية. على الرغم من أن `createCounter` قد انتهى تنفيذها، إلا أن `myCounter` لا يزال "يتذكر" المتغير `count`. هذا هو سحر الكلوجر!
