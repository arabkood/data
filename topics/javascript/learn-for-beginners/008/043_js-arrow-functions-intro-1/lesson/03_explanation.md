## بنية دالة السهم الأساسية

رائع! لقد تعرفت على الشكل الجديد. لنفصل البنية:

1.  **المعاملات (Parameters)**: توضع داخل أقواس `()` مثل الدوال العادية.
2.  **السهم (The Arrow)**: نستخدم `=>` وهو ما يعطي هذه الدوال اسمها.
3.  **جسم الدالة (Function Body)**: يوضع داخل أقواس معقوفة `{}`.

مثال على دالة تجمع رقمين:

```javascript
// الطريقة التقليدية
const sum_old = function(a, b) {
  return a + b;
};

// باستخدام دالة السهم
const sum_new = (a, b) => {
  return a + b;
};
```

> بإتقانك لهذه البنية، أصبحت قادراً على كتابة كود :javascript حديث ومختصر!
