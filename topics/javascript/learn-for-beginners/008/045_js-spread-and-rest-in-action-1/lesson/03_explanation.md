# عامل التفريق (`...`) - الساحر الذي يفكك المجموعات

كما رأيت في التمرين، عامل التفريق (`:spread syntax`) `...` هو طريقة لنشر عناصر كيان قابل للتكرار (مثل `:array` أو `:string`) في الأماكن التي تتوقع فيها صفرًا أو أكثر من العناصر أو الوسائط.

**فكر فيه كأنه يفتح صندوقًا ويفرد محتوياته.**

```javascript
const arr1 = [1, 2, 3];

// إنشاء نسخة جديدة من المصفوفة
const arr2 = [...arr1]; // arr2 هي [1, 2, 3]

// إضافته كوسائط لدالة
const numbers = [4, 1, 9];
const max = Math.max(...numbers); // يعادل Math.max(4, 1, 9)
console.log(max); // يطبع 9
```

> بإتقانك هذا المفهوم، أصبحت قادراً على إنشاء نسخ من المصفوفات والكائنات ودمجها وتمريرها للدوال بكود أنظف وأكثر قابلية للقراءة.
