للدوال السهمية بعض الصيغ المختلفة المفيدة التي تعتمد على عدد `المُعاملات`.

1. **مُعامِل واحد:** الأقواس اختيارية.

```javascript
const greet = (name) => `أهلاً، ${name}`;
```

2. **بلا مُعاملات:** يجب استخدام أقواس فارغة `()`.

```javascript
const sayHello = () => "أهلاً وسهلاً!";
```

3. **أسطر متعددة:** إذا كانت دالتك تحتاج لأكثر من سطر، يجب استخدام **الأقواس المعقوفة** `{}` وكلمة `return` بشكل صريح.

```javascript
const getFullName = (firstName, lastName) => {
  const fullName = `${firstName} ${lastName}`;
  return `مرحباً بك، ${fullName}`;
};
```

**ركز على هذا وتذكر الصيغ الثلاثة لأنك ستراها كثيرًا**
