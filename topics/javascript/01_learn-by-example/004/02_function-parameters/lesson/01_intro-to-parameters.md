في مهمتنا السابقة، أنشأنا دوالاً تقوم بنفس الشيء في كل مرة. هذا مفيد جدًا، ولكن ماذا لو أردنا بعض التنوع؟

تخيّل أنك تطلب شاورما. أنت لا تقول فقط "أعطني طعامًا"، بل تحدد تعليماتك: `دجاج`، `صوص ثوم زيادة`، `بدون مخلل`.

يمكننا إعطاء دوالّنا تعليمات محددة أيضًا. نفعل ذلك عن طريق تحديد أماكن مخصصة تُسمى **المُعامِلات (`parameters`)**.

### لنرَ كيف

هنا، ننشئ دالة `greet` مع مكان مخصص اسمه `name`. هذا المكان المخصص هو `مُعامِل`.

```javascript
// المكان المخصص 'name' هو مُعامِل
function greet(name) {
  console.log("أهلاً، " + name + "!");
}
```

عندما نستدعي الدالة، نمرر لها قيمة حقيقية مثل `"لينا"`. هذه القيمة تُسمى **الوسيط (`argument`)**.

```javascript
greet("لينا");

// --- المخرجات ---
// أهلاً، لينا!
```
