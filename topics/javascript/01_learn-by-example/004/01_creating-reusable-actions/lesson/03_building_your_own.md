الآن إلى الجزء الممتع. **لنبنِ دالة خاصة بنا** من الصفر.

تذكر الهيكل:

1. الكلمة المفتاحية `function`
2. اسم فريد من اختيارك
3. `()`
4. الأقواس المعقوصة `{}` لوضع الشيفرة بداخلها

```javascript
// تعريف الدالة
function functionName() {
  // شيفرتك التي ستعمل توضع هنا
}

// يمكنك استدعاء دالتك عدة مرات بعد تعريفها
functionName();
functionName();
functionName();
```

هذا الهيكل هو مخططك الأساسي لإنشاء أي إجراء قابل للتكرار.
