ماذا يحدث لو نسينا علامات الاقتباس؟ هذا خطأ شائع، لذلك دعنا نستكشفه معًا.

انظر إلى هذا الكود. يحاول تخزين اسم بلد ولكن هناك شيء مفقود.

```javascript
// يا للخطأ!
let country = Cairo;

// هذا الكود سيُسبب خطأ!
```

يتعطّل البرنامج لأنه بدون علامات الاقتباس، يظن أن `Cairo` هو `متغيّر` آخر، وليس قطعة نصية.

**ضع دائمًا نصوصك بين علامتي اقتباس** لتعريفها كـ`سلسلة نصية`.
