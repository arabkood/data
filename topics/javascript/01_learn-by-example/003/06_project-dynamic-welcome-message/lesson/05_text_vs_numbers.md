يبدو أن الحاسوب قد ارتبك! لأن `age` تم تخزينه بين علامتي اقتباس، فقد تم التعامل معه كنص (`text`)، وليس كرقم (`number`).

عندما استخدمنا `+`، قامت جافاسكريبت بدمج النصوص معًا فقط. هذا أمر شائع جدًا في البرمجة.

لإصلاح هذا، نحتاج إلى تحويل النص إلى رقم قبل إجراء العمليات الحسابية. يمكننا استخدام دالة خاصة تسمى `parseInt()` للقيام بذلك.

```javascript
let ageAsString = "22";
let ageAsNumber = parseInt(ageAsString);

console.log(ageAsNumber + 5);
// المخرجات: 27
```
هذا أفضل بكثير! الآن يتم إجراء عملية حسابية.
