كنت أتساءل سابقًا إن كانت `المصفوفة` تستطيع احتواء نوع واحد فقط من البيانات، مثل **النصوص (`strings`)** أو **الأرقام (`numbers`)** فقط.

لكن اتضح أنها مرنة جدًا! يمكنك مزج أنواع بيانات مختلفة في نفس `المصفوفة`.

على سبيل المثال، لنخزّن معلومات الطالبة ليلى: اسمها، ودرجتها، وما إذا كانت طالبة جديدة.

```javascript
let studentLaila = ["Laila", 10, true];

console.log(studentLaila);
```

**النتيجة هي:**
```
[ 'Laila', 10, true ]
```
هذا يجمع بين `نص`، و`رقم`، و**قيمة منطقية (`boolean`)** في مكان واحد.
