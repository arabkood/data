أهم قاعدة للـ`ثابت` بسيطة: **لا يمكنك تغيير قيمته** بعد أن يتم تحديده.

ماذا يحدث لو حاولنا؟ لنرَ. هنا سنحاول تغيير قيمة باي (pi)، وهو ثابت رياضي شهير.

```javascript
const PI = 3.14159;
// محاولة تغيير القيمة
PI = 3.14;
```
هذه الشفرة ستتعطل وتُظهر خطأ!
`TypeError: Assignment to constant variable.`

هذا الخطأ مفيد في الواقع! فهو يمنعنا من تغيير بيانات مهمة في برنامجنا عن طريق الخطأ. إنها ميزة أمان.
