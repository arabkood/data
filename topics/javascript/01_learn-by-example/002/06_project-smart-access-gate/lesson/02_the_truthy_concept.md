في جافاسكريبت، لا يحتاج الشرط بالضرورة إلى قيمة `منطقية` (`boolean`) (أي `true` أو `false`). يمكنه تقييم قيم أخرى *كما لو* كانت صحيحة.

هذا هو مفهوم **القيمة الصائبة (`truthy`)**. تكون القيمة `صائبة` (`truthy`) إذا تصرفت مثل `true` عند استخدامها في شرط.

**شاهد المثال:**

```javascript
let userName = "Fatima";

if (userName) {
  console.log("مرحباً بك، " + userName);
}
```

**الناتج:**
```
مرحباً بك، Fatima
```

لاحظ أننا لم نستخدم مقارنة مثل `userName !== ""`. لأن المتغير `userName` يحتوي على نص غير فارغ، فإن جافاسكريبت تعامله على أنه **قيمة `صائبة`** وتشغّل الكود الموجود داخل كتلة `if`.
