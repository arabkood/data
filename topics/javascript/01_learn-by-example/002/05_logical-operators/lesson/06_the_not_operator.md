`!`: المُعامِل `NOT` (`ليس`)

أحيانًا نحتاج للتحقق مما إذا كان شيء ما `false`. المُعامِل `!` بسيط: وظيفته هي عكس **القيمة المنطقية (`boolean`)**.

إنه يحوّل `true` إلى `false`، و `false` إلى `true`. لنرَ ذلك عمليًا.

```javascript
let isDoorLocked = true;

// ما هو عكس قيمة `isDoorLocked`؟
console.log(!isDoorLocked);
```

**الناتج:**

```
false
```

هذا مفيد للتحقق من أمور مثل `if (!isAdmin)` لمعرفة ما إذا كان المستخدم **ليس** مديرًا للنظام.
