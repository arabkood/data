لدينا الآن المخطط، وهو **"مسار البرنامج (`program flow`)"**، والمواد الخام، وهي **"نمذجة البيانات (`data modeling`)"**. حان الوقت لبناء المحرك الذي يجعل كل هذا يعمل!

هنا سنقوم بترجمة خططنا إلى القلب النابض والمفكر لبرنامجنا. هذا ما يسمى **"تطبيق المنطق (`logic implementation`)"**.

لنبدأ بقاعدة بسيطة لنظام تقييم الدرجات في مدرسة. **إذا كانت درجة الطالب 90 أو أكثر، يكون تقديره 'ممتاز'.**

هكذا تبدو هذه القاعدة في الكود. لنكتشف هذا معًا!

```javascript
function calculateGrade(score) {
  if (score >= 90) {
    return "ممتاز";
  }
}

// لنجرّب الكود على طالب اسمه عمر
let omarScore = 95;
let omarGrade = calculateGrade(omarScore);

console.log(omarGrade);
```

**الناتج:**
```
ممتاز
```

أرأيت؟ جملة `if` هي الجزء الذي *يفكر* ويتخذ القرار. إنها جوهر المنطق لدينا. ✨
