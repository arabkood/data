محاولة رائعة في التمرين السابق! من الشائع أن يحدث التباس حول متى نستخدم القوسين `()`.

ماذا يحدث لو أضفناهما عن طريق الخطأ؟

```javascript
// هذه هي نفس الدالة من قبل
function sayMarhaba(name) {
  console.log("مرحباً، " + name + "!");
}

function performAction(name, action) {
  action(name);
}

// يا للخطأ! لقد استدعينا sayMarhaba() داخل الوسائط
performAction("يارا", sayMarhaba());
```

سيؤدي هذا إلى خطأ! 💥

الدالة `sayMarhaba()` تُنفّذ فورًا ولا تُرجع أي شيء. بعد ذلك، تستقبل الدالة `performAction` القيمة `undefined` بدلاً من دالة، فتتعطل الشفرة.

**مرّر دائمًا اسم الدالة كمرجع**، وليس نتيجة استدعائها.
