المتغير الذي يُصرَّح عنه خارج أي دالة يكون في **النطاق العام (`global scope`)**. إنه بمثابة إعلان عام في القاعة الرئيسية لمبناها، فكل الغرف يمكنها سماعه.

انظر إلى هذا المثال. المتغير `restaurantName` موجود في `النطاق العام`، لذا يمكن لدالتنا الوصول إليه بسهولة.

```javascript
// نطاق عام
const restaurantName = "بيت ستي";

function printWelcome() {
  // هذه الدالة يمكنها 'رؤية' المتغير العام
  console.log(`!أهلاً بك في ${restaurantName}`);
}

printWelcome();
```

**الناتج:**
```
!أهلاً بك في بيت ستي
```
