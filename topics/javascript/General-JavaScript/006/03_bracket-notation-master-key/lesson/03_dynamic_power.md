استخدام `الترميز بالأقواس` مع نص مثل `'location'` يعمل، لكنه يؤدي نفس وظيفة `الترميز النقطي`.

تكمن القوة الحقيقية في استخدام **متغيّر** داخل الأقواس.

تخيّل أن لديك متغيّرًا يحمل اسم الخاصية التي تريدها. يمكنك استخدام هذا المتغيّر للبحث عن القيمة بشكل ديناميكي!

```javascript
const student = {
  name: "Layla",
  grade: "A+"
};

let propertyToGet = "grade";

// هذا ينظر إلى القيمة الموجودة داخل propertyToGet
console.log(student[propertyToGet]);
```

**الناتج:**
```
A+
```
