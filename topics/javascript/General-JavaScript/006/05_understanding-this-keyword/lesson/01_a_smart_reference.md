### مدخل: مرجع ذكي

في درسنا السابق، أعطينا الكائنات إجراءات باستخدام **الدوال (`methods`)**. ولكن كيف تعرف الدالة إلى أي كائن تنتمي؟

تخيل أن لديك صديقين، عمر وليلى. إذا قال عمر "**طعامي** المفضل هو الكنافة"، فهو يتحدث عن نفسه. وإذا قالتها ليلى، فإن ياء المتكلم في "طعامي" تشير إليها.

في جافاسكريبت، تعمل **الكلمة المفتاحية `this` (`this` keyword)** تمامًا مثل ياء المتكلم. إنها مُعرِّف خاص يشير إلى الكائن الذي تعمل عليه الدالة حاليًا.

### لنرى الآن: الكلمة المفتاحية `this` قيد التنفيذ

لنلقِ نظرة على كائن لمطعم. بدون `this`، لن تعرف الدالة اسم أي مطعم يجب أن تحصل عليه.

باستخدام `this.name`، يمكن للدالة قراءة خاصية `name` من الكائن الخاص بها. لقد أصبح واعيًا بذاته!

```javascript
const restaurant = {
  name: "Foul w Hummus",
  location: "Amman",
  displayInfo: function() {
    // تشير 'this' إلى كائن 'restaurant'
    console.log(`${this.name} is located in ${this.location}.`);
  }
};

restaurant.displayInfo();

// المخرجات:
// Foul w Hummus is located in Amman.
```

استخدام `this` يجعل دوالنا مرنة وقوية. لنرَ كيف يمكننا استخدامها. 🤔
