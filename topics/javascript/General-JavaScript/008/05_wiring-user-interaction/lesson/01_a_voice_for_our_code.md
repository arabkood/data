في مهمتنا السابقة، بنينا 'عقل' برنامجنا—المنطق الأساسي. لكن العقل يظل صامتًا بدون صوت وأذنين!

لنمنح برنامجنا القدرة على التواصل. هذا ما يُسمى **'منطق تفاعل المستخدم' (`user interaction logic`)**.

---

تخيّل الأمر كأنه صاحب متجر ودود. الزبون (المستخدم) يقدم طلبًا (المدخلات)، وصاحب المتجر يرد بالتحية والأغراض (المخرجات).

يمكننا فعل ذلك باستخدام الدوال و `console.log`.

---

**شاهد كيف تعمل:** هذه الدالة تأخذ اسمًا وترحب به. إنها أبسط طريقة ليتمكن البرنامج من 'التحدث'.

```javascript
function greet(name) {
  // تطبع رسالة ترحيب مخصصة
  console.log("أهلاً، " + name + "!");
}

greet("فاطمة");
```

**الناتج:**
```
أهلاً، فاطمة!
```

لاحظ كيف تستخدم الدالة الـ `name` الذي تم تزويده لإنشاء رسالة مخصصة. لنجرّب هذا معًا.
