ممتاز! يمكننا الآن نمذجة بيانات ضيف واحد. لكن ماذا عن قائمة ضيوف كاملة لحفل زفاف أو مناسبة؟

بالنسبة لقوائم العناصر، نستخدم **"المصفوفة (`array`)"**. يمكننا إنشاء **مصفوفة من الكائنات** لتضم جميع ضيوفنا!

لاحظ الأقواس المربعة `[]` للقائمة والأقواس المعقوفة `{}` لكل ضيف بداخلها.

```javascript
let guestList = [
  {
    name: "ليلى",
    city: "القاهرة"
  },
  {
    name: "خالد",
    city: "عمّان"
  }
];

console.log(guestList);
```

**OUTPUT**
```
[ { name: 'ليلى', city: 'القاهرة' }, { name: 'خالد', city: 'عمّان' } ]
```
