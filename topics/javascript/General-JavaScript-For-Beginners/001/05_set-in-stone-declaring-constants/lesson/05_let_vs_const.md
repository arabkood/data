إذًا، متى نستخدم `let` ومتى نستخدم `const`؟

الاختيار بسيط: **هل ستحتاج هذه القيمة إلى التغيير؟**

- إذا كانت الإجابة نعم، استخدم `let`. (مثال: نقاط المستخدم الحالية، عدد المنتجات في سلة التسوق).
- إذا كانت الإجابة لا، استخدم `const`. (مثال: اسم شركة، نسبة ضريبة ثابتة).

تخيّل تطبيقًا لمطعم في بيروت.
```javascript
// اسم المطعم لن يتغير
const restaurantName = "Em Sherif Cafe";

// عدد الطاولات المتاحة يتغير باستمرار
let availableTables = 12;
```
