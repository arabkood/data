أتذكر كيف استخدمنا `let` لإنشاء 'صناديق ذاكرة' للمعلومات التي يمكن أن تتغير، مثل نقاط لعبة ما؟

ولكن ماذا عن المعلومات التي لا يجب أن تتغير *أبدًا*؟ فكّر في تاريخ ميلادك، أو عدد أيام الأسبوع.

لهذه الحالات، لدينا أداة خاصة تسمى `const`. هي تعرّف **ثابتًا (`constant`)**، وهو قيمة تُحفر في الصخر بمجرد إنشائها.

لنَرَها قيد التنفيذ. مدينة مكة المكرمة مركزية في الإسلام، وموقعها لا يتغير.
```javascript
const holyCity = "Mecca";
console.log(holyCity);
```
**المُخرجات:**
```
Mecca
```
استخدام `const` يشبه تقديم وعد للحاسوب بأن هذه القيمة لن يُعاد تعيينها. هيا بنا نجرب! 🤔
