عمل رائع! لقد بدأت تتقن إنشاء مسارات أكثر تعقيدًا لشفرتك.

إليك نصيحة مهمة: عند استخدام `else if`، فإن **ترتيب الشروط مهم جدًا**.

تتحقق جافاسكريبت منها من الأعلى إلى الأسفل وتتوقف عند أول شرط تكون نتيجته **صحيح (`true`)**.

انظر ماذا يحدث إذا تحققنا من الدرجة الأقل أولاً.

```javascript
let score = 95; 
// هذه الدرجة يجب أن تكون "ممتاز"

// ترتيب غير صحيح
if (score > 70) { 
  // هذا الشرط صحيح، لذا تتوقف الشفرة هنا!
  console.log("جيد");
} else if (score > 90) { 
  // هذا السطر لن يتم التحقق منه أبدًا
  console.log("ممتاز");
}

// المخرجات:
// جيد
```

لإصلاح هذا، تحقق دائمًا من **الشرط الأكثر تحديدًا أولاً** (مثل `> 90`) ثم انتقل إلى الشروط الأكثر عمومية (مثل `> 70`).
