تقوم دالة `.map()` بإنشاء **مصفوفة جديدة** عبر استدعاء دالة على كل عنصر في المصفوفة الأصلية.

لنَرَها قيد التنفيذ. لدينا مصفوفة من الأرقام، ونريد مضاعفة كل واحد منها.

```javascript
const numbers = [2, 5, 10];

// تخبر هذه الدالة `.map()` بما يجب فعله بكل 'num'
const doubledNumbers = numbers.map(num => num * 2);

console.log(doubledNumbers);
```

**الناتج:**
```
[4, 10, 20]
```

لاحظ أن مصفوفة `numbers` الأصلية لم تتغير. دالة `.map()` تُرجع دائمًا مصفوفة جديدة تمامًا.
