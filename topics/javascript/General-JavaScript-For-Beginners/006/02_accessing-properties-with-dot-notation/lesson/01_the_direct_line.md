في درسنا السابق، نظّمنا البيانات داخل `كائن` (`object`)، والذي يشبه خزانة ملفات رقمية. لكن كيف نفتح درجًا معينًا للحصول على المعلومة التي نحتاجها؟

هنا يأتي دور `ترميز النقطة` (`dot notation`). إنه خط مباشر يوصلك إلى معلومة محددة.

لنَرَ كيف يعمل. هذا كائن يمثّل طالبًا اسمه زيد.

```javascript
let student = {
  name: "Zayd",
  field: "Computer Science"
};

// للحصول على الاسم، نستخدم اسم الكائن، ثم نقطة، ثم اسم الخاصية
console.log(student.name);
```

**الناتج:**
```
Zayd
```

يبدو أن هذه النقطة `.` هي المفتاح! **حان دورك لتجرّب** هذا في الخطوة التالية. ✨
