الآن، ماذا لو صرّحنا عن متغير **داخل** دالة؟ هذا يُنشئ **نطاقًا محليًا (`local scope`)**. الأمر أشبه برسالة سرية تُمرَّر داخل غرفة خاصة، فلا أحد في الخارج يستطيع قراءتها.

لنجرب الوصول إلى متغير محلي من الخارج. برأيك ماذا سيحدث؟

```javascript
function createGreeting() {
  // نطاق محلي
  const greeting = "أهلاً وسهلاً!";
}

createGreeting();

// ...لنجرب الوصول إلى 'greeting' هنا في الخارج
console.log(greeting);
```

**الناتج:**
```
ReferenceError: greeting is not defined
```

مدهش! يتعطل البرنامج لأن المتغير `greeting` محبوس داخل جدران الدالة. وهذا أمر جيد، فهو يمنع متغيراتنا من التسبب بمشاكل عرضية في أماكن أخرى.
