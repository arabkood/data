أتتذكر كيف استخدمنا **المتغيرات (`variables`)** لتخزين معلومات مثل الاسم؟ هذا يشبه تذكر مكون واحد في وصفة.

الآن، تخيل أن لديك وصفة، مثل تحضير الشاي لصديقك عمر. أنت تتبع نفس الخطوات في كل مرة. **الدالة (`function`)** في البرمجة تشبه تلك الوصفة تمامًا: مجموعة محفوظة من التعليمات.

### لنرَ مثالاً

هكذا ننشئ أمر ترحيب بسيط. هذا يسمى **تعريف الدالة**.

```javascript
function greet() {
  console.log("أهلاً! مرحبًا بك في أكوود.");
}
```

لتشغيل أمرنا، **نستدعي الدالة** باسمها، متبوعًا بقوسين.

```javascript
greet();
```

### المخرجات

```
أهلاً! مرحبًا بك في أكوود.
```

هذا رائع! تعريف `الدالة` يشبه تدوين الوصفة، واستدعاؤها يشبه تحضير الشاي فعليًا. لنجرب ذلك معًا.
