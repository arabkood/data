لقد بنينا 'مخططات' قوية للدوال. لكن ماذا لو كانت هناك طريقة أسرع وأقصر لكتابتها؟

فكّر فيها كاختصار في رسالة نصية مقابل بريد إلكتروني كامل. كلاهما يفي بالغرض، لكن أحدهما أسرع بكثير للرسائل البسيطة.

**الدوال السهمية (`Arrow functions`)** هي اختصار الرسائل النصية في عالم الأكواد. لنرَ كيف تُقارن بالدوال التي نعرفها بالفعل.

**دالة عادية:**
```javascript
function add(a, b) {
  return a + b;
}
```

**دالة سهمية:**
```javascript
const add = (a, b) => a + b;
```

هل ترى كم هي أنقى؟ اختفت الكلمة المفتاحية `function`، وحلّ السهم `=>` محل `return` في الدوال البسيطة ذات السطر الواحد. لنتعمق في التفاصيل.
