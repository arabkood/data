## تخيل أن الحاسوب يعد لك من 1 إلى 100...

في هذا الدرس، ستتعلم كيف تطلب من الحاسوب تكرار مهمة معينة عدة مرات دون أن تضطر لكتابة نفس الكود مراراً وتكراراً.

سنستكشف:

- ما هي **الحلقات** (`:loops`)
- كيفية استخدام `:for` للعد والتكرار
- كيفية استخدام `:while` للتكرار بشرط
- أمثلة عملية مثل إطلاق الصاروخ 🚀

إليك مثال بسيط لما سنتعلمه:

```javascript
console.log("استعداد لإطلاق الصاروخ...");
for (let countdown = 5; countdown >= 1; countdown--) {
  console.log(`${countdown}...`);
}
console.log("🚀 انطلق الصاروخ!");
```

**النتيجة:**

```
استعداد لإطلاق الصاروخ...
5...
4...
3...
2...
1...
🚀 انطلق الصاروخ!
```
