## لماذا نحتاج للحلقات؟

تخيل أنك تريد طباعة الأرقام من 1 إلى 10. بدون **الحلقات** (`:loops`)، ستحتاج لكتابة 10 أسطر منفصلة:

```javascript
// طريقة مملة ومتكررة ❌
console.log(1);
console.log(2);
console.log(3);
console.log(4);
console.log(5);
console.log(6);
console.log(7);
console.log(8);
console.log(9);
console.log(10);
```

ولكن مع **الحلقات**، يمكنك كتابة 3 أسطر فقط:

```javascript
// طريقة ذكية وبسيطة ✅
for (let i = 1; i <= 10; i++) {
  console.log(i);
}
```

**الحلقات** تجعل الكود:

- أقصر وأوضح
- أسهل في التعديل (لو أردت العد إلى 100 بدلاً من 10)
- أقل عرضة للأخطاء

**الحلقة** هي طريقة لإخبار الحاسوب: "كرر هذا العمل عدة مرات حتى يتحقق شرط معين."
