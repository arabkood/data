## حلقة `:while`: التكرار بشرط

**حلقة `:while` تستمر في التكرار طالما أن شرطاً معيناً **صحيح\*\* (`:true`). إنها مفيدة عندما لا تعرف بالضبط كم مرة ستحتاج للتكرار.

## البنية الأساسية

```javascript
while (الشرط) {
  // الكود الذي سيتكرر
}
```

## مثال بسيط: العد من 1 إلى 3

```javascript
let number = 1;

while (number <= 3) {
  console.log(`الرقم: ${number}`);
  number++; // مهم جداً! لا تنس زيادة المتغير
}
```

**النتيجة:**

```
الرقم: 1
الرقم: 2
الرقم: 3
```

## ⚠️ تحذير مهم: الحلقة اللانهائية

إذا نسيت تحديث المتغير، ستحصل على حلقة لا تتوقف أبداً:

```javascript
let x = 1;
while (x <= 3) {
  console.log(x);
  // نسيت كتابة x++
  // الحلقة ستستمر إلى الأبد! ❌
}
```

**تأكد دائماً من تحديث المتغير داخل الحلقة!**

## مثال: لعبة التخمين البسيطة

```javascript
let secretNumber = 7;
let guess = 1;

while (guess !== secretNumber) {
  console.log(`محاولة: ${guess}`);
  guess++;
}
console.log(`وجدت الرقم السري: ${secretNumber}!`);
```
