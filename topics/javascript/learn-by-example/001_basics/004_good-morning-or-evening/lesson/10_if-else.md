# فهم if else للمبتدئين

## ما هي الجملة الشرطية؟

**الجملة الشرطية** هي مثل سؤال يطرحه الحاسوب على نفسه، ثم يتخذ قراراً بناءً على الإجابة.

تخيل أنك تقف أمام باب بيتك وتسأل نفسك:

> "هل معي المفتاح؟"

- إذا كانت الإجابة **نعم** → ادخل البيت
- إذا كانت الإجابة **لا** → اطرق الباب

هذا بالضبط ما يفعله `if else`!

## البنية الأساسية

```javascript
if (شرط) {
  // ما يحدث إذا كان الشرط صحيح
} else {
  // ما يحدث إذا كان الشرط خاطئ
}
```

## مثال بسيط: العمر

```javascript
let age = 16;

if (age >= 18) {
  console.log("يمكنك القيادة!");
} else {
  console.log("انتظر حتى تبلغ 18 سنة");
}
```

**النتيجة**: `"انتظر حتى تبلغ 18 سنة"` لأن 16 أقل من 18.

## مثال آخر: الطقس

```javascript
let weather = "ممطر";

if (weather === "مشمس") {
  console.log("اذهب إلى الشاطئ!");
} else {
  console.log("ابق في البيت");
}
```

**النتيجة**: `"ابق في البيت"` لأن الطقس ليس مشمساً.

## أنواع الشروط البسيطة

```javascript
let x = 10;
let y = 5;

// أكبر من
if (x > y) {
  console.log("x أكبر");
}

// أقل من
if (x < y) {
  console.log("x أقل");
}

// يساوي
if (x === y) {
  console.log("x يساوي y");
}
```
