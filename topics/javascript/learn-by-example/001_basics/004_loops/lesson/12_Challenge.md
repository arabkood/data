## تحدي الممارسة: أنشئ برنامج "مؤقت الطماطم" 🍅

الآن حان دورك لتطبيق ما تعلمته! سنبني برنامج بسيط يحاكي مؤقت دراسة.

## التحدي الأول: مؤقت بسيط

اكتب حلقة تعد تنازلياً من 5 إلى 1، ثم تطبع "وقت الاستراحة!"

**النتيجة المطلوبة:**

```
⏰ بدء جلسة التركيز...
5 دقائق متبقية
4 دقائق متبقية
3 دقائق متبقية
2 دقائق متبقية
1 دقيقة متبقية
🎉 وقت الاستراحة!
```

## التحدي الثاني: دورات متعددة

اكتب برنامج يشغل 3 دورات دراسة، كل دورة تستمر 3 "دقائق"

**النتيجة المطلوبة:**

```
📚 بدء الدورة 1
3 دقائق...
2 دقائق...
1 دقيقة...
✅ انتهت الدورة 1

📚 بدء الدورة 2
3 دقائق...
2 دقائق...
1 دقيقة...
✅ انتهت الدورة 2

📚 بدء الدورة 3
3 دقائق...
2 دقائق...
1 دقيقة...
✅ انتهت الدورة 3

🏆 تم إنجاز جميع الدورات!
```

## نصائح للحل:

- استخدم حلقة `for` خارجية للدورات
- استخدم حلقة `for` داخلية للعد التنازلي
- لا تنس استخدام `:template literals` لإدراج الأرقام في النصوص
