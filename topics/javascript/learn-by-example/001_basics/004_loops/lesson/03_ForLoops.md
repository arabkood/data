## حلقة `for`: العد المنتظم

**حلقة `:for`** هي الأكثر استخداماً عندما تعرف بالضبط كم مرة تريد تكرار شيء معين.

## البنية الأساسية

```javascript
for (البداية; الشرط; التحديث) {
  // الكود الذي سيتكرر
}
```

## مثال بسيط: العد من 1 إلى 5

```javascript
for (let i = 1; i <= 5; i++) {
  console.log(`الرقم: ${i}`);
}
```

**النتيجة:**

```
الرقم: 1
الرقم: 2
الرقم: 3
الرقم: 4
الرقم: 5
```

## تفكيك الحلقة

دعنا نفهم كل جزء:

1. **البداية** (`let i = 1`): ننشئ متغير `i` ونبدأ من الرقم 1
2. **الشرط** (`i <= 5`): نستمر طالما أن `i` أقل من أو يساوي 5
3. **التحديث** (`i++`): في نهاية كل تكرار، نزيد `i` بواحد

## مثال: العد العكسي

```javascript
for (let countdown = 3; countdown >= 1; countdown--) {
  console.log(`${countdown}...`);
}
console.log("انتهى!");
```

**النتيجة:**

```
3...
2...
1...
انتهى!
```

هنا استخدمنا `countdown--` للعد العكسي (تقليل الرقم بواحد).
