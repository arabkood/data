# الشرط المتدرج: else if

لاحظت من المثال السابق أن استخدام عدة شروط `:if` منفصلة أدى لطباعة أكثر من نتيجة؟ هذا لأن الحاسوب فحص كل شرط بشكل منفصل.

هنا يأتي دور **else if** - وهو الطريقة الأفضل للتعامل مع الشروط المتدرجة.

**else if** مثل طرح أسئلة متتالية: إذا كان الجواب الأول "لا"، نسأل سؤالاً ثانيًا، وهكذا.

## الطريقة الصحيحة

```javascript
let grade = 85;

if (grade >= 90) {
  console.log("ممتاز!");
} else if (grade >= 80) {
  console.log("جيد جداً!");
} else if (grade >= 70) {
  console.log("جيد!");
} else {
  console.log("يحتاج تحسين");
}

// النتيجة: "جيد جداً!" فقط
```

**الفرق الأساسي**: مع `:else if`، بمجرد أن يجد شرطًا صحيحًا، ينفذه ويتوقف. لا يفحص باقي الشروط!
