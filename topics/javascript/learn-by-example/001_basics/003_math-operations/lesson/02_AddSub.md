## ➕ الجمع و ➖ الطرح

لنبدأ بالعمليتين الأساسيتين: الجمع والطرح. جافاسكريبت تتعامل معهما تمامًا كما تتوقع!

### 1. الجمع (`+`)

تستخدم علامة `+` لجمع رقمين أو أكثر.

```javascript
let apples = 5;
let oranges = 3;
let totalFruits = apples + oranges; // الناتج سيكون 8

console.log("لدي " + apples + " تفاحات.");
console.log("ولدي " + oranges + " برتقالات.");
console.log("إجمالي الفواكه: " + totalFruits); // إجمالي الفواكه: 8

let score1 = 10;
let score2 = 20;
let score3 = 5;
let totalScore = score1 + score2 + score3;
console.log("النتيجة النهائية: " + totalScore); // النتيجة النهائية: 35
```

> 💡 **ملاحظة سريعة**: علامة `+` تُستخدم أيضاً لدمج النصوص (كما رأينا في `console.log` أعلاه)، لكن عندما تكون بين رقمين، فإنها تقوم بعملية الجمع الحسابي.

### 2. الطرح (`-`)

تستخدم علامة `-` لطرح رقم من آخر.

```javascript
let budget = 100;
let expense = 30;
let remaining = budget - expense; // الناتج سيكون 70

console.log("كان معي: " + budget + " ريال.");
console.log("صرفت منها: " + expense + " ريال.");
console.log("المتبقي معي: " + remaining + " ريال."); // المتبقي معي: 70

let initialTemperaure = 25;
let drop = 5;
let finalTemperature = initialTemperaure - drop;
console.log("الحرارة النهائية: " + finalTemperature + " درجة."); // الحرارة النهائية: 20 درجة.
```

سهل جداً، أليس كذلك؟ هيا نختبر معلوماتك!
