## Line 4: Store Your Name

This one's simple. We're telling the computer to store the text `Muhammad` in a `constant` called `yourName`.

```javascript
const yourName = "Muhammad";
```

### How Does JavaScript Know It's Text?

JavaScript knows `"Muhammad"` is a `string` (text) because it's wrapped in `"quotation marks"`.

If you forget the quotes, the computer gets confused and throw an `error`.

### Fun && Important Fact

You can use any of these to define a `string` in JavaScript:

- Double quotes: `"Muhammad"`
- Single quotes: `'Muhammad'`
- Backticks: `` `Muhammad` ``

They all work the same most of the time, but backticks have extra features, which we’ll see later!
