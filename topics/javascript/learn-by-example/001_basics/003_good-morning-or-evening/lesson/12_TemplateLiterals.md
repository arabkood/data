## ما هي Template Literals؟

**النصوص المتقدمة** هي طريقة أسهل وأذكى لكتابة النصوص في جافاسكريبت. بدلاً من استخدام علامتي التنصيص العاديتين `"` أو `'`، نستخدم **العلامتين الخلفيتين** `` ` ``.

## الطريقة القديمة vs الطريقة الجديدة

### الطريقة القديمة (صعبة):

```javascript
let name = "أحمد";
let age = 25;
let message = "اسمي " + name + " وعمري " + age + " سنة";
console.log(message); // اسمي أحمد وعمري 25 سنة
```

### الطريقة الجديدة (أسهل):

```javascript
let name = "أحمد";
let age = 25;
let message = `اسمي ${name} وعمري ${age} سنة`;
console.log(message); // اسمي أحمد وعمري 25 سنة
```

## كيف تعمل؟

داخل العلامتين الخلفيتين، يمكنك وضع أي متغير أو عملية حسابية داخل `${...}`:

```javascript
let price = 100;
let tax = 15;

console.log(`السعر: ${price} ريال`);
console.log(`الضريبة: ${tax} ريال`);
console.log(`المجموع: ${price + tax} ريال`);
```

**النتيجة**:

```
السعر: 100 ريال
الضريبة: 15 ريال
المجموع: 115 ريال
```

## مثال من درسنا السابق

تذكر هذا الكود؟

```javascript
console.log(`صباح الخير, ${yourName}!`);
```

هنا استخدمنا `:template literals` لإدراج قيمة `yourName` داخل الرسالة بسهولة!

> ️ **انتبه**: تأكد من استخدام العلامة الخلفية `` ` `` وليس علامة التنصيص العادية `"`.
