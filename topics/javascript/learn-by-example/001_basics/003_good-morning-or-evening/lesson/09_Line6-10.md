## الأسطر 6-10: اتخاذ قرار

```javascript
if (hour < 12) {
  console.log(`صباح الخير، ${yourName}!`);
} else {
  console.log(`مساء الخير، ${yourName}!`);
}
```

الحاسوب يتحقق من هذا الشرط:

- هل `hour` أقل من `12`؟

هذا ما يُسمى **جملة شرطية** (`:conditional statement`)، وهي من أهم المفاهيم في البرمجة.

- إذا كان الشرط **صحيحاً** (`:true`)، يشغّل الحاسوب الكتلة الأولى داخل `{}`:

  ```javascript
  console.log(`صباح الخير، ${yourName}!`);
  ```

- إذا كان الشرط **خاطئاً** (`:false`)، يتجاهل الكتلة الأولى وينتقل إلى كتلة `else {}` ويشغّل:
  ```javascript
  console.log(`مساء الخير، ${yourName}!`);
  ```

### يمكنك التفكير في هذا كقرار بسيط:

- إذا كان الوقت قبل الظهر (`hour < 12`)، قل "صباح الخير".
- وإلا، قل "مساء الخير".
