## How the `console.log()` works

`console.log()` is a built-in JavaScript `function` that tells the computer to display something in the `console` (the place where you see output when you run code).

### Example 1:

```javascript
console.log("أهلا!");
```

will print this in the `console`:

```
أهلا!
```

### Example 2:

```javascript
const message = "أهلا!";
console.log(message);
```

will also print this in the `console`:

```
أهلا!
```

### We mostly use `console.log()` for:

- Showing messages to the developer
- Checking values while debugging
- Logging errors or status updates

In our program, it's used to greet the user based on the current time.
