تمتلك جافاسكربت ثلاثة أنواع بيانات (`:type`) أساسية تحتفظ بأنواع مختلفة من المعلومات:

- **`:string`**: وهو **نص** محاط بعلامات اقتباس مثل: `"Hello World"`
- **`:number`**: وهو **رقم**، أعداد بدون علامات اقتباس مثل: `42` أو `3.14`
- **`:boolean`**: وهي **قيمة منطقية**، وتكون إما `:true` أو `:false`

## أمثلة من الواقع

**بيانات شخص:**

```javascript
// string نص
let name = "محمد";
// number رقم
let age = 12;
// boolean قيمة منطقية
let isStudent = true;
```

**بيانات كتاب:**

```javascript
// string نص
let title = "المدينة الغامضة";
// number رقم
let pages = 364;
// boolean قيمة منطقية
let isForKids = false;
```

## نقاط رئيسية للتذكر

- البيانات من النوع `:string` تحتاج إلى علامات اقتباس:

  - `"نص"`
  - `'نص'`
  - `` `نص` ``

- البيانات من النوع `:number` لا تستخدم علامات اقتباس أبدًا:

  - `10`
  - `3.14`
  - `-20`

- البيانات من النوع `:boolean` هي بالضبط الكلمتان `:true` أو `:false` بدون علامات اقتباس:
  - `true`
  - `false`

> [!NOTE]
> انتبه دائمًا إلى **نوع** (`:type`) البيانات التي تعمل معها — فهو يؤثر على كيفية استخدامك لهذه البيانات ومعالجتها في برامجك!
