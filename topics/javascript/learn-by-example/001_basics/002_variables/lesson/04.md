# أنواع البيانات الأساسية

تمتلك `JavaScript` ثلاثة أنواع بيانات (`:type`) أساسية تحتفظ بأنواع مختلفة من المعلومات:

- **`string`**: وهو `:string`، نص محاط بعلامات اقتباس مثل: `"Hello World"`
- **`number`**: وهو **رقم**، أعداد بدون علامات اقتباس مثل: `42` أو `3.14`
- **`boolean`**: وهي `:boolean`، وتكون إما `true` أو `false`

## أمثلة من الواقع

**بيانات شخص:**

```javascript
let name = "محمد"; // string
let age = 12; // number
let isStudent = true; // boolean
```

**بيانات كتاب:**

```javascript
let title = "المدينة الغامضة"; // string
let pages = 364; // number
let isForKids = false; // boolean
```

## نقاط رئيسية للتذكر

- البيانات من النوع `string` (`:string`) تحتاج إلى علامات اقتباس (`"نص"` أو `'نص'` أو `` `نص` ``).
- البيانات من النوع `number` (الأرقام) لا تستخدم علامات اقتباس أبدًا (`25`، وليس `"25"`).
- البيانات من النوع `boolean` (`:boolean`) هي بالضبط الكلمتان `true` (`:true`) أو `false` (`:false`) بدون علامات اقتباس.
- **نوع البيانات** (`:type`) يحدد ما يمكنك فعله بالقيمة.

> [!IMPORTANT]
> انتبه دائمًا إلى **نوع** البيانات التي تعمل معها — فهو يؤثر على كيفية استخدامك لهذه البيانات ومعالجتها في برامجك!
