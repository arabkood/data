# JavaScript Basic Data Types

JavaScript has three fundamental data types that hold different kinds of information:

- **`string`** — Text wrapped in quotes: `"Hello World"`
- **`number`** — Numbers without quotes: `42` or `3.14`
- **`boolean`** — True or false values: `true` or `false`

## Real-World Examples

**Person Data:**

```javascript
let name = "Tom"; // string
let age = 12; // number
let isStudent = true; // boolean
```

**Book Data:**

```javascript
let title = "المدينة الغامضة"; // string
let pages = 364; // number
let isForKids = false; // boolean
```

## Key Points to Remember

- Strings need quotes (`"text"` or `'text'` or `` `text` ``)
- Numbers never use quotes (`25`, not `"25"`)
- Booleans are exactly `true` or `false` (no quotes)
- The data type determines what you can do with the value

> [!IMPORTANT]
> Always pay attention to the type of data you’re working with — it affects how you can use and manipulate that data in your programs!
