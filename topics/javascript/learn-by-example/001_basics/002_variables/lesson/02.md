**المتغيرات** (`variable`) هي مثل صناديق تحمل اسمًا معينًا داخل برنامجك، تُخزن بداخلها البيانات والمعلومات. تتيح لك هذه الصناديق إمكانية حفظ المعلومات، واسترجاعها، وتغييرها في أي وقت خلال تنفيذ البرنامج، مما يجعلها عنصرًا أساسيًا لإدارة البيانات في البرمجة.

## إنشاء المتغيرات

استخدم **الكلمة المحجوزة** (`keyword`) `let` أو `const` لإنشاء `:variable`:

```javascript
let age; // متغير فارغ
let name = "محمد"; // متغير يحمل اسم محمد
```

## استخدام المتغيرات

بمجرد إنشائها، يمكنك استخدام اسم `:variable` للوصول إلى قيمته:

```javascript
let message = "Hello World";
console.log(message); // يطبع: Hello World
```

## تغيير قيم المتغيرات

يمكنك تحديث ما هو مخزن في `:variable` من نوع `let`:

```javascript
let score = 10; // الآن يحتوي على 10
score = 15; // الآن يحتوي على 15
score = score + 5; // الآن يحتوي على 20
```

## قواعد تسمية المتغيرات

- يجب أن تبدأ بحرف، أو شرطة سفلية (`_`)، أو علامة الدولار (`$`)
- يمكن أن تحتوي على حروف، وأرقام، وشرطات سفلية، وعلامات الدولار
- لا يمكن أن تكون من **الكلمات المحجوزة** (`keyword`) في `JavaScript` مثل `let`، `if`، `for`
- حساسة لحالة الأحرف: `name` و `Name` هما متغيران مختلفان

**أمثلة جيدة:** `userName`، `total_score`، `isReady`، `$price`
**أمثلة سيئة:** `user-name`، `let`، `total score`, `2fast`
