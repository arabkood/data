# JavaScript Variables

Variables are like labeled boxes that store information in your program. You can put data inside them, use that data later, and even change what's stored inside.

## Creating Variables

Use the `let` or `const` keyword to create a variable:

```javascript
let age; // Creates an empty variable called 'age'
let name = "Tom"; // Creates a variable with initial value
```

## Using Variables

Once created, you can use the variable name to access its value:

```javascript
let message = "Hello World";
console.log(message); // Prints: Hello World
```

## Changing Variable Values

You can update what's stored in a `let` variable:

```javascript
let score = 10;
score = 15; // Now score contains 15
score = score + 5; // Now score contains 20
```

## Variable Names Rules

- Must start with a letter, underscore (\_), or dollar sign ($)
- Can contain letters, numbers, underscores, and dollar signs
- Cannot be JavaScript keywords like `let`, `if`, `for`
- Case-sensitive: `name` and `Name` are different variables

**Good examples:** `userName`, `total_score`, `isReady`, `$price`
**Bad examples:** `2fast`, `my-name`, `let`, `class`
