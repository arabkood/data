# JavaScript Variables and Output

In this lesson, you'll learn the basics of a simple JavaScript program. We'll explore:

- What variables are
- Common data types
- How to output information using `console.log`

Here's a code we'll be working with today:

```javascript
let name = "محمد";
let age = 19;
let isMale = true;

console.log("My name is " + name);
console.log("My age is " + age);
console.log("I'm a male: " + isMale);
```

## 💡 Try It Yourself

Don't just wait for explanations — Learning by doing is one of the most effective ways to understand programming.

A reminder on how to run the code:

1. Copy the code into a file on your computer (e.g., profile.js)
2. Open your terminal or command prompt
3. Navigate to the folder containing your file
4. Run the program using the command:

```bash
node profile.js
```
