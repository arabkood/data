في هذا الدرس، ستتعلم أساسيات برنامج بسيط. سوف نستكشف:

- ما هي **المتغيرات** (`variable`)
- **أنواع البيانات** (`type`) الشائعة
- كيفية طباعة المعلومات باستخدام `console.log`

إليك الكود الذي سنعمل عليه اليوم:

```javascript
let name = "محمد";
let age = 19;
let isMale = true;

console.log("My name is " + name);
console.log("My age is " + age);
console.log("I'm a male: " + isMale);
```

## 💡 جرب بنفسك

لا تنتظر الشرح فقط — التعلم بالممارسة هو أحد أكثر الطرق فعالية لفهم البرمجة.

حاول تعديل القيم أو إضافة أسطر جديدة، على سبيل المثال:

- غيّر الاسم أو العمر
- غيّر `isMale` الى `false`
- أضف `:variable` آخر مثل `let hobby = "coding";` و اطبعه
