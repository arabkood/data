`console.log()` هي نافذتك لمعرفة ما يحدث في الكود الخاص بك. تعرض هذه الدالة معلومات في `:console` (`console`) الخاصة بالمتصفح (أو `terminal` في حالة `Node.js`)، مما يساعدك على رؤية القيم، و**تصحيح الأخطاء** (`debug`)، وفهم كيفية عمل برنامجك.

```javascript
console.log("مرحبا"); // يطبع: مرحبا
console.log(42); // يطبع: 42
console.log(true); // يطبع: true
```

## عرض المتغيرات

يمكنك إظهار ما هو مخزن في `variable`:

```javascript
let name = "هانا";
let age = 25;

console.log(name); // يطبع: هانا
console.log(age); // يطبع: 25
```

## قيم متعددة

اطبع عدة أشياء مرة واحدة عن طريق فصلها بفواصل:

```javascript
let score = 100;
console.log("Your score is:", score); // يطبع: Your score is: 100

let x = 5;
let y = 10;
console.log("x =", x, "and y =", y); // يطبع: x = 5 and y = 10
```
