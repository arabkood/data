# JavaScript console.log

`console.log()` is your window into what's happening in your code. It displays information in the browser's console, helping you see values, debug problems, and understand how your program works.

## Basic Usage

```javascript
console.log("Hello World"); // Prints: Hello World
console.log(42); // Prints: 42
console.log(true); // Prints: true
```

## Displaying Variables

You can show what's stored in variables:

```javascript
let name = "Sarah";
let age = 25;

console.log(name); // Prints: Sarah
console.log(age); // Prints: 25
```

## Multiple Values

Print several things at once by separating them with commas:

```javascript
let score = 100;
console.log("Your score is:", score); // Prints: Your score is: 100

let x = 5;
let y = 10;
console.log("x =", x, "and y =", y); // Prints: x = 5 and y = 10
```

## Helpful for Learning

Use `console.log()` to understand what your code is doing:

```javascript
let total = 10;
console.log("Starting total:", total); // Prints: Starting total: 10

total = total + 5;
console.log("After adding 5:", total); // Prints: After adding 5: 15
```
