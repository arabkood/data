## Line 6-10: Make a Decision

```javascript
if (hour < 12) {
  console.log(`Good morning, ${yourName}!`);
} else {
  console.log(`Good evening, ${yourName}!`);
}
```

The computer checks this condition:

> Is `hour` less than `12`?

This is called a `conditional statement`, and it's one of the most important concepts in programming.

- If the condition is `true`, the computer runs the first block inside the `{}`:

  ```javascript
  console.log(`Good morning, ${yourName}!`);
  ```

- If the condition is `false`, it skips to the `else {}` block and runs:
  ```javascript
  console.log(`Good evening, ${yourName}!`);
  ```

### You can think of this like a simple decision:

- If it's before noon (`hour < 12`), say "Good morning".
- Otherwise, say "Good evening".
