اكتب دالة باسم `matrixRowSum` تأخذ مصفوفة (قائمة من القوائم) وتُرجع قائمة تحتوي على مجموع كل صف.

**المطلوب:**

- الدالة تأخذ معامل واحد: `matrix` (list of lists)
- كل صف هو قائمة من الأرقام
- الدالة تُرجع قائمة تحتوي على مجموع كل صف
- إذا كانت المصفوفة فارغة، أرجع قائمة فارغة

**مثال:**

```python
matrixRowSum([[1, 2, 3], [4, 5, 6]])           # يُرجع: [6, 15]
matrixRowSum([[1, 2], [3, 4], [5, 6]])         # يُرجع: [3, 7, 11]
matrixRowSum([[10]])                           # يُرجع: [10]
matrixRowSum([])                               # يُرجع: []
matrixRowSum([[1, 2, 3]])                      # يُرجع: [6]
```
