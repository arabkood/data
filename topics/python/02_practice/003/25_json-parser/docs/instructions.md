اكتب دالة باسم `parseSimpleJSON` تأخذ نص JSON بسيط (يحتوي على قاموس واحد فقط) وتحوله إلى قاموس Python.

فقط ادعم:
- مفاتيح نصية
- قيم نصية أو أرقام
- لا يوجد قوائم أو قواميس متداخلة

**المطلوب:**

- الدالة تأخذ معامل واحد: `json_str` (نص JSON)
- الدالة تُرجع قاموس Python
- JSON يبدأ بـ `{` وينتهي بـ `}`
- المفاتيح والقيم النصية محاطة بعلامات اقتباس مزدوجة
- الأزواج مفصولة بفواصل

**مثال:**

```python
parseSimpleJSON('{"name": "Ali", "age": 25}')
# {"name": "Ali", "age": 25}

parseSimpleJSON('{"x": 10}')
# {"x": 10}

parseSimpleJSON('{}')
# {}
```
