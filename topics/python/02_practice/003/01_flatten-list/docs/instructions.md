اكتب دالة باسم `flattenList` تأخذ قائمة متداخلة (قد تحتوي على عناصر أو قوائم أخرى على أي عمق) وتُرجع قائمة مسطحة تحتوي على جميع العناصر.

**المطلوب:**

- الدالة تأخذ معامل واحد: `nested_list` (list)
- القائمة قد تحتوي على أرقام، نصوص، أو قوائم أخرى
- يجب التعامل مع التداخل العميق (قوائم داخل قوائم داخل قوائم...)
- الدالة تُرجع قائمة مسطحة تحتوي على جميع العناصر الأساسية بنفس الترتيب
- استخدم التكرار الذاتي (recursion) لحل المشكلة

**مثال:**

```python
flattenList([1, [2, 3], 4])                    # يُرجع: [1, 2, 3, 4]
flattenList([1, [2, [3, 4]], 5])               # يُرجع: [1, 2, 3, 4, 5]
flattenList([[1, 2], [3, [4, [5]]]])           # يُرجع: [1, 2, 3, 4, 5]
flattenList([])                                # يُرجع: []
flattenList([1, 2, 3])                         # يُرجع: [1, 2, 3]
```
