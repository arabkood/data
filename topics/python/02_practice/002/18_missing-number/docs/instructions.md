اكتب دالة باسم `findMissing` تأخذ قائمة من الأرقام المتسلسلة (ينقصها رقم واحد) وتُرجع الرقم الناقص.

**المطلوب:**

- الدالة تأخذ معامل واحد: `numbers` (قائمة من الأرقام)
- الأرقام تبدأ من 1 وتنتهي عند n، لكن ينقص رقم واحد
- الدالة تُرجع الرقم الناقص

**مثال:**

```python
findMissing([1, 2, 4, 5])          # يُرجع: 3
findMissing([3, 1, 2, 5, 6])       # يُرجع: 4
findMissing([2, 3, 4, 5])          # يُرجع: 1
findMissing([1, 2, 3, 4, 5, 7])    # يُرجع: 6
```
