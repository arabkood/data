اكتب دالة باسم `mostCommonChar` تأخذ نص وتُرجع الحرف الأكثر تكراراً فيه (بدون احتساب المسافات).

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع الحرف الأكثر تكراراً
- المسافات لا تُحسب
- إذا كان هناك أكثر من حرف بنفس التكرار، أرجع الحرف الذي ظهر أولاً

**مثال:**

```python
mostCommonChar("hello")            # يُرجع: "l"
mostCommonChar("aabbcc")           # يُرجع: "a"
mostCommonChar("programming")      # يُرجع: "g"
mostCommonChar("hello world")      # يُرجع: "l"
```
