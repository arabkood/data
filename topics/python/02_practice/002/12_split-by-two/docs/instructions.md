اكتب دالة باسم `splitByTwo` تأخذ نص وتُرجعه كقائمة من أزواج الحروف (كل عنصر حرفين).

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع قائمة حيث كل عنصر يحتوي على حرفين
- إذا كان طول النص فردي، أضف `_` للحرف الأخير

**مثال:**

```python
splitByTwo("abcdef")       # يُرجع: ["ab", "cd", "ef"]
splitByTwo("abcde")        # يُرجع: ["ab", "cd", "e_"]
splitByTwo("hello")        # يُرجع: ["he", "ll", "o_"]
splitByTwo("")             # يُرجع: []
```
