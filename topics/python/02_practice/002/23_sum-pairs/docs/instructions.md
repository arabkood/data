اكتب دالة باسم `findPairs` تأخذ قائمة من الأرقام ورقم هدف، وتُرجع جميع الأزواج التي مجموعها يساوي الهدف.

**المطلوب:**

- الدالة تأخذ معاملين: `numbers` (قائمة) و `target` (رقم هدف)
- الدالة تُرجع قائمة من الأزواج، كل زوج هو قائمة من رقمين
- كل زوج يجب أن يظهر مرة واحدة فقط

**مثال:**

```python
findPairs([1, 2, 3, 4, 5], 5)      # يُرجع: [[1, 4], [2, 3]]
findPairs([1, 1, 2, 3], 4)         # يُرجع: [[1, 3]]
findPairs([1, 2, 3], 10)           # يُرجع: []
```
