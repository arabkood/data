اكتب دالة باسم `flattenList` تأخذ قائمة متداخلة (مستوى واحد) وتُرجعها كقائمة مسطحة.

**المطلوب:**

- الدالة تأخذ معامل واحد: `nested` (قائمة متداخلة)
- الدالة تُرجع قائمة مسطحة (تحتوي على جميع العناصر بدون تداخل)
- التداخل مستوى واحد فقط

**مثال:**

```python
flattenList([[1, 2], [3, 4]])           # [1, 2, 3, 4]
flattenList([[1], [2], [3]])            # [1, 2, 3]
flattenList([])                         # []
flattenList([[1, 2, 3]])                # [1, 2, 3]
```
