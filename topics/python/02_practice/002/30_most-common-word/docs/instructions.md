اكتب دالة باسم `mostCommonWord` تأخذ نص وتُرجع الكلمة الأكثر تكراراً فيه.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع الكلمة الأكثر تكراراً
- تجاهل حالة الأحرف (كبيرة أو صغيرة)
- إذا كان هناك أكثر من كلمة بنفس التكرار، أرجع الكلمة الأولى

**مثال:**

```python
mostCommonWord("hello world hello")      # يُرجع: "hello"
mostCommonWord("the cat and the dog")    # يُرجع: "the"
mostCommonWord("one two three")          # يُرجع: "one"
```
