اكتب دالة باسم `moveZeros` تأخذ قائمة من الأرقام وتُرجعها بعد نقل جميع الأصفار إلى النهاية مع الحفاظ على ترتيب الأرقام الأخرى.

**المطلوب:**

- الدالة تأخذ معامل واحد: `numbers` (قائمة من الأرقام)
- الدالة تُرجع قائمة جديدة حيث جميع الأصفار في النهاية
- الحفاظ على ترتيب الأرقام غير الصفرية

**مثال:**

```python
moveZeros([1, 0, 2, 0, 3])         # [1, 2, 3, 0, 0]
moveZeros([0, 0, 1])               # [1, 0, 0]
moveZeros([1, 2, 3])               # [1, 2, 3]
moveZeros([0, 0, 0])               # [0, 0, 0]
```
