اكتب دالة باسم `countVowels` تأخذ نص وتُرجع عدد حروف العلة (vowels) الموجودة فيه.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع عدد حروف العلة الإنجليزية: a, e, i, o, u (صغيرة وكبيرة)
- الحروف الأخرى لا تُحسب

**مثال:**

```python
countVowels("hello")           # يُرجع: 2
countVowels("world")           # يُرجع: 1
countVowels("Python")          # يُرجع: 1
countVowels("aeiou")           # يُرجع: 5
countVowels("xyz")             # يُرجع: 0
```
