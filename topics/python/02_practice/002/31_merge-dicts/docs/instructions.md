اكتب دالة باسم `mergeDicts` تأخذ قاموسين وتُرجعهما مدموجين. إذا كان هناك مفاتيح مشتركة، استخدم القيمة من القاموس الثاني.

**المطلوب:**

- الدالة تأخذ معاملين: `dict1` و `dict2` (قواميس)
- الدالة تُرجع قاموس مدموج
- القيم من dict2 تُفضل في حالة التكرار

**مثال:**

```python
mergeDicts({"a": 1}, {"b": 2})           # يُرجع: {"a": 1, "b": 2}
mergeDicts({"a": 1}, {"a": 2})           # يُرجع: {"a": 2}
mergeDicts({"a": 1, "b": 2}, {"b": 3, "c": 4})  # يُرجع: {"a": 1, "b": 3, "c": 4}
```
