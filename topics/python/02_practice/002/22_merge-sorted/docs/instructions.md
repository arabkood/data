اكتب دالة باسم `mergeSorted` تأخذ قائمتين مرتبتين وتُرجعهما مدموجتين بشكل مرتب.

**المطلوب:**

- الدالة تأخذ معاملين: `list1` و `list2` (قوائم مرتبة تصاعدياً)
- الدالة تُرجع قائمة واحدة مرتبة تحتوي على جميع عناصر القائمتين

**مثال:**

```python
mergeSorted([1, 3, 5], [2, 4, 6])       # يُرجع: [1, 2, 3, 4, 5, 6]
mergeSorted([1, 2], [3, 4])             # يُرجع: [1, 2, 3, 4]
mergeSorted([], [1, 2])                 # يُرجع: [1, 2]
mergeSorted([1], [])                    # يُرجع: [1]
```
