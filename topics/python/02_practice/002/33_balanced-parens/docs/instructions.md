اكتب دالة باسم `isBalanced` تتحقق من توازن الأقواس في نص.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع `True` إذا كانت جميع الأقواس متوازنة، وإلا `False`
- الأقواس المدعومة: `()`, `[]`, `{}`
- كل قوس فتح يجب أن يُغلق بنفس نوع القوس

**مثال:**

```python
isBalanced("()")              # True
isBalanced("([{}])")          # True
isBalanced("([)]")            # False
isBalanced("((")              # False
```
