اكتب دالة باسم `parseCSV` تأخذ سطرين من CSV (الأول للعناوين والثاني للقيم) وتُرجع قاموس.

**المطلوب:**

- الدالة تأخذ معاملين: `headers` و `values` (نصوص بصيغة CSV)
- الدالة تُرجع قاموس حيث المفاتيح من headers والقيم من values
- القيم مفصولة بفاصلة

**مثال:**

```python
parseCSV("name,age", "Ali,25")           # يُرجع: {"name": "Ali", "age": "25"}
parseCSV("x,y,z", "1,2,3")               # يُرجع: {"x": "1", "y": "2", "z": "3"}
```
