اكتب دالة باسم `invertDict` تأخذ قاموس وتُرجعه معكوساً (القيم تصبح مفاتيح والمفاتيح تصبح قيم).

**المطلوب:**

- الدالة تأخذ معامل واحد: `data` (قاموس)
- الدالة تُرجع قاموس جديد حيث المفاتيح والقيم معكوسة
- افترض أن القيم الأصلية فريدة

**مثال:**

```python
invertDict({"a": 1, "b": 2})         # {1: "a", 2: "b"}
invertDict({"x": 10, "y": 20})       # {10: "x", 20: "y"}
invertDict({})                       # {}
```
