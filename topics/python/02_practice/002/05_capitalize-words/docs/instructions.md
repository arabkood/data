اكتب دالة باسم `capitalizeWords` تأخذ نص وتُرجعه بعد تكبير الحرف الأول من كل كلمة.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع النص مع تكبير الحرف الأول من كل كلمة
- باقي الحروف تبقى صغيرة

**مثال:**

```python
capitalizeWords("hello world")         # "Hello World"
capitalizeWords("python programming")  # "Python Programming"
capitalizeWords("HELLO")               # "Hello"
capitalizeWords("a b c")               # "A B C"
```
