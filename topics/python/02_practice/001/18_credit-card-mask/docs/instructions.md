اكتب دالة باسم `maskCard` تأخذ رقم بطاقة ائتمان وتُخفي جميع الأرقام ماعدا آخر 4 أرقام.

**المطلوب:**

- الدالة تأخذ معامل واحد: `card_number` (نص يحتوي على رقم البطاقة)
- الدالة تُرجع نفس الرقم لكن مع استبدال جميع الأرقام بـ `#` ماعدا آخر 4 أرقام
- إذا كان طول النص أقل من أو يساوي 4، أرجعه كما هو بدون إخفاء

**مثال:**

```python
maskCard("1234567812345678")        # "############5678"
maskCard("4123456789012345")        # "############2345"
maskCard("12")                      # "12"
maskCard("1234")                    # "1234"
```
