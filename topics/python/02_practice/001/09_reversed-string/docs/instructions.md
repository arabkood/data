اكتب دالة باسم `reverseString` تأخذ نص وتُرجعه معكوساً.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص)
- الدالة تُرجع النص بترتيب معكوس
- الحرف الأول يصبح الأخير، والأخير يصبح الأول

**مثال:**

```python
reverseString("hello")      # يُرجع: "olleh"
reverseString("Python")     # يُرجع: "nohtyP"
reverseString("a")          # يُرجع: "a"
reverseString("")           # يُرجع: ""
```
