اكتب دالة باسم `fizzBuzz` تأخذ رقم وتُرجع قيمة حسب القواعد التالية:

**القواعد:**

- إذا كان الرقم يقبل القسمة على 3 **و** 5 معاً، أرجع `"FizzBuzz"`
- إذا كان الرقم يقبل القسمة على 3 فقط، أرجع `"Fizz"`
- إذا كان الرقم يقبل القسمة على 5 فقط، أرجع `"Buzz"`
- وإلا، أرجع الرقم نفسه كنص

**المطلوب:**

- إنشاء دالة تُسمى `fizzBuzz`
- الدالة تأخذ معامل واحد: `n` (رقم صحيح)
- الدالة تُرجع نص حسب القواعد أعلاه

**مثال:**

```python
fizzBuzz(3)         # يُرجع: "Fizz"
fizzBuzz(5)         # يُرجع: "Buzz"
fizzBuzz(15)        # يُرجع: "FizzBuzz"
fizzBuzz(7)         # يُرجع: "7"
fizzBuzz(30)        # يُرجع: "FizzBuzz"
```
