اكتب دالة باسم `toArabicDigits` تأخذ نص مختلط يحتوي على حروف وأرقام، وتُرجعه بعد تحويل الأرقام الإنجليزية إلى أرقام عربية.

**المطلوب:**

- الدالة تأخذ معامل واحد: `text` (نص مختلط)
- الدالة تُرجع نفس النص لكن مع تحويل الأرقام الإنجليزية (0-9) إلى أرقام عربية (٠-٩)
- الحروف والرموز الأخرى تبقى كما هي

**مثال:**

```python
toArabicDigits("rhc123")         # يُرجع: "rhc١٢٣"
toArabicDigits("hello789")       # يُرجع: "hello٧٨٩"
toArabicDigits("test0")          # يُرجع: "test٠"
toArabicDigits("no numbers")     # يُرجع: "no numbers"
```
