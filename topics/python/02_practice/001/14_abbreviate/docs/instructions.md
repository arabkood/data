اكتب دالة باسم `abbreviateName` تأخذ اسم كامل (اسم أول واسم عائلة) وتُرجع الأحرف الأولى بأحرف كبيرة مفصولة بنقطة.

**المطلوب:**

- الدالة تأخذ معامل واحد: `name` (اسم كامل)
- الدالة تُرجع الأحرف الأولى من كل اسم بأحرف كبيرة مع نقطة بينهما
- الأحرف في الإدخال قد تكون صغيرة أو كبيرة

**مثال:**

```python
abbreviateName("Sam Harris")        # يُرجع: "S.H"
abbreviateName("john doe")          # يُرجع: "J.D"
abbreviateName("MARK SMITH")        # يُرجع: "M.S"
abbreviateName("alice wonder")      # يُرجع: "A.W"
```
