اكتب دالة باسم `findLongestWord` تأخذ جملة وتُرجع أطول كلمة فيها.

**المطلوب:**

- الدالة تأخذ معامل واحد: `sentence` (جملة نصية)
- الدالة تُرجع أطول كلمة في الجملة
- إذا كان هناك أكثر من كلمة بنفس الطول الأطول، تُرجع الأولى
- إذا كانت الجملة فارغة، تُرجع نص فارغ

**مثال:**

```python
findLongestWord("hello world")                  # "hello"
findLongestWord("Python is amazing")            # "amazing"
findLongestWord("a bb ccc")                     # "ccc"
findLongestWord("")                             # ""
```
