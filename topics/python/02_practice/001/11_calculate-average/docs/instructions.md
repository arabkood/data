اكتب دالة باسم `calculateAverage` تأخذ قائمة من الأرقام وتُرجع المتوسط الحسابي.

**المطلوب:**

- الدالة تأخذ معامل واحد: `numbers` (قائمة من الأرقام)
- الدالة تُرجع المتوسط الحسابي (مجموع الأرقام ÷ عددها)
- إذا كانت القائمة فارغة، تُرجع 0
- يمكن أن تحتوي القائمة على أرقام صحيحة أو عشرية

**مثال:**

```python
calculateAverage([1, 2, 3, 4, 5])       # 3.0
calculateAverage([10, 20, 30])          # 20.0
calculateAverage([5])                   # 5.0
calculateAverage([])                    # 0
```
