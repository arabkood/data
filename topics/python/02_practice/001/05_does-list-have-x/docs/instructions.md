اكتب دالة باسم `hasElement` تتحقق من وجود عنصر معين في قائمة.

**المطلوب:**

- الدالة تأخذ معاملين: `lst` (قائمة) و `item` (العنصر المراد البحث عنه)
- الدالة تُرجع `True` إذا كان العنصر موجوداً في القائمة
- الدالة تُرجع `False` إذا لم يكن العنصر موجوداً

**مثال:**

```python
hasElement([1, 2, 3, 4, 5], 3)      # True
hasElement([1, 2, 3, 4, 5], 6)      # False
hasElement([], 1)                   # False
hasElement(['a', 'b', 'c'], 'b')    # True
```
