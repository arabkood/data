اكتب دالة باسم `repeatString` تأخذ نص وعدد، وتُرجع النص مكرراً بعدد المرات المحدد.

**المطلوب:**

- الدالة تأخذ معاملين: `text` (نص) و `n` (عدد مرات التكرار)
- الدالة تُرجع النص مكرراً `n` مرة
- إذا كان `n` يساوي 0 أو أقل، تُرجع نص فارغ

**مثال:**

```python
repeatString("abc", 3)      # "abcabcabc"
repeatString("Hello", 2)    # "HelloHello"
repeatString("x", 5)        # "xxxxx"
repeatString("test", 0)     # ""
```
