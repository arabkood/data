اكتب دالة باسم `makeNegative` تأخذ رقم وتُرجعه دائماً بصيغة سالبة.

**المطلوب:**

- الدالة تأخذ معامل واحد: `number`
- إذا كان الرقم موجباً، تُرجعه سالباً
- إذا كان الرقم سالباً بالفعل، تُرجعه كما هو
- إذا كان الرقم صفر، تُرجع صفر

**مثال:**

```python
makeNegative(5)    # يُرجع: -5
makeNegative(-3)   # يُرجع: -3
makeNegative(0)    # يُرجع: 0
makeNegative(42)   # يُرجع: -42
```
