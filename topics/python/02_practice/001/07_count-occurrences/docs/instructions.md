اكتب دالة باسم `countOccurrences` تأخذ قائمة وعنصر، وتُرجع عدد مرات ظهور العنصر في القائمة.

**المطلوب:**

- الدالة تأخذ معاملين: `lst` (قائمة) و `item` (العنصر المراد البحث عنه)
- الدالة تُرجع عدد مرات ظهور العنصر
- إذا لم يكن العنصر موجوداً، تُرجع 0

**مثال:**

```python
countOccurrences([1, 2, 3, 2, 4, 2], 2)      # يُرجع: 3
countOccurrences([1, 1, 1, 1], 1)            # يُرجع: 4
countOccurrences([1, 2, 3], 5)               # يُرجع: 0
countOccurrences([], 1)                      # يُرجع: 0
```
