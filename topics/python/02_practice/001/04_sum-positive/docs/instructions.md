اكتب دالة باسم `sumPositive` تأخذ قائمة من الأرقام وتُرجع مجموع الأرقام الموجبة فقط.

**المطلوب:**

- الدالة تأخذ معامل واحد: `numbers` (قائمة من الأرقام)
- الدالة تُرجع مجموع الأرقام الموجبة فقط
- تجاهل الأرقام السالبة والصفر

**مثال:**

```python
sumPositive([1, 2, 3, 4, 5])        # 15
sumPositive([1, -2, 3, -4, 5])      # 9
sumPositive([-1, -2, -3, -4, -5])   # 0
sumPositive([])                     # 0
```
