اكتب دالة باسم `evenOrOdd` تأخذ رقم وتُحدد إذا كان زوجياً أم فردياً.

**المطلوب:**

- الدالة تأخذ معامل واحد: `number`
- الدالة تُرجع `"Even"` إذا كان الرقم زوجياً
- الدالة تُرجع `"Odd"` إذا كان الرقم فردياً

**مثال:**

```python
evenOrOdd(4)   # يُرجع: "Even"
evenOrOdd(7)   # يُرجع: "Odd"
evenOrOdd(0)   # يُرجع: "Even"
evenOrOdd(-3)  # يُرجع: "Odd"
```
