## متى يمكن استخدام كلاهما؟

أحياناً يمكن استخدام أي منهما، لكن واحدة تكون **أوضح**:

**مثال: طباعة 1 إلى 3**

✅ **واضح مع for:**
```python
for i in range(1, 4):
    print(i)
```

⚠️ **ممكن لكن أطول مع while:**
```python
i = 1
while i <= 3:
    print(i)
    i = i + 1
```

**القاعدة:** اختر الحلقة التي تجعل الكود أبسط وأوضح!
