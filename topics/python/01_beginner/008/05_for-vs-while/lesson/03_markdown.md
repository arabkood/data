## حلقة While: عندما لا تعرف العدد

استخدم `while` عندما **لا تعرف** كم مرة ستتكرر، أو عندما تريد الاستمرار حتى يحدث شيء معين.

**مثال 1: حتى يتحقق شرط**
```python
password = ""
while password != "سر123":
    password = input("أدخل كلمة السر: ")
```

**مثال 2: حتى يصل رقم لقيمة معينة**
```python
balance = 100
while balance < 1000:
    balance = balance * 1.1
```

**لماذا while؟** لا نعرف كم محاولة للباسورد، أو كم مرة سنضاعف!
