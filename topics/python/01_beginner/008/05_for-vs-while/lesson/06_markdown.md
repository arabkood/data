دعنا نرى نفس المهمة بالطريقتين!

**المهمة:** اجمع الأرقام من 1 إلى 5

**باستخدام for:**
```python
total = 0
for i in range(1, 6):
    total = total + i
print(total)  # 15
```

**باستخدام while:**
```python
total = 0
i = 1
while i <= 5:
    total = total + i
    i = i + 1
print(total)  # 15
```
