## حلقة For: عندما تعرف العدد

استخدم `for` عندما تعرف **بالضبط** كم مرة تريد التكرار، أو عندما تمر على **قائمة محددة**.

**مثال 1: عدد محدد من التكرارات**
```python
for i in range(5):
    print(i)
```

**مثال 2: المرور على قائمة**
```python
fruits = ["تفاح", "موز", "برتقال"]
for fruit in fruits:
    print(fruit)
```

**لماذا for؟** لأننا نعرف مسبقاً: 5 مرات، أو 3 فواكه.
