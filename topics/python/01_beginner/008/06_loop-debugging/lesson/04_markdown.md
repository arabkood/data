## الخطأ #2: الخطأ بمقدار واحد (Off-by-One Error)

**المشكلة:** الحلقة تعمل مرة زيادة أو مرة ناقصة!

```python
# ⚠️ يطبع 0-4 بدلاً من 1-5
for i in range(5):
    print(i)
```

**الحل:** تحقق من بداية ونهاية range!
```python
# ✅ صحيح: 1-5
for i in range(1, 6):
    print(i)
```

**تذكر:** `range(1, 6)` تعني من 1 حتى 5 (لا تشمل 6)
