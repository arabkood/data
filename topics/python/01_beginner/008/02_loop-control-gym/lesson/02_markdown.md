## أولاً: كلمة `break` - الإيقاف الفوري

`break` تخرج من الحلقة **فوراً**، حتى لو لم ينته الشرط.

```python
count = 0

while count < 10:
    if count == 5:
        break  # توقف عندما نصل إلى 5
    print(count)
    count = count + 1

print("خرجنا من الحلقة!")
```

**النتيجة:** سيطبع 0, 1, 2, 3, 4 ثم يتوقف!
