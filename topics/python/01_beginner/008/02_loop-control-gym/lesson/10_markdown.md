## ثالثاً: كلمة `pass` - مكان حافظ فارغ

`pass` لا تفعل شيئاً على الإطلاق! تستخدم كـ "عنصر نائب" عندما تحتاج كوداً لكن لا تريد تنفيذ أي شيء بعد.

```python
for i in range(5):
    if i % 2 == 0:
        pass  # سنضيف شيئاً لاحقاً
    else:
        print(i)
```

مفيدة أثناء كتابة الكود أو في حالات خاصة!
