لنرى مثالاً بسيطاً:

```python
count = 1

while count <= 3:
    print(f"العد: {count}")
    count = count + 1

print("انتهى!")
```

**ماذا يحدث؟**
1. نبدأ بـ `count = 1`
2. نتحقق: هل `count <= 3`؟ نعم! → ننفذ الكود
3. نطبع "العد: 1" ثم نزيد `count` إلى 2
4. نتحقق مجدداً: هل `2 <= 3`؟ نعم! → ننفذ مرة أخرى
5. نستمر حتى يصبح `count = 4`، عندها `4 <= 3` يصبح خاطئاً
6. نخرج من الحلقة ونطبع "انتهى!"
