معلومة مهمة جداً: **الدالة `input()` دائماً تعطيك نص!**

حتى لو كتب المستخدم رقماً:

```python
user_age = input("كم عمرك؟ ")  # المستخدم يكتب: 25
print(type(user_age))          # النتيجة: <class 'str'>
print(user_age)                # النتيجة: "25" (نص وليس رقم!)
```

هذا أمر طبيعي! سنتعلم كيفية تحويل النصوص لأرقام في الدرس القادم.
