بايثون تقدم لك أداة رائعة لمعرفة نوع أي قيمة: الدالة `type()`.

فكر فيها كعدسة مكبرة تكشف لك حقيقة البيانات:

```python
print(type("مرحباً"))    # <class 'str'>
print(type(42))         # <class 'int'>
print(type(3.14))       # <class 'float'>
```

- `str` يعني string (نص)
- `int` يعني integer (رقم صحيح)  
- `float` يعني floating point (رقم عشري)
