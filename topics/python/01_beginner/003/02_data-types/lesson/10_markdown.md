لنجرب مثالاً أكثر تعقيداً:

```python
name = "سارة"
age = 28
height = 165.5
id_number = "123456789"

print("الاسم:", name, "- النوع:", type(name))
print("العمر:", age, "- النوع:", type(age))
print("الطول:", height, "- النوع:", type(height))
print("رقم الهوية:", id_number, "- النوع:", type(id_number))
```

لاحظ أن `id_number` هو نص رغم أنه يحتوي على أرقام، لأنه محاط بعلامات اقتباس!
