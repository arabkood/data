### البحث والاستبدال: `.replace()`

أحياناً، تريد استبدال جزء من النص بشيء آخر. الـ method المسمى `.replace()` يقوم بذلك تماماً.

الصيغة هي: `.replace("النص القديم", "النص الجديد")`

```python
sentence = "أنا أحب القهوة. القهوة لذيذة."

# استبدل كل "القهوة" بـ "الشاي"
new_sentence = sentence.replace("القهوة", "الشاي")

print(new_sentence)
```
**الناتج:**
```text
أنا أحب الشاي. الشاي لذيذ.
```
