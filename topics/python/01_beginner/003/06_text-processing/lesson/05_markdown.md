### تغيير حالة الأحرف: `.upper()` و `.lower()`

مشكلة شائعة أخرى هي حالة الأحرف. هل "Egypt" هي نفسها "egypt"؟ بالنسبة لنا نعم، لكن ليس للكمبيوتر.

للتوحيد، يمكننا تحويل كل النص إلى أحرف كبيرة (`UPPERCASE`) أو صغيرة (`lowercase`).

- `.upper()`: يحول كل الأحرف إلى كبيرة.
- `.lower()`: يحول كل الأحرف إلى صغيرة.

```python
city = "Cairo"
print(city.upper()) # سيطبع CAIRO
print(city.lower()) # سيطبع cairo
```
هذا مفيد جداً للمقارنات غير الحساسة لحالة الأحرف.
