
لقد قمت بعمل رائع في حل هذه الألغاز. تذكر هذه الأنماط الشائعة للأخطاء:

- **خطأ النوع (`TypeError`):**
  **المشكلة:** خلط أنواع غير متوافقة (مثل نص ورقم).
  **الحل:** وحّد النوع أولاً باستخدام `int()` أو `float()`.

- **خطأ القيمة (`ValueError`):**
  **المشكلة:** نص "غير نظيف" لا يمكن تحويله إلى رقم.
  **الحل:** نظّف النص دائماً (`.strip()`, `.replace()`) قبل تحويله.

- **خطأ منطقي (الكود يعمل لكن النتيجة خطأ):**
  **المشكلة:** غالباً بسبب نسيان حفظ نتيجة (`name = name.strip()`) أو استخدام `=` بدلاً من `==`.
  **الحل:** استخدم `print()` لتتبع قيم متغيراتك وكشف الخطأ.

تذكر دائماً: الأخطاء ليست فشلاً، بل هي خارطة طريق لإصلاح الكود. كل خطأ تصلحه يجعلك مبرمجاً أقوى.
