
لقد قمت بعمل رائع في حل هذه الألغاز. تذكر هذه الأنماط الشائعة للأخطاء:

**1. خطأ النوع (`TypeError`)**

* **المشكلة:** خلط أنواع غير متوافقة (مثل جمع نص مع رقم).
* **الحل:** وحّد النوع أولاً باستخدام `int()` أو `float()`.

**2. خطأ القيمة (`ValueError`)**

* **المشكلة:** محاولة تحويل نص "غير نظيف" إلى رقم.
* **الحل:** نظّف النص دائماً قبل التحويل (مثل: `.strip()`, `.replace()`).

**3. خطأ منطقي (Logic Error)**

* **المشكلة:** الكود يشتغل لكن النتيجة خاطئة.

  * مثال: نسيان حفظ النتيجة (`name = name.strip()`)
  * أو الخلط بين `=` و `==`
* **الحل:** تتبع القيم بـ `print()` لاكتشاف أين يحصل الخطأ.

---

تذكر دائماً: الأخطاء ليست فشلاً، بل هي خارطة طريق لإصلاح الكود. كل خطأ تصلحه يجعلك مبرمجاً أقوى.
