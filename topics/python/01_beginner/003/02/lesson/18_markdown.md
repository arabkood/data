لنطبق ما تعلمناه في مثال من متجر إلكتروني:

```python
# بيانات منتج
product_name = "سماعات لاسلكية"    # نص
price = 299.99                   # رقم عشري
in_stock = 150                   # رقم صحيح
product_code = "WH1000XM4"       # نص (رغم وجود أرقام!)

print("المنتج:", product_name)
print("السعر:", price, "ريال")
print("المتوفر:", in_stock, "قطعة")
print("الكود:", product_code)
```
