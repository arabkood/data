### ماذا لو فشل التحويل؟

ماذا سيحدث لو حاولنا تحويل نص لا يبدو كرقم على الإطلاق؟

```python
# هذا الكود سيسبب انهيار البرنامج!
not_a_number = int("مرحباً") 
```
سيغضب بايثون ويعرض خطأ يسمى `ValueError`. هذه هي طريقته ليقول: "لقد أعطيتني نص 'مرحباً'، وأنا لا أعرف كيف أحول هذا إلى رقم!".

تذكر هذا الخطأ جيداً، لأنه من أكثر الأخطاء شيوعاً عند التعامل مع مدخلات المستخدم.
