### التحويل إلى نص: `str()`

في بعض الأحيان، نحتاج إلى القيام بالعكس تماماً: تحويل رقم إلى نص.

لماذا؟ السبب الأكثر شيوعاً هو عندما نريد دمج رقم مع نص لطباعة رسالة. تذكر أن عامل `+` يستخدم للجمع الحسابي مع الأرقام، وللصق النصوص معاً. لا يمكنك خلطهما!

```python
level = 10

# هذا الكود سيسبب خطأ TypeError
# message = "لقد وصلت إلى المستوى " + level

# الحل: تحويل الرقم إلى نص أولاً
message = "لقد وصلت إلى المستوى " + str(level)
print(message)
```
دالة `str()` يمكنها تحويل أي شيء تقريباً إلى تمثيله النصي.
