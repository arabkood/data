لماذا نحتاج لفحص أنواع البيانات؟ لنرى مثالاً:

```python
# المستخدم قد يدخل أي شيء
user_input = input("أدخل رقماً: ")

# ماذا لو أردنا مضاعفة الرقم؟
# هذا لن يعمل كما نتوقع!
result = user_input * 2
```

إذا كتب المستخدم "5"، النتيجة ستكون "55" وليس 10!

لذلك نحتاج لفحص النوع أولاً لنتعامل معه بالطريقة الصحيحة.
