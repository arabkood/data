يمكنك استخدام `type()` للفحص والمقارنة:

```python
value = 42

if type(value) == int:
    print("هذا رقم صحيح!")
elif type(value) == str:
    print("هذا نص!")
elif type(value) == float:
    print("هذا رقم عشري!")
```

**ملاحظة:** لا تقلق حول `if` الآن، سنتعلمها لاحقاً. المهم أن تفهم فكرة المقارنة مع الأنواع.
