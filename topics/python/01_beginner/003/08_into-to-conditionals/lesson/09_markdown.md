### ماذا لو كان الشرط `False`؟

هذا هو جمال جملة `if`. إذا كان الشرط يُقيّم إلى `False`، فإن الحارس يمنع الدخول.

بايثون ببساطة **يتخطى** كتلة الكود ذات المسافة البادئة وينتقل إلى السطر الأول بعده.

```python
temperature = 20

# هل 20 > 30؟ لا، هذا False.
if temperature > 30:
    # هذا السطر سيتم تجاهله بالكامل.
    print("الجو حار اليوم!")

# سينتقل بايثون مباشرة إلى هنا.
print("استمتع بيومك.")
```
**الناتج:**
```text
استمتع بيومك.
```
