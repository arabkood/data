لنرى مثالاً عملياً. لدينا درجة طالب، ونريد طباعة رسالة خاصة إذا كانت درجته كاملة.

```python
score = 100

# هل يساوي 100؟
# True
if score == 100:
    # بما أن الشرط True
    # سيتم تنفيذ هذا السطر.
    print("نتيجة ممتازة!")

# هل يساوي 0؟
# False
if score == 0:
    # بما أن الشرط False
    # لن تنفيذ هذا السطر.
    print("فشلت!")

# هذا السطر سيتم تنفيذه دائماً.
print("لقد أنهيت الاختبار.")
```

**الناتج:**

```text
نتيجة ممتازة!
لقد أنهيت الاختبار.
```
