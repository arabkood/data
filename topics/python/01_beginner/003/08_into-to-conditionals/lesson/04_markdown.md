### طرح الأسئلة: عامل المقارنة `==`

نادراً ما نكتب `is_sunny = True` مباشرة. بدلاً من ذلك، نجعل الكمبيوتر يكتشف الحقيقة بنفسه عن طريق طرح سؤال.

الطريقة الأساسية لطرح سؤال في البرمجة هي مقارنة قيمتين. للسؤال "هل هاتان القيمتان متساويتان؟"، نستخدم علامتي يساوي `==`.

```python
# هل 5 تساوي 5؟ -> نعم، إذن النتيجة 
# True
print(5 == 5)

# هل 5 تساوي 6؟ -> لا، إذن النتيجة 
# False
print(5 == 6)

# هل "مرحباً" تساوي "مرحباً"؟ -> نعم، إذن النتيجة 
# True
print("مرحباً" == "مرحباً")
```

الناتج:

```text
True
False
True
```

عندما يرى بايثون `==`، فإنه يقوم بتقييم المقارنة ويعطينا إجابة `True` أو `False`.
