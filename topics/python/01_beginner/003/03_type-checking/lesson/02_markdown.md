### الأداة الأولى: `type()`

تقدم بايثون دالة مدمجة بسيطة تسمى `type()`. هذه الدالة تشبه المفتش الذي ينظر إلى القيمة داخل المتغير ويخبرك بنوعها بالضبط.

دعنا نجرّبها مع دالة `input()`:

```python
user_input = input("أدخل أي شيء (رقم أو نص): ")

print("البيانات التي أدخلتها من نوع:")
print(type(user_input))
```

جرّب تشغيل هذا الكود وأدخل الرقم `50`. ماذا تتوقع أن تكون النتيجة؟
