بالطبع، تعمل دالة `type()` مع جميع أنواع البيانات. دعنا نرى أمثلة مع متغيرات أنشأناها مباشرة في الكود:

```python
# متغير من نوع عدد صحيح (integer)
score = 100
print(type(score))

# متغير من نوع عدد عشري (float)
pi_value = 3.14
print(type(pi_value))

# متغير من نوع نص (string)
message = "Hello, Akood!"
print(type(message))
```

**الناتج:**
```text
<class 'int'>
<class 'float'>
<class 'str'>
```
لا تقلق من كلمة `class` الآن. فقط اعتبر أن `<class 'int'>` هي الطريقة الرسمية التي يقول بها بايثون "هذا عدد صحيح".
