### لماذا كل هذا مهم؟

التحقق من الأنواع هو أساس كتابة برامج قوية وموثوقة. يتيح لك التعامل مع مدخلات المستخدم بأمان واتخاذ قرارات في الكود الخاص بك.

سنلقي نظرة سريعة على كيفية استخدام هذا في اتخاذ قرار بسيط. سنتعلم المزيد عن جمل `if` الشرطية لاحقاً بالتفصيل.

```python
data = 42

if isinstance(data, int):
    # هذا الكود سيعمل فقط إذا كانت البيانات من نوع int
    print("البيانات هي رقم. يمكننا إجراء عمليات حسابية!")
    print(data * 2) 
```
جرّب تغيير `data = 42` إلى `data = "Hello"` وانظر كيف لن يتم تنفيذ الكود داخل جملة `if`.
