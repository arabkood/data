## 🔄 مراجعة حلقات For

### المفهوم الأساسي:
```python
# التكرار عدد معين من المرات
for i in range(5):
    print(f"التكرار رقم: {i}")
```

### مع المعاملات:
```python
# البداية والنهاية والخطوة
for i in range(2, 10, 2):  # 2, 4, 6, 8
    print(i)
```

### مع القوائم:
```python
fruits = ["تفاح", "موز", "برتقال"]
for fruit in fruits:
    print(f"أحب {fruit}")
```
