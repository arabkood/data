## 🎯 نقاط التقييم الذاتي

قبل الانتقال للوحدة القادمة، تأكد من أنك تستطيع:

### ✅ المفاهيم الأساسية:
- [ ] أفهم الفرق بين `for` و `while`
- [ ] أستطيع استخدام `range()` بمعاملات مختلفة
- [ ] أعرف متى أستخدم `break` و `continue`
- [ ] أفهم كيفية عمل الحلقات المتداخلة

### ✅ التطبيقات العملية:
- [ ] أستطيع إنشاء عدادات ومجمعات
- [ ] أستطيع التكرار عبر القوائم ومعالجة البيانات
- [ ] أستطيع كتابة حلقات تفاعلية مع المستخدم
- [ ] أستطيع البحث والفلترة في البيانات

### ✅ حل المشاكل:
- [ ] أستطيع تحديد وإصلاح الحلقات اللا نهائية
- [ ] أعرف كيفية تجنب أخطاء الفهارس
- [ ] أستطيع استخدام `print()` لتتبع الأخطاء
- [ ] أفهم رسائل الأخطاء الشائعة وحلولها

### ✅ الأنماط المتقدمة:
- [ ] أستطيع دمج عدة تقنيات في برنامج واحد
- [ ] أعرف الأنماط الشائعة (عد، تجميع، بحث، تحويل)
- [ ] أستطيع كتابة برامج تفاعلية معقدة
- [ ] أثق في قدرتي على حل مشاكل جديدة
