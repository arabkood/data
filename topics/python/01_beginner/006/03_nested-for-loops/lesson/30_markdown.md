# تمرين إبداعي: نمطك الخاص

جرب تطبيق هذا الكود وغيّر القيم لتنشئ أنماطاً مختلفة:

```python
# جرب قيم مختلفة لهذه المتغيرات
width = 5
height = 4
char1 = "🌟"
char2 = "⭐"

for row in range(height):
    for col in range(width):
        if (row + col) % 2 == 0:
            print(char1, end=" ")
        else:
            print(char2, end=" ")
    print()  # سطر جديد بعد كل صف
```

**تحدي:** غيّر المتغيرات واكتشف أنماطاً جديدة!
