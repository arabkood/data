# استخدام break و continue في الحلقات المتداخلة

**مهم:** `break` و `continue` يؤثران فقط على الحلقة التي هما فيها مباشرة.

```python
for i in range(3):
    for j in range(3):
        if j == 1:
            break  # يخرج من الحلقة الداخلية فقط
        print(f"({i},{j})", end=" ")
    print()  # سطر جديد
    print("انتهى الصف")
```

النتيجة:
```
(0,0) 
انتهى الصف
(1,0) 
انتهى الصف
(2,0) 
انتهى الصف
```
