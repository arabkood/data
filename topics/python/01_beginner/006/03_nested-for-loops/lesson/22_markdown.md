# مثال متقدم: رقعة الشطرنج

لنبني نمط رقعة شطرنج بسيط باستخدام # و -:

```python
size = 4
for row in range(size):
    for col in range(size):
        if (row + col) % 2 == 0:
            print("#", end=" ")
        else:
            print("-", end=" ")
    print()  # سطر جديد بعد كل صف
```

النتيجة:
```
# - # - 
- # - # 
# - # - 
- # - # 
```

**الفكرة:** إذا كان مجموع الصف والعمود زوجي، اطبع #، وإلا اطبع -
