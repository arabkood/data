# فهم تدفق التنفيذ بالتفصيل

دعني أوضح لك **خطوة بخطوة** كيف تعمل الحلقة المتداخلة:

```python
for i in range(2):
    print(f"--- بداية الصف {i} ---")
    for j in range(3):
        print(f"i={i}, j={j}", end=" ")
    print()  # سطر جديد
    print(f"--- نهاية الصف {i} ---")
```

**النتيجة ستكون:**
```
--- بداية الصف 0 ---
i=0, j=0 i=0, j=1 i=0, j=2 
--- نهاية الصف 0 ---
--- بداية الصف 1 ---
i=1, j=0 i=1, j=1 i=1, j=2 
--- نهاية الصف 1 ---
```
