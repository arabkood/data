تخيل أنك تريد رسم مربع من النجوم حجمه 3×3:

```
* * *
* * *
* * *
```

بالطريقة التي نعرفها، ستكتب:

```python
print("* * *")
print("* * *")
print("* * *")
```

لكن ماذا لو أردت مربعاً حجمه 10×10؟ أو حتى 100×100؟ هذا مستحيل!
