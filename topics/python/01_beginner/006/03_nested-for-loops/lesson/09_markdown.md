# أول حلقة متداخلة حقيقية

الآن يمكننا رسم مربع 3×3 بالطريقة الذكية:

```python
for row in range(3):        # الحلقة الخارجية: الصفوف
    for col in range(3):    # الحلقة الداخلية: الأعمدة
        print("*", end=" ")
    print()  # انتقال لسطر جديد بعد كل صف
```

**شرح التنفيذ:**
- row = 0: تطبع ثلاث نجوم على نفس السطر، ثم تنتقل لسطر جديد
- row = 1: تطبع ثلاث نجوم على نفس السطر، ثم تنتقل لسطر جديد  
- row = 2: تطبع ثلاث نجوم على نفس السطر، ثم تنتقل لسطر جديد
