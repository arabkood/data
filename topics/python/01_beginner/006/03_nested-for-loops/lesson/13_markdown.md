# قاعدة مهمة: المسافات البادئة

في الحلقات المتداخلة، المسافات البادئة **حرجة جداً**:

```python
for i in range(2):           # بدون مسافات
    for j in range(2):       # 4 مسافات
        print("داخل", end=" ")  # 8 مسافات
    print()                  # 4 مسافات - سطر جديد
    print("وسط")             # 4 مسافات
print("خارج")                # بدون مسافات
```

**تذكر:** كل مستوى من التداخل يحتاج 4 مسافات إضافية!
