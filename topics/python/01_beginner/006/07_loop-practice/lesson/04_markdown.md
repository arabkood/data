## السيناريو الثاني: العد التنازلي للألعاب النارية 🎆

في احتفالات رأس السنة، نحتاج لعد تنازلي قبل إطلاق الألعاب النارية.

هذا مثال رائع لاستخدام range مع step سالب:

```python
print("الاستعداد للألعاب النارية...")
for count in range(5, 0, -1):
    print(f"{count}...")
print("🎆 الألعاب النارية! 🎆")
```
