## خطأ الشرط المقلوب

### المشكلة:
```python
# نريد طباعة الأرقام الموجبة فقط
numbers = [5, -3, 8, -1, 12]
for num in numbers:
    if num < 0:  # خطأ: الشرط مقلوب!
        print(f"رقم موجب: {num}")
```

### النتيجة الخاطئة:
```
رقم موجب: -3
رقم موجب: -1
```

### الحل:
```python
# الحل: عكس الشرط
for num in numbers:
    if num > 0:  # الآن الشرط صحيح
        print(f"رقم موجب: {num}")
```
