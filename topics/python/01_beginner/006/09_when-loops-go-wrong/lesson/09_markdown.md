## كيفية تتبع الأخطاء (Debugging)

### 1. استخدام print() للتتبع:
```python
total = 0
for i in range(1, 4):
    print(f"قبل الإضافة: total = {total}, i = {i}")  # تتبع
    total += i
    print(f"بعد الإضافة: total = {total}")  # تتبع
```

### 2. التحقق من الشروط:
```python
number = 5
if number > 0:
    print("الرقم موجب")  # تأكيد
else:
    print("الرقم سالب أو صفر")  # تأكيد
```
