## الخطأ الأكثر شيوعاً: الحلقة اللا نهائية

### المشكلة:
```python
# خطأ: الحلقة لن تتوقف أبداً!
count = 1
while count <= 5:
    print(f"العد: {count}")
    # نسينا count += 1
```

### العلامات التحذيرية:
- البرنامج "يعلق" ولا يتوقف
- نفس الناتج يطبع إلى ما لا نهاية
- الكمبيوتر يصبح بطيئاً

### الحل:
```python
# الحل: تحديث المتغير
count = 1
while count <= 5:
    print(f"العد: {count}")
    count += 1  # هذا السطر مفقود!
```
