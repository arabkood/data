## أول حلقة متداخلة: المثال البسيط

دعنا نبدأ بمثال بسيط لنفهم الفكرة:

```python
for i in range(3):
    print(f"الحلقة الخارجية: {i}")
    for j in range(2):
        print(f"    الحلقة الداخلية: {j}")
```

النتيجة:

```
الحلقة الخارجية: 0
    الحلقة الداخلية: 0
    الحلقة الداخلية: 1
الحلقة الخارجية: 1
    الحلقة الداخلية: 0
    الحلقة الداخلية: 1
الحلقة الخارجية: 2
    الحلقة الداخلية: 0
    الحلقة الداخلية: 1
```

**كيف يعمل هذا؟**

- `i` يأخذ القيم: 0، 1، 2
- **لكل قيمة من `i`**: `j` يأخذ القيم: 0، 1
