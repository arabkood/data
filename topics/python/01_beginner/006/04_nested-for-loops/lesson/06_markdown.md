## مثال من الحياة الواقعية: طباعة النجوم ⭐

لنطبع مثلث من النجوم:

```
*
**
***
****
```

**التفكير:**
- الصف الأول: نجمة واحدة
- الصف الثاني: نجمتان  
- الصف الثالث: 3 نجوم
- الصف الرابع: 4 نجوم

```python
for row in range(1, 5):  # 4 صفوف
    for star in range(row):  # عدد النجوم = رقم الصف
        print("*", end="")
    print()  # سطر جديد بعد كل صف
```
