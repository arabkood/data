## تحدي نهائي: فهم التدفق 🧠

عندما نرى حلقات متداخلة، فكر في التسلسل:

```python
for i in range(2):
    print(f"بداية الحلقة الخارجية: i = {i}")
    for j in range(3):
        print(f"  داخل الحلقة الداخلية: j = {j}")
    print(f"نهاية الحلقة الخارجية: i = {i}")
```

**التسلسل:**
1. i = 0 → j يأخذ 0, 1, 2
2. i = 1 → j يأخذ 0, 1, 2 مرة أخرى

**القاعدة الذهبية:** الحلقة الداخلية تكمل دورتها كاملة قبل أن تنتقل الحلقة الخارجية للقيمة التالية.
