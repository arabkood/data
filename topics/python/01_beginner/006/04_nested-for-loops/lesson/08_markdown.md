## نمط شائع: جدول الضرب

الآن لننشئ جدول ضرب حقيقي:

```python
for i in range(1, 4):  # الأرقام من 1 إلى 3
    for j in range(1, 4):  # الأرقام من 1 إلى 3
        result = i * j
        print(f"{i}×{j}={result}", end="  ")
    print()  # سطر جديد لكل صف
```

**النتيجة:**
```
1×1=1  1×2=2  1×3=3
2×1=2  2×2=4  2×3=6
3×1=3  3×2=6  3×3=9
```
