## تطبيق متقدم: شطرنج صغير 🏁

لنطبع رقعة شطرنج 4×4 باستخدام ⬜ و ⬛:

```python
for row in range(4):
    for col in range(4):
        if (row + col) % 2 == 0:
            print("⬜", end="")
        else:
            print("⬛", end="")
    print()
```

**الفكرة:** إذا كان مجموع (الصف + العمود) زوجي → مربع أبيض، وإلا مربع أسود.
