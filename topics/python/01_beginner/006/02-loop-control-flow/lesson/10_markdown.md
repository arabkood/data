# الكلمة السحرية الثالثة: pass

`pass` تعني "لا تفعل شيئاً، فقط امضي قدماً"

لماذا نحتاجها؟ أحياناً نريد كتابة حلقة فارغة مؤقتاً:

```python
for i in range(5):
    if i % 2 == 0:
        pass  # سأكتب الكود لاحقاً
    else:
        print(f"رقم فردي: {i}")
```

`pass` هو مثل وضع ملاحظة "سأكمل هذا لاحقاً" في الكود.
