# الكلمة السحرية الأولى: break

`break` تعني "توقف فوراً واخرج من الحلقة"

تخيل أنك تبحث في صندوق عن مفتاحك. عندما تجده، ستتوقف عن البحث فوراً!

```python
for i in range(10):
    print("البحث في الموضع:", i)
    if i == 3:
        print("وجدت المفتاح!")
        break
    print("لم أجد شيئاً هنا")
print("انتهيت من البحث")
```

# media_idea: رسم توضيحي لشخص يبحث في صندوق ويتوقف عند العثور على المفتاح
