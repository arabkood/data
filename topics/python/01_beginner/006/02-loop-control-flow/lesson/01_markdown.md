# أحياناً نحتاج إلى التحكم في الحلقة

في الدرس السابق، تعلمنا كيفية إنشاء حلقات بسيطة. لكن أحياناً نحتاج إلى:
- **إيقاف الحلقة مبكراً** عند حدوث شيء معين
- **تخطي دورة معينة** والانتقال للتالية
- **وضع placeholder** عندما لا نريد فعل شيء

اليوم سنتعلم ثلاث كلمات سحرية: `break`، `continue`، و `pass`!
