# الكلمة السحرية الأولى: break

`break` تعني "توقف فوراً واخرج من الحلقة"

تخيل أنك تبحث في صندوق عن مفتاحك. عندما تجده، ستتوقف عن البحث فوراً!

```python
for i in range(10):
    print("البحث في الموضع:", i)
    if i == 3:
        print("وجدت المفتاح!")
        break
    print("لم أجد شيئاً هنا")
print("انتهيت من البحث")
```

النتيجة:

```
البحث في الموضع: 0
لم أجد شيئاً هنا
البحث في الموضع: 1
لم أجد شيئاً هنا
البحث في الموضع: 2
لم أجد شيئاً هنا
البحث في الموضع: 3
وجدت المفتاح!
انتهيت من البحث
```
