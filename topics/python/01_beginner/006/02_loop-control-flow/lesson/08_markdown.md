# مثال عملي: طباعة الأرقام الإيجابية فقط

```python
numbers = [5, -2, 8, -1, 3, 0, -4, 7]

print("الأرقام الإيجابية:")
for num in numbers:
    if num <= 0:
        continue  # تخطي الأرقام السالبة والصفر
    print(f"رقم إيجابي: {num}")
```

النتيجة:

```
الأرقام الإيجابية:
رقم إيجابي: 5
رقم إيجابي: 8
رقم إيجابي: 3
رقم إيجابي: 7
```

`continue` مفيد جداً لتصفية البيانات!

> ملاحظة: لا تقلق من شكل numbers = [...] الآن، سنتعلم القوائم بالتفصيل لاحقاً.
