# مثال عملي مع break

لنبني برنامج يعد الأرقام حتى يجد رقماً قابلاً للقسمة على 7:

```python
for i in range(1, 50):
    # إذا كان الرقم قابل للقسمة على 7
    if i % 7 == 0:  
        print(f"أول رقم قابل للقسمة على 7 هو: {i}")
        break
```

هذا مفيد جداً عندما تريد التوقف بمجرد العثور على ما تبحث عنه!
