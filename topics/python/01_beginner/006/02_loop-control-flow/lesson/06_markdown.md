# الكلمة السحرية الثانية: continue

`continue` تعني "تخطى باقي هذه الدورة وانتقل للتالية"

تخيل أنك تنظف غرفتك. إذا وجدت شيئاً نظيفاً، ستتخطاه وتنتقل للشيء التالي:

```python
for i in range(5):
    if i == 2:
        print("هذا نظيف، سأتخطاه")
        continue
    print(f"سأنظف الشيء رقم {i}")
```

النتيجة:
```
سأنظف الشيء رقم 0
سأنظف الشيء رقم 1
هذا نظيف، سأتخطاه
سأنظف الشيء رقم 3
سأنظف الشيء رقم 4
```
