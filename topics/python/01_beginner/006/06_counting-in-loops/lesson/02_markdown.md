## المتغير العداد (Counter Variable)

**العداد** هو متغير نستخدمه لحساب عدد المرات التي حدث فيها شيء معين.

إليك المثال الأساسي:

```python
counter = 0  # نبدأ من الصفر

for i in range(5):
    counter = counter + 1  # أو counter += 1
    print(f"المرة رقم: {counter}")

print(f"المجموع النهائي: {counter}")
```

**النتيجة:**
```
المرة رقم: 1
المرة رقم: 2
المرة رقم: 3
المرة رقم: 4
المرة رقم: 5
المجموع النهائي: 5
```
