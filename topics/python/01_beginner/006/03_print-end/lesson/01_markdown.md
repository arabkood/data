هل لاحظت شيئاً مثيراً للاهتمام عندما تستخدم `print()` عدة مرات؟

دعنا نرى مثالاً:

```python
print("مرحبا")
print("كيف حالك؟")
print("أتمنى لك يوماً سعيداً")
```

النتيجة ستكون:

```
مرحبا
كيف حالك؟
أتمنى لك يوماً سعيداً
```

كل `print()` ينتقل إلى **سطر جديد** تلقائياً! لكن ماذا لو أردنا التحكم في هذا السلوك؟
