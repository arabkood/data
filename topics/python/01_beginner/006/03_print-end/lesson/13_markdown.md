## تحدي إضافي: الإبداع مع `end`

جرب هذه الأفكار:

```python
# إنشاء خط فاصل
for i in range(10):
    print("-", end="")
print()  # سطر جديد في النهاية

# طباعة الوقت بتنسيق جميل
hours = "14"
minutes = "30"
print("الوقت الآن: ", end="")
print(hours, end=":")
print(minutes)
```

الآن أنت تعرف سر التحكم في نهايات `print()`! 🎉
