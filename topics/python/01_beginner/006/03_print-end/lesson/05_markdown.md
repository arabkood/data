## أمثلة متنوعة على استخدام `end`

يمكنك وضع أي نص تريده في `end`:

### أمثلة

```python
# مسافة بين الكلمات
print("أ", end=" ")
print("ب", end=" ")
print("ج")
```

```
أ ب ج
```

---

```python
# استخدام رمز
print("أ", end=".")
print("ب", end=".")
print("ج")
```

```
أ.ب.ج
```

---

```python
# سهم بين الكلمات
print("البداية", end=" -> ")
print("الوسط", end=" -> ")
print("النهاية")
```

```
البداية -> الوسط -> النهاية
```

---

```python
# بدون أي فاصل (سلسلة متصلة)
print("123", end="")
print("456", end="")
print("789")
```

```
123456789
```

---

```python
# إيموجي
print("🐍", end="✨")
print("بايثون", end="✨")
print("قوي")
```

```
🐍✨بايثون✨قوي
```
