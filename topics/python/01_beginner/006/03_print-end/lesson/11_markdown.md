## متى نستخدم `end`؟

**استخدم `end` عندما تريد:**

✅ طباعة عدة أجزاء في نفس السطر  
✅ بناء أشكال وأنماط نصية  
✅ إنشاء عدادات أو أشرطة تقدم  
✅ تجميع النصوص بفواصل مخصصة  

**مثال من الحياة الواقعية:**
```python
print("اسم المستخدم: ", end="")
username = input()
# المستخدم يكتب اسمه في نفس السطر!
```
