# مثال عملي: العد التنازلي

لنبني عداد تنازلي من 5 إلى 1:

```python
for i in range(5, 0, -1):
    print("العد التنازلي:", i)
print("انطلق!")
```

هنا نبدأ من 5، ننتهي قبل 0، ونقلل بـ 1 في كل مرة (-1).

النتيجة:

```
العد التنازلي: 5
العد التنازلي: 4
العد التنازلي: 3
العد التنازلي: 2
العد التنازلي: 1
انطلق!
```
