# المسافة البادئة (Indentation) - مهم جداً!

في Python، **المسافة البادئة** تحدد أي كود ينتمي للحلقة.

```python
for i in range(3):
    print("داخل الحلقة")  # 4 مسافات
    print("أيضاً داخل الحلقة")  # 4 مسافات
print("خارج الحلقة")  # بدون مسافات
```

**قاعدة مهمة:** استخدم 4 مسافات أو Tab واحد، وكن منسجماً!
