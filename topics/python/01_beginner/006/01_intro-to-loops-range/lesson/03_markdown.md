# أول حلقة لك

إليك كيفية كتابة حلقة تطبع "مرحبا" خمس مرات:

```python
for i in range(5):
    print("مرحبا")
```

دعني أفسر لك كل جزء:
- `for`: كلمة مفتاحية تخبر Python أننا نريد حلقة
- `i`: متغير مؤقت (يمكن أن نسميه أي شيء)
- `range(5)`: دالة تنشئ الأرقام من 0 إلى 4
- `:`: نهاية سطر الحلقة
- `print("مرحبا")`: الكود الذي سيتكرر
