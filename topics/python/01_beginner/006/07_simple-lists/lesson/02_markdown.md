## إنشاء واستخدام القوائم البسيطة

**القائمة** في Python هي مجموعة مرتبة من العناصر، نضعها بين أقواس مربعة `[]`:

```python
# قائمة أسماء
names = ["أحمد", "فاطمة", "محمد", "عائشة"]

# قائمة أرقام
numbers = [10, 20, 30, 40, 50]

# قائمة فارغة
empty_list = []
```

لطباعة القائمة كاملة:
```python
print(names)
# النتيجة: ['أحمد', 'فاطمة', 'محمد', 'عائشة']
```
