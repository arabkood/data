## التكرار مع الفهارس (Index)

أحياناً نحتاج لمعرفة موقع العنصر في القائمة:

```python
cities = ["الرياض", "جدة", "الدمام", "مكة"]

for i in range(len(cities)):
    print(f"{i + 1}. {cities[i]}")
```

**النتيجة:**
```
1. الرياض
2. جدة  
3. الدمام
4. مكة
```

**شرح:** `len(cities)` يعطي عدد العناصر (4)، و `range(4)` ينتج `[0, 1, 2, 3]`.
