## التعامل مع القوائم المختلطة

يمكن للقوائم أن تحتوي على أنواع مختلفة من البيانات:

```python
mixed_list = ["أحمد", 25, True, "طالب", 3.14]

for item in mixed_list:
    print(f"العنصر: {item}, النوع: {type(item).__name__}")
```

**النتيجة:**
```
العنصر: أحمد, النوع: str
العنصر: 25, النوع: int
العنصر: True, النوع: bool
العنصر: طالب, النوع: str
العنصر: 3.14, النوع: float
```
