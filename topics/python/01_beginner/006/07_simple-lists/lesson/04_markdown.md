## التكرار عبر القوائم باستخدام for

أسهل طريقة للمرور عبر جميع عناصر القائمة:

```python
fruits = ["تفاح", "موز", "برتقال", "عنب"]

for fruit in fruits:
    print(f"أحب أكل {fruit}")
```

**النتيجة:**
```
أحب أكل تفاح
أحب أكل موز  
أحب أكل برتقال
أحب أكل عنب
```

**ملاحظة هامة:** يمكنك استخدام أي اسم متغير بدلاً من `fruit`، مثل `item` أو `element`.
