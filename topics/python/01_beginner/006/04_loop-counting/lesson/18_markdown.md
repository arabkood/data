لقد أتقنت أساسيات العد والتجميع في Python!

**ما تعلمته:**

- البدء بالقيمة الصحيحة (0 للجمع، 1 للضرب)
- تحديث المتغير في كل دورة
- استخدام شروط للتجميع الانتقائي
- بناء النصوص تدريجياً

**القاعدة الذهبية:**

```python
accumulator = initial_value
for item in sequence:
    accumulator = accumulator + item
```

في الدرس القادم، سنتعلم كيف نبني أنماطاً وأشكالاً باستخدام الحلقات!
