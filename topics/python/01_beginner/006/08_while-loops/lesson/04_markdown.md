## البنية الأساسية لحلقة while

```python
while الشرط:
    # الكود الذي سيتكرر
    # تعديل المتغير (مهم جداً!)
```

**مثال بسيط:**
```python
counter = 1
while counter <= 3:
    print(f"العد: {counter}")
    counter += 1  # نزيد العداد

print("انتهت الحلقة!")
```

**النتيجة:**
```
العد: 1
العد: 2
العد: 3
انتهت الحلقة!
```
