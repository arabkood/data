## الفرق بين for و while

### حلقة for - عندما نعرف العدد:
```python
# نعرف أننا نريد 5 تكرارات
for i in range(5):
    print("مرحبا")
```

### حلقة while - عندما لا نعرف العدد:
```python
# نستمر حتى يحدث شيء معين
count = 0
while count < 5:
    print("مرحبا")
    count += 1  # مهم جداً!
```

**النقطة الأساسية:** `while` تتحقق من الشرط قبل كل تكرار، و`for` تعرف عدد التكرارات مسبقاً.
