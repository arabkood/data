## while مع المدخلات من المستخدم

إحدى أقوى استخدامات `while` هي مع المدخلات:

```python
password = ""
while password != "سر123":
    password = input("ادخل كلمة المرور: ")
    if password != "سر123":
        print("كلمة مرور خاطئة، حاول مرة أخرى")

print("مرحباً! تم تسجيل الدخول بنجاح")
```

هذا الكود سيستمر في طلب كلمة المرور حتى يدخل المستخدم الكلمة الصحيحة.
