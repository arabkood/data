## تطبيق شامل: دمج الأنماط 🚀

المبرمجون الماهرون يدمجون هذه الأنماط معاً لحل مشاكل معقدة.

مثال: **تحليل بيانات الطلاب**
```python
students = [
    ("أحمد", 85),
    ("فاطمة", 92), 
    ("محمد", 78),
    ("عائشة", 95)
]

# نمط التصفية + التحويل
top_students = []
for name, grade in students:
    if grade >= 90:  # تصفية
        top_students.append(name.upper())  # تحويل
```
