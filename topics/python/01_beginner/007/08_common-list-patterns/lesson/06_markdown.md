## النمط الثالث: التصفية والفلترة 🎯

**المشكلة:** تريد الحصول على عناصر معينة فقط من القائمة (تلك التي تحقق شرط معين).

**الحل:**
```python
# إنشاء قائمة جديدة للنتائج
filtered_list = []

for item in original_list:
    if condition:  # شرط معين
        filtered_list.append(item)
```

هذا النمط قوي جداً لتنظيم البيانات!
