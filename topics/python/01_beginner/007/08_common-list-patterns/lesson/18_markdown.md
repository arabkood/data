## مرجعك السريع 📋

**الأنماط الخمسة الأساسية:**

🔄 **التكرار والعرض**: `for item in list: print(item)`

🔍 **البحث والإيجاد**: `if target in list` أو استخدام حلقة مع `break`

🎯 **التصفية**: قائمة فارغة + شرط + `append()`

🔄 **التحويل**: تطبيق عملية على كل عنصر → قائمة جديدة

🧮 **الحساب**: متغير مساعد + تجميع في حلقة

**نصيحة ذهبية:** اختر النمط حسب هدفك:
- تريد عرض؟ → التكرار والعرض
- تريد إيجاد؟ → البحث  
- تريد بعض العناصر؟ → التصفية
- تريد تغيير كل العناصر؟ → التحويل
- تريد رقم واحد؟ → الحساب
