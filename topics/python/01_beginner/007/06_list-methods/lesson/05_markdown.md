## طريقة `.pop()` - إزالة وإرجاع عنصر

طريقة `.pop()` تفعل شيئين في نفس الوقت:
1. **تحذف** عنصراً من القائمة
2. **ترجع** ذلك العنصر لتتمكن من استخدامه

```python
colors = ["أحمر", "أزرق", "أخضر"]
last_color = colors.pop()  # يحذف ويرجع "أخضر"
print(last_color)  # أخضر
print(colors)      # ['أحمر', 'أزرق']
```
