## مثال عملي: إدارة سلة التسوق

دعنا نطبق ما تعلمناه في مثال عملي لسلة تسوق:

```python
cart = ["خبز", "حليب"]

# إضافة عناصر جديدة
cart.append("بيض")
cart.append("جبن")

# تغيير الرأي - حذف آخر عنصر
removed = cart.pop()
print(f"قررت عدم شراء: {removed}")

# حذف عنصر محدد
cart.remove("خبز")

print(f"قائمة التسوق النهائية: {cart}")
```
