## طريقة `.remove()` - حذف بالقيمة

أحياناً لا تعرف **فهرس** العنصر، لكن تعرف **قيمته**. هنا تأتي `.remove()`:

```python
animals = ["قط", "كلب", "أرنب", "قط"]
animals.remove("كلب")  # يحذف أول "كلب" يجده
print(animals)  # ['قط', 'أرنب', 'قط']
```

**مهم**: `.remove()` يحذف فقط **أول** تطابق يجده!
