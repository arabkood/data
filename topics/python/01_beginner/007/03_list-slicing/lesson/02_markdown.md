## الحل: تقطيع القوائم! 🔪

**تقطيع القوائم** (List Slicing) يسمح لك بالحصول على **جزء من القائمة** بدلاً من عنصر واحد فقط.

```python
numbers = [10, 20, 30, 40, 50]
first_three = numbers[0:3]
print(first_three)  # [10, 20, 30]
```

لاحظ الصيغة: `قائمة[البداية:النهاية]`

**مهم:** النهاية **غير مشمولة**! `[0:3]` يأخذ العناصر في المواضع 0 و 1 و 2 (لا يشمل 3).
