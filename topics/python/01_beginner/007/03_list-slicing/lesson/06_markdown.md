## الاختصارات المفيدة! ✨

Python يوفر اختصارات رائعة لحالات شائعة:

```python
numbers = [10, 20, 30, 40, 50]

# من البداية حتى موضع معين
first_three = numbers[:3]  # [10, 20, 30]

# من موضع معين حتى النهاية
from_second = numbers[1:]  # [20, 30, 40, 50]

# كامل القائمة (نسخة)
all_copy = numbers[:]  # [10, 20, 30, 40, 50]
```
