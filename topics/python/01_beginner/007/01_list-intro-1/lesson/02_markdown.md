القائمة في Python هي مثل صندوق به أقسام متعددة، كل قسم يحتوي على قيمة.

إليك أول قائمة لك:

```python
grades = [85, 92, 78, 90, 88]
print(grades)
```

**لاحظ:**

- نستخدم الأقواس المربعة `[]` لإنشاء قائمة
- نفصل بين العناصر بفاصلة `,`
- يمكننا طباعة القائمة كاملة بـ `print()`
