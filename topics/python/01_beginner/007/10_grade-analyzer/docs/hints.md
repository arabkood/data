## إذا واجهتك صعوبة، جرب هذه التلميحات

### 1. هيكل البرنامج الأساسي

  ```python
  # قائمة فارغة للدرجات
  grades = []

  # حلقة while للإدخال المستمر
  while True:
      # احصل على المدخل
      # حوله لرقم
      # تحقق من -1
      # تحقق من الصحة
      # أضف للقائمة

  # تحقق إذا القائمة فارغة
  # احسب واطبع الإحصائيات
  ```

### 2. التحقق من صحة الدرجة

  تذكر أن الدرجة الصحيحة يجب أن تكون:

- أكبر من أو تساوي 0
- أصغر من أو تساوي 100

  ```python
  if grade < 0 or grade > 100:
      print("درجة غير صحيحة")
      continue  # تخطى باقي الحلقة وابدأ من جديد
  ```

### 3. حساب الناجحين والراسبين

  استخدم حلقة for مع عداد:

  ```python
  passing = 0
  failing = 0

  for grade in grades:
      if grade >= 60:
          passing = passing + 1
      else:
          failing = failing + 1
  ```

### 4. تنسيق المتوسط

  لطباعة المتوسط بخانتين عشريتين:

  ```python
  average = sum(grades) / len(grades)
  print(f"المتوسط: {average:.2f}")
  ```

### 5. دوال مفيدة

- `len(grades)` - عدد العناصر
- `max(grades)` - أكبر قيمة
- `min(grades)` - أصغر قيمة
- `sum(grades)` - مجموع القيم

### 6. أخطاء شائعة يجب تجنبها

  ❌ **لا تنسى** التحقق من القائمة الفارغة قبل الحسابات
  ❌ **لا تضف** -1 للقائمة
  ❌ **لا تنسى** `continue` بعد طباعة "درجة غير صحيحة"
  ❌ **لا تستخدم** `int()` إذا كنت تريد قبول درجات عشرية
