# 📊 محلل الدرجات

## المهمة

  اكتب برنامجاً لتحليل درجات الطلاب في الصف. البرنامج يجب أن:

  1. **يطلب من المستخدم** إدخال درجات الطلاب واحدة تلو الأخرى
  2. **يتوقف** عند إدخال -1 (لا تضف -1 للدرجات)
  3. **يحسب ويعرض**:
     - عدد الطلاب
     - أعلى درجة
     - أقل درجة
     - المتوسط (لأقرب رقمين عشريين)
     - عدد الطلاب الناجحين (درجة >= 60)
     - عدد الطلاب الراسبين (درجة < 60)

## متطلبات مهمة

- الدرجات يجب أن تكون بين 0 و 100
- إذا أدخل المستخدم درجة غير صحيحة، اطبع "درجة غير صحيحة" واستمر
- إذا لم يتم إدخال أي درجات، اطبع "لم يتم إدخال أي درجات"
- استخدم القوائم والحلقات لحل المشكلة

## مثال على التشغيل

  ```
  أدخل درجة الطالب (-1 للإنهاء): 85
  أدخل درجة الطالب (-1 للإنهاء): 92
  أدخل درجة الطالب (-1 للإنهاء): 150
  درجة غير صحيحة
  أدخل درجة الطالب (-1 للإنهاء): 67
  أدخل درجة الطالب (-1 للإنهاء): 45
  أدخل درجة الطالب (-1 للإنهاء): 73
  أدخل درجة الطالب (-1 للإنهاء): -1

  === تحليل الدرجات ===
  عدد الطلاب: 5
  أعلى درجة: 92
  أقل درجة: 45
  المتوسط: 72.40
  الناجحون: 4
  الراسبون: 1
  ```
