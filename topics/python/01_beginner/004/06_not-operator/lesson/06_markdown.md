### دمج `not` مع المقارنات

يمكنك أيضاً استخدام `not` لعكس نتيجة تعبير مقارنة كامل. من الأفضل دائماً وضع المقارنة بين قوسين `()` لجعل الكود أكثر وضوحاً.

لنفترض أنك تريد التحقق مما إذا كان عمر الشخص **ليس** أكبر من 18 عاماً.

```python
age = 15

# (age > 18) نتيجتها False
# not False نتيجتها True
if not (age > 18):
    print("You are not old enough.") 
```
هذا الشرط `not (age > 18)` يعادل تماماً الشرط `age <= 18`. في بعض الأحيان، استخدام `not` يمكن أن يجعل منطقك أوضح، خاصة مع الشروط المعقدة التي سنتعلمها لاحقاً.
