### استخدام `not` في الشروط

القوة الحقيقية لـ `not` تظهر عندما نستخدمها في جمل `if`. إنها تجعل الكود يبدو أقرب إلى اللغة الإنجليزية الطبيعية.

**الطريقة القديمة (تعمل ولكنها أقل شيوعاً):**
```python
is_logged_in = False
if is_logged_in == False:
    print("Please log in to continue.")
```

**طريقة بايثون الأنيقة (الأكثر تفضيلاً):**
```python
is_logged_in = False
if not is_logged_in:
    print("Please log in to continue.")
```

كلا الكودين يفعلان نفس الشيء تماماً، لكن النسخة الثانية أسهل في القراءة: "إذا لم يكن المستخدم مسجلاً دخوله...".
