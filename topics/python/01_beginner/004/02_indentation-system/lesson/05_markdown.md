**القاعدة الذهبية: كن متسقًا!**

الاتفاق الشائع بين مبرمجي بايثون هو استخدام **4 مسافات** لكل مستوى من مستويات المسافة البادئة.

إذا بدأت كتلة بـ 4 مسافات، فيجب أن تكون جميع الأسطر الأخرى في تلك الكتلة مزاحة بـ 4 مسافات أيضًا. عدم الاتساق سيؤدي إلى خطأ.

```python
# صحيح ✅
if True:
    print("السطر الأول")
    print("السطر الثاني")

# خاطئ ❌ (مسافات غير متسقة)
if True:
    print("السطر الأول")
      print("السطر الثاني") # <-- هذا سيسبب خطأ
```
