في بايثون، هذه المجموعة من الأسطر المزاحة للداخل تسمى **كتلة الكود (Code Block)**.

عندما نكتب جملة `if`، فإن المسافة البادئة تخبر بايثون بالضبط أي الأسطر يجب تنفيذها إذا كان الشرط `True`. كل الأسطر التي لها نفس مستوى الإزاحة تحت `if` تعتبر جزءًا من نفس الكتلة.

```python
# هذا ليس جزءًا من كتلة if
if condition:
    # هذا السطر جزء من الكتلة
    # وهذا السطر أيضًا جزء من نفس الكتلة
# وهذا السطر ليس جزءًا من الكتلة لأنه عاد إلى اليسار
```
