ماذا عن الكتل داخل الكتل؟

بالطبع يمكنك فعل ذلك! وهذا ما يجعل البرمجة قوية جدًا. إذا وضعت جملة `if` داخل جملة `if` أخرى، فإن كتلة الكود الداخلية تحصل على مستوى آخر من المسافة البادئة.

```python
# المستوى 0 (لا توجد مسافة بادئة)
if condition_A:
    # المستوى 1 (4 مسافات)
    print("الشرط A صحيح")
    if condition_B:
        # المستوى 2 (8 مسافات)
        print("الشرط B صحيح أيضًا")
```
هذا يوضح التسلسل الهرمي بشكل مرئي.
