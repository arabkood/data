في الدرس السابق، هل لاحظت كيف أن سطر `print()` داخل جملة `if` كان مزاحًا قليلاً إلى اليمين؟

```python
is_sunny = True

if is_sunny:
    print("يا له من يوم جميل!") # <-- هذا السطر
```
هذه الإزاحة تسمى **المسافة البادئة (Indentation)**، وفي بايثون، هي ليست مجرد اختيار للتنسيق، بل هي قاعدة أساسية ومهمة جدًا!
