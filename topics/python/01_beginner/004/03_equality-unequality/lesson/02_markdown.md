أبسط سؤال يمكننا طرحه هو: "هل هاتان القيمتان متساويتان؟"

في بايثون، نطرح هذا السؤال باستخدام علامتي يساوي متتاليتين: `==`.

`5 == 5`   # هل 5 تساوي 5؟ -> الإجابة: True
`10 == 7`  # هل 10 تساوي 7؟ -> الإجابة: False

هذا يسمى **عامل المقارنة (Comparison Operator)**. إنه يأخذ قيمتين ويقارنهما، ثم "يعيد" قيمة بولينية.
