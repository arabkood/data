يمكننا أيضًا استخدام `==` لمقارنة النصوص (strings). تعمل بنفس الطريقة، ولكن مع ملاحظة هامة: **المقارنة حساسة لحالة الأحرف**.

- `"hello" == "hello"`  -> True

- `"Ahmed" == "Saleh"`  -> False

- `"Python" == "python"` -> False ('P' تختلف عن 'p')

- `987 == 987` -> True

- `987 == "987"` -> False (لأن نوع القيمة مختلف)
