الآن، ماذا يحدث إذا كان الشرط `False`؟

```python
is_enemy_near = False

if is_enemy_near:
    print("استعد للقتال!") # هذا السطر سيتم تخطيه

print("كل شيء هادئ.")
```
**ماذا سيحدث هنا؟**
1.  يتحقق `if` من `is_enemy_near`، ويجدها `False`.
2.  لأنها `False`، يتم **تخطي** الكود ذي المسافة البادئة بالكامل.
3.  ينتقل البرنامج مباشرة إلى السطر التالي بعد كتلة `if` ويطبع "كل شيء هادئ.".
