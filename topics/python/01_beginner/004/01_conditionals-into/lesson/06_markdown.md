هيكل جملة `if` بسيط جدًا:

1.  الكلمة المفتاحية `if`.
2.  الشرط الذي يتم التحقق منه (الذي يجب أن يكون `True` أو `False`).
3.  نقطتان رأسيتان `:`.
4.  سطر (أو أسطر) من الكود بمسافة بادئة (Indented).

```python
if condition:
    # هذا الكود يُنفذ فقط إذا كان الشرط True
    # لاحظ المسافة في بداية السطر
```
المسافة البادئة (Indentation) مهمة جدًا في بايثون. إنها الطريقة التي يعرف بها بايثون أن هذا الكود "يتبع" جملة `if`. سنتحدث عنها أكثر لاحقًا!
