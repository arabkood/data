لنرى مثالاً عمليًا. في هذا الكود، الشرط هو `True` بشكل مباشر.

```python
player_has_shield = True

if player_has_shield:
    print("درعك يصد الهجوم!")

print("المعركة مستمرة...")
```
**ماذا سيحدث؟**
1.  يتحقق `if` من `player_has_shield`، ويجدها `True`.
2.  لأنها `True`، يتم تنفيذ الكود ذي المسافة البادئة وتُطبع رسالة "درعك يصد الهجوم!".
3.  يستمر البرنامج ويطبع "المعركة مستمرة..." لأن هذا السطر ليس جزءًا من جملة `if` (لا توجد مسافة بادئة).
