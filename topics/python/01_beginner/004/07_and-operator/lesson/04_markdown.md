### `and` في العمل

لنعد إلى مثال تسجيل الدخول. هكذا سيبدو في بايثون:

```python
username = "user123"
password = "secret_password"

# التحقق من كلا الشرطين معاً
if username == "user123" and password == "secret_password":
    print("تم تسجيل الدخول بنجاح!")
else:
    print("اسم المستخدم أو كلمة المرور غير صحيحة.")
```

في هذا المثال، بما أن كلا الشرطين صحيحان، ستتم طباعة رسالة الترحيب. لو كان أي منهما خاطئاً، لكانت كتلة `else` هي التي ستُنفذ.
