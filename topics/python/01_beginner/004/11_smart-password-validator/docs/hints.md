### 1. بنية الكود

قسّم المشكلة إلى ثلاثة أجزاء: `if` للباب الأحمر، `if` للباب الأزرق، و `if` للاختيار الخاطئ.

### 2. تحويل المدخلات

الذهب هو رقم، ولكن `input()` يعطيك نصًا. تذكر استخدام `int()`.

### 3. الشروط المتداخلة

القرار الثاني (عن الذهب أو اليوم) يجب أن يكون **داخل** القرار الأول. استخدم المسافة البادئة.

```python
if condition_one:
    # <-- مسافة بادئة
    if condition_two:
        # <-- مسافة بادئة إضافية
        ...
```

### 4. التحقق من الاختيار الخاطئ

إذا أردت أن تتأكد أن الإجابة ليست "أحمر" وليست "أزرق"، ستحتاج لشرط يجمع حالتين معًا. تذكّر أنه يمكنك استخدام الكلمة `and` في بايثون لربط شرطين.

الشرط المطلوب هو:

> إذا كانت الإجابة **لا تساوي** أحمر **و**  **لا تساوي** أزرق

### 5. دقة النصوص

الاختبارات حساسة جدًا. انسخ والصق نصوص الأسئلة والأجوبة تمامًا كما هي مطلوبة.
