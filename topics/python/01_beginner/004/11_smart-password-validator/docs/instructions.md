# تحدي: باب المغامرة الذكي

اكتب برنامج مغامرة نصية قصيرة. البرنامج يسأل اللاعب أسئلة، وبحسب إجاباته يطبع النتيجة.

## المطلوب

1. أول سؤال يجب أن يكون:

   ```
   أمامك بابان، باب أحمر وباب أزرق. أي واحد تختار؟ (أحمر/أزرق)
   ```

2. إذا اختار `"أحمر"`:

   * اسأله:

     ```
     كم لديك من الذهب؟
     ```

   * إذا كان الذهب `>= 50`: اطبع

     ```
     لقد قمت برشوة الحارس ومررت بأمان!
     ```

   * إذا كان الذهب `< 50`: اطبع

     ```
     الحارس يضحك منك ويلقيك في الزنزانة.
     ```

3. إذا اختار `"أزرق"`:

   * اسأله:

     ```
     ما هو اليوم من أيام الأسبوع؟
     ```

   * إذا كان اليوم `"الثلاثاء"`: اطبع

     ```
     الباب السحري يفتح لك!
     ```

   * غير ذلك: اطبع

     ```
     الباب يبقى مغلقاً بإحكام.
     ```

4. إذا لم يكتب `"أحمر"` أو `"أزرق"`, اطبع:

   ```
   لقد ترددت طويلاً وتحولت إلى حجر.
   ```
