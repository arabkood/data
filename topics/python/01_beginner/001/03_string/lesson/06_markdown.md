هل تتذكر المتغيرات من الدرس الماضي؟ إنها تعمل بشكل مثالي مع النصوص. يمكنك تخزين أي نص في `متغير` واستخدامه لاحقًا:

```python
الاسم_الأول = "عمر"
اسم_العائلة = "أحمد"
المدينة = "القاهرة"

print(الاسم_الأول)
print(اسم_العائلة)
print(المدينة)
```

هذا الكود ينشئ ثلاثة متغيرات نصية، كل منها يحتوي على نص مختلف.
