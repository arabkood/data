# ☕ نظام طلبات المقهى

مرحباً بك في أول تحدٍ برمجي لك! ستقوم بإنشاء نظام بسيط لطلبات المقهى باستخدام كل ما تعلمته حتى الآن.

## مهمتك

دخل زبون إلى المقهى الخاص بك وقدم طلبًا. أنت بحاجة إلى:

1. تخزين مشروب الزبون في `متغير` اسمه `drink`.
2. تخزين سعر المشروب كـ `رقم` في `متغير` اسمه `price`.
3. إضافة إكرامية بقيمة 2$ إلى سعر المشروب.
4. عرض معلومات الطلب الكاملة.

## المخرجات المتوقعة

```
- المشروب:
لاتيه
- السعر:
6.50
- الإكرامية:
2
- الإجمالي:
8.50
```

## المتطلبات

- استخدم **`متغيرات`** لجميع المعلومات مع أنواع البيانات الصحيحة (`نصوص` للكلام، و`أرقام` للأسعار).
- استخدم `الدالة` `print()` لعرض كل معلومة.
