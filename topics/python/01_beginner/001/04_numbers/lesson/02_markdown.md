تذكر الفرق الرئيسي بين الأرقام والنصوص: **الأرقام لا تحتاج إلى علامات اقتباس**.

```python
age = 25          # هذا رقم
price = 19.99     # هذا أيضًا رقم
pi = 3.14159      # رقم آخر
```

قارن هذا بالنصوص:

```python
name = "Fatima"    # هذا نص
year = "2026"      # هذا نص يحتوي على رقم
```

عندما تضع علامات اقتباس حول الأرقام، فإنها تصبح نصوصًا، وليست أرقامًا يمكنك إجراء عمليات حسابية عليها.
