Here's where numbers get exciting! You can do math with them using these symbols:

- `+` for addition
- `-` for subtraction
- `*` for multiplication
- `/` for division

```python
result = 10 + 5    # result = 15
difference = 20 - 8  # difference = 12
product = 6 * 7    # product = 42
quotient = 15 / 3  # quotient = 5.0
```
