# دوال الآلة الحاسبة

## المطلوب

اكتب 4 دوال لإجراء عمليات حسابية أساسية.

### الدوال المطلوبة

1. **add(a, b)**: تُرجع مجموع رقمين
2. **subtract(a, b)**: تُرجع الفرق بين رقمين (a - b)
3. **multiply(a, b)**: تُرجع حاصل ضرب رقمين
4. **divide(a, b)**: تُرجع ناتج القسمة (a / b)

### ثم

- اختبر كل دالة بطباعة النتيجة
- مثال:

  ```python
  print(add(10, 5))       # 15
  print(subtract(10, 5))  # 5
  print(multiply(10, 5))  # 50
  print(divide(10, 5))    # 2.0
  ```

### مثال على المخرجات

```
15
5
50
2.0
```

### ملاحظات

- كل دالة يجب أن تستخدم `return` وليس `print`
