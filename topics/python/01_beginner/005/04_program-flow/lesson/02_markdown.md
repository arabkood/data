دعنا نتتبع مسار تنفيذ بسيط معاً، ونتخيل أننا الكمبيوتر.

```python
status = "online"
friend_count = 55

print("بدء فحص الملف الشخصي...")

if status == "offline":
    print("المستخدم غير متصل.")
elif status == "online":
    print("المستخدم متصل الآن.")

if friend_count > 50:
    print("لديه شبكة واسعة من الأصدقاء.")

print("...فحص الملف الشخصي انتهى.")
```

**تحليل التنفيذ:**
1.  `status` يصبح "online".
2.  `friend_count` يصبح 55.
3.  **الناتج:** "بدء فحص الملف الشخصي..."
4.  هل `status == "offline"`؟ **خطأ**. نتجاهل الكود الخاص بها.
5.  هل `status == "online"`؟ **صحيح**. ندخل وننفذ الكود.
6.  **الناتج:** "المستخدم متصل الآن."
7.  هل `friend_count > 50`؟ **صحيح**. ندخل وننفذ الكود.
8.  **الناتج:** "لديه شبكة واسعة من الأصدقاء."
9.  **الناتج:** "...فحص الملف الشخصي انتهى."
