هذه النقطة الأخيرة هي من أهم المفاهيم في التحكم بالتدفق!

**`if / elif / else`** -> سلسلة مترابطة. مثل مفترق طرق متعدد الخيارات. أنت تختار **مساراً واحداً فقط**.

**`if` ... `if` ... `if`** -> عدة أسئلة منفصلة. مثل قائمة تحقق. أنت تجيب على كل سؤال على حدة.

انظر إلى الفرق الهائل في السلوك بين هذين الكودين:

```python
# الحالة الأولى: elif (سؤال واحد، إجابة واحدة)
score = 95
if score >= 90:
  print("ممتاز")
elif score >= 50:
  print("جيد") 
# الناتج: "ممتاز"
```

```python
# الحالة الثانية: if مستقلة (سؤالان، إجابتان محتملتان)
score = 95
if score >= 90:
  print("ممتاز")
if score >= 50:
  print("جيد")
# الناتج:
# ممتاز
# جيد
```
فهم هذا الفرق هو مفتاح بناء منطق صحيح وغير متضارب.
