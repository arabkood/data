### التقنية الثانية: "الشروط الحارسة" (Guard Clauses)

هل سئمت من الشروط المتداخلة التي تجعل كودك يبدو كسلم طويل؟

```python
# الطريقة المتداخلة (صعبة القراءة)
if user is not None:
  if user.is_active:
    # ... افعل شيئاً مهماً هنا ...
  else:
    print("خطأ: المستخدم غير نشط")
else:
  print("خطأ: لا يوجد مستخدم")
```

"الشرط الحارس" هو أسلوب يقلب هذا المنطق. أنت تتحقق من كل الحالات السيئة أو الشاذة **أولاً** وتخرج مبكراً. هذا يترك الجزء الرئيسي من الكود نظيفاً وغير متداخل.

```python
# طريقة الشرط الحارس (أسهل للقراءة)
if user is None:
  print("خطأ: لا يوجد مستخدم")
elif not user.is_active:
  print("خطأ: المستخدم غير نشط")
else:
  # ... افعل شيئاً مهماً هنا ...
  # الكود الرئيسي واضح الآن!
```
