### التقنية الثالثة: العامل الثلاثي (Ternary Operator)

في بعض الأحيان، تكون جملة `if/else` بأكملها مخصصة فقط لتعيين قيمة لمتغير واحد.
```python
if is_logged_in:
  status_message = "أهلاً بعودتك"
else:
  status_message = "يرجى تسجيل الدخول"
```
العامل الثلاثي هو اختصار أنيق لكتابة هذا في سطر واحد.

**الصيغة:** `value_if_true if condition else value_if_false`

```python
status_message = "أهلاً بعودتك" if is_logged_in else "يرجى تسجيل الدخول"
```
اقرأها هكذا: "ستكون الرسالة 'أهلاً بعودتك' **إذا كان** المستخدم مسجلاً دخوله، **وإلا** ستكون 'يرجى تسجيل الدخول'".
