```python
if condition_outer:
    # هذا الكود يُنفذ إذا كان الشرط الخارجي صحيحاً

    if condition_inner:
        # هذا الكود يُنفذ فقط إذا كان كلا الشرطين (الخارجي والداخلي) صحيحين
```

فكر فيها كصناديق داخل صناديق. لا يمكنك الوصول إلى الصندوق الداخلي إلا بعد فتح الصندوق الخارجي أولاً.
