يمكن أن تحتوي الشروط المتداخلة أيضاً على `else` خاصة بها. كل عبارة `else` تتبع `if` التي على **نفس مستوى المسافة البادئة**.

```python
age = 20
has_license = False

if age >= 18:  # المستوى الأول
    print("العمر مناسب للقيادة.")

    if has_license:  # المستوى الثاني
        print("يمكنك القيادة.")
    else:  # تتبع if المستوى الثاني
        print("لكنك تحتاج إلى رخصة قيادة!")

else:  # تتبع if المستوى الأول
    print("أنت صغير جداً على القيادة.")
```
لاحظ كيف أن كل `else` مقترنة بـ `if` التي تسبقها مباشرة وعلى نفس المستوى.
