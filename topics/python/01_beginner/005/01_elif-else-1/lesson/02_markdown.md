للتعامل مع أكثر من خيارين، تقدم بايثون لنا `elif`. هي اختصار لـ "else if" (وإلا إذا).

تسمح لك `elif` بطرح سؤال آخر **فقط إذا كان شرط `if` الأول خاطئاً (`False`)**.

هكذا تبدو البنية:
```python
if condition_1:
  # نفّذ هذا الكود إذا كان الشرط الأول صحيحاً
elif condition_2:
  # نفّذ هذا الكود إذا كان الشرط الأول خاطئاً والثاني صحيحاً
```
