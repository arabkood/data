ممتاز! ولكن ماذا عن الضوء الأحمر؟ يمكننا إضافة `elif` أخرى، ولكن ماذا لو أردنا إجراءً افتراضياً لـ**كل الحالات الأخرى**؟

هنا يأتي دور `else` (وإلا). إنها بمثابة "الشبكة الأخيرة" التي تلتقط كل شيء. يتم تنفيذ الكود الموجود داخل `else` إذا كانت **جميع** شروط `if` و `elif` السابقة خاطئة (`False`).

**نقطة مهمة:** `else` لا تأخذ شرطاً أبداً، لأنها تتعامل مع "كل ما تبقى".

```python
if condition_1:
  # ...
elif condition_2:
  # ...
else:
  # نفّذ هذا الكود إذا كانت كل الشروط السابقة خاطئة
```
