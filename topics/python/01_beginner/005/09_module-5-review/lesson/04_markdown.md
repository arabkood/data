### **القرارات داخل القرارات (التداخل)**

تذكرنا أن الحياة ليست دائماً بسيطة. في بعض الأحيان، يعتمد قرار على نتيجة قرار آخر. هذا هو المكان الذي نستخدم فيه **الشروط المتداخلة**، حيث نضع `if` داخل `if` أخرى.

المفتاح هنا هو **المسافة البادئة (Indentation)**. هي التي تخبر بايثون أي قرار يتبع أي قرار آخر.

```python
# مراجعة من الوحدة 3: الحصول على المدخلات وتحويلها
age_input = input("ادخل عمرك: ")
age = int(age_input)

# منطق متداخل
if age >= 18:
  print("مرحباً بك.")
  if age >= 65:
    print("لديك خصم لكبار السن.")
else:
  print("الدخول للكبار فقط.")
```
هنا، لن نتحقق أبداً من خصم كبار السن إلا إذا تم استيفاء شرط العمر 18+ أولاً.
