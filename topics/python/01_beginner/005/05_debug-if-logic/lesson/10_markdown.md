3.  **راجع الترتيب:** هل شروط `elif` مرتبة من الأكثر تحديداً إلى الأكثر عمومية؟
4.  **استخدم `print()`:** عندما تشك في شيء، اطبعه! شاهد قيم متغيراتك لتتبع مسار تنفيذ برنامجك.
