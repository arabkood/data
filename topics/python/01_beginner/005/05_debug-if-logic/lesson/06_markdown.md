### **الخطأ الشائع الثالث: الترتيب الخاطئ في `if/elif`**

لقد ناقشنا هذا من قبل، لكنه سبب شائع جداً للأخطاء المنطقية. تذكر دائماً: بايثون تنفذ **أول شرط صحيح** تجده وتتجاهل الباقي.

إذا وضعت شرطاً عاماً (مثل `num > 10`) قبل شرط أكثر تحديداً (مثل `num > 100`)، فإن الشرط الأكثر تحديداً لن يتم الوصول إليه أبداً!
