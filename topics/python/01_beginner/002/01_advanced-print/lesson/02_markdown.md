## طباعة عدة أشياء

بدلاً من كتابة عدة جمل طباعة:

```python
name = "نورة"
age = 25
print("الاسم:")
print(name)
print("العمر:")
print(age)
```

**الناتج:**

```
الاسم:
نورة
العمر:
25
```

**يمكنك طباعة كل شيء في سطر واحد** عبر فصل العناصر بفاصلات (,):

```python
name = "نورة"
age = 25
print("الاسم:", name, "العمر:", age)
```

**الناتج:**

```
الاسم: نورة العمر: 25
```
