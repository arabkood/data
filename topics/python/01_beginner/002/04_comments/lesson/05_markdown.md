`التعليقات` لها قوة خارقة أخرى: تسمح لك "بإيقاف" سطر من `الكود` مؤقتًا دون حذفه.

تُسمى هذه العملية **التعطيل بالتعليق** (`commenting out`) وهي مفيدة بشكل لا يصدق للاختبار وتصحيح الأخطاء.

```python
print("جاري تحميل الموارد...")
# print("تم تعطيل هذه الرسالة مؤقتًا.")
print("جاهز!")
```

عند تشغيل هذا `الكود`، سيتم طباعة "جاري تحميل الموارد..." و "جاهز!" فقط.
