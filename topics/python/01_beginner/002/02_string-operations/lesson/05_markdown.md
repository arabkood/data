## إضافة المسافات والمزيد

تذكر، عند ربط النصوص باستخدام `+`، لا تضيف بايثون مسافات تلقائيًا. **يجب عليك إضافتها بنفسك.**

إليك بعض الأنماط الشائعة:

```python
# إضافة مسافات
result = "مرحباً" + " " + "بالعالم"

# أو قم بتضمين المسافات في نصوصك
result = "مرحباً " + "بالعالم"

# مزج المتغيرات والنصوص
name = "نورة"
message = "أهلاً بكِ يا " + name + " في موقعنا!"
```
