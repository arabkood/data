## دمج النصوص: فن الربط

في بايثون، يمكنك ربط النصوص معًا باستخدام عامل التشغيل `+`. يُطلق على هذه العملية اسم **دمج النصوص** (`concatenation`).

إليك كيف تعمل:

```python
first_name = "أحمد"
last_name = "سالم"
full_name = first_name + last_name
print(full_name)
```

لكن انتظر! هذا سيطبع "أحمدسالم" بدون مسافة. دعنا نصلح ذلك:

```python
full_name = first_name + " " + last_name
print(full_name)  # يطبع الآن: أحمد سالم
```

إن ` " "` هو `نص` يحتوي على مسافة فقط - لكنه لا يزال `نصًا`!
