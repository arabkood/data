### **Module 4: Code Recipes: Creating Reusable Blocks with Functions**

**Module Theme:** This module introduces the single most important organizational tool in programming: the function. The user will learn how to stop repeating themselves, package their code into reusable "recipes," and create blocks of logic that can accept inputs and produce outputs—the key to solving challenges and building applications.

---

**Item 4.1: Your First Recipe: Defining and Calling a Function**

- **Narrative Hook:** Writing the same code over and over is slow and error-prone. Let's learn the programmer's secret to being efficient: packaging instructions into a reusable recipe, called a function, that you can use anytime you want.
- **New Concept(s):** `function` keyword, function declaration, function invocation (calling a function `()`)
- **Builds On:** All previous concepts (as functions can contain any code)

**Item 4.2: Customizing Your Recipe: Adding Parameters**

- **Narrative Hook:** A recipe that always makes the exact same cake is not very useful. Let's learn how to create flexible functions that can accept "ingredients" (data) to produce different results each time they are run.
- **New Concept(s):** `parameters` (the placeholders), `arguments` (the actual values)
- **Builds On:** Defining and calling functions

**Item 4.3: Getting a Result: The `return` Statement**

- **Narrative Hook:** So far, our functions just _do_ things. But what if we need to get a value _back_ from them to use elsewhere? This is the most crucial step for building testable code and the key to solving our upcoming challenges.
- **New Concept(s):** The `return` keyword, difference between `console.log` (displaying) and `return` (outputting)
- **Builds On:** Function parameters

**Item 4.4: The Silent Treatment: Functions without `return`**

- **Narrative Hook:** A common bug appears when you expect a function to give you something back, but it gives you... nothing. Let's investigate what JavaScript gives you by default and how to avoid this silent but confusing problem.
- **New Concept(s):** Implicit `return undefined`
- **Builds On:** `return` keyword

**Item 4.5: The Modern Shortcut: Arrow Functions**

- **Narrative Hook:** As you look at modern code, you'll see a sleek, compact way of writing functions using a `=>`. Let's learn this popular syntax so you can write code like a professional and understand the code of others.
- **New Concept(s):** Arrow Function syntax (`=>`)
- **Builds On:** Classic functions, parameters, return

**Item 4.6: The Function Bubble: An Introduction to Scope**

- **Narrative Hook:** Imagine an invisible wall around your function that keeps its variables private. This "function bubble" is a critical feature that prevents chaos in your programs. Let's learn why what happens in the function, stays in the function.
- **New Concept(s):** Function Scope (at a high level)
- **Builds On:** `let`/`const`, functions

**Item 4.7: `code` - Milestone: The Temperature Converter**

- **Narrative Hook:** You've mastered the theory of creating code recipes. Now, build a practical tool. Create a function that takes a temperature in Celsius as an input and returns the correct temperature in Fahrenheit. This is your first test as a tool-builder.
- **New Concept(s):** _Synthesis of all module concepts_
- **Builds On:** All previous items in Module 4
