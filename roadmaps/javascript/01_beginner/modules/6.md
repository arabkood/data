### **Module 6: A Deeper Look: Modeling Data with Objects**

**Module Theme:** This module moves beyond simple lists to structured data. The user will learn how to represent a single "thing" with multiple descriptive properties (like a user profile or a product listing) using Objects. This is the key to organizing complex information in a logical, human-readable way.

---

**Item 6.1: Beyond the List: Introduction to Objects**

- **Narrative Hook:** An array is great for a list of names, but how would you represent a single person with a name, an age, AND a city? Let's learn about Objects, the perfect tool for storing related information under descriptive labels.
- **New Concept(s):** Object literal syntax (`{}`), key-value pairs.
- **Builds On:** All data types (a value can be a string, number, boolean, etc.).

**Item 6.2: Reading the Profile: Accessing Properties with Dot Notation**

- **Narrative Hook:** You've created your first data object. Now, how do you retrieve a specific piece of information from it, like the user's email? Let's learn the most common and direct way: Dot Notation.
- **New Concept(s):** Dot Notation (`.`) to read property values.
- **Builds On:** Object creation.

**Item 6.3: Dynamic Data: Updating & Adding Properties**

- **Narrative Hook:** Real-world data changes. A user gets older, a product's price is updated. Learn how to modify the values in your objects and even add new key-value pairs on the fly.
- **New Concept(s):** Using dot notation with the assignment operator (`=`) to modify and add properties.
- **Builds On:** Dot Notation.

**Item 6.4: The Other Key: Accessing Properties with Bracket Notation**

- **Narrative Hook:** What if a property name has a space in it, or what if you need to access a property whose name is stored in a variable? Dot notation can't help here. Let's learn about its flexible cousin: Bracket Notation.
- **New Concept(s):** Bracket Notation (`[]`) for accessing properties with strings or variables.
- **Builds On:** Dot Notation, Variables.

**Item 6.5: Objects with Behavior: Introduction to Methods**

- **Narrative Hook:** Your objects can store data, but what if they could also perform actions? Let's level up our objects by giving them their own built-in functions, turning them from simple data containers into powerful, active tools.
- **New Concept(s):** Methods (defining functions as property values within an object).
- **Builds On:** Functions, Objects.

**Item 6.6: The Ultimate Combo: Arrays of Objects**

- **Narrative Hook:** This is the pattern you'll see everywhere. A single object is good; a list of them is powerful. Let's combine our knowledge of Arrays and Objects to manage a list of user profiles, the most common data structure in web development.
- **New Concept(s):** Nesting objects inside arrays, chaining accessors (`array[i].property`).
- **Builds On:** Arrays, Objects, Loops.

**Item 6.7: `code` - Milestone: The User Database Search**

- **Narrative Hook:** You are the keeper of a small user database (an array of user objects). Your task is to build a search function. This function will receive the database and a user's email as input, and you must find and return the entire object for the user who matches that email.
- **New Concept(s):** _Synthesis of all module concepts._
- **Builds On:** All previous items in Module 6, Functions, Loops.
