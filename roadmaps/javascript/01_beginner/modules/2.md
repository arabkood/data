### **Module 2: Building Blocks of a Program: Data & Variables**

**Module Theme:** This module moves the user from simply executing commands to actively managing information. We will introduce the fundamental "ingredients" of any program (data types) and give them a home (variables). The pace is deliberate, ensuring each concept is fully understood before the next is introduced. The module culminates in a challenge that synthesizes all these new skills.

---

**Item 2.1: The Atoms of Code: Text & Numbers**

- **Narrative Hook:** You've told the computer _what to do_, but to build anything interesting, you must also tell it what _kind of information_ to work with. Let's learn the difference between plain text and numbers.
- **New Concept(s):** `string`, `number`
- **Builds On:** `console.log`

**Item 2.2: Memory Boxes: Storing Data with `let`**

- **Narrative Hook:** Your data disappears the moment it's used. To build a real program, you need a way to store information in memory so you can use it again later. Learn to create your first variable.
- **New Concept(s):** `let`, Assignment Operator (`=`)
- **Builds On:** `string`, `number`

**Item 2.3: Set in Stone: Creating Unchanging Constants**

- **Narrative Hook:** Some data, like a birth date or a server address, should never change by accident. Learn how to protect your most important information by creating constants.
- **New Concept(s):** `const`
- **Builds On:** `let`

**Item 2.4: The Rulebook: How to Name Your Variables**

- **Narrative Hook:** Giving your data a name is a superpower, but with great power comes great responsibility. Learn the essential rules for naming variables so both the computer and other humans can understand them.
- **New Concept(s):** Variable Naming Rules, `camelCase`
- **Builds On:** `let`, `const`

**Item 2.5: The Storyteller: Weaving Data into Text**

- **Narrative Hook:** Combining text and variables with `+` is clumsy. Learn the modern, clean, and professional way to craft dynamic messages using template literals. It's a trick that will make your code beautiful.
- **New Concept(s):** `Template Literals`
- **Builds On:** `string`, `let`, `const`

**Item 2.6: The Decision Maker: Booleans & Comparisons**

- **Narrative Hook:** To make a program "smart," it needs to answer yes/no questions. Learn about the `boolean` data type and the comparison operators that allow you to ask questions like "is this value equal to that value?"
- **New Concept(s):** `boolean`, Comparison Operators (`===`, `!==`, `>`, `<`)
- **Builds On:** `let`, `const`

**Item 2.7: The Investigator: Spotting the 'Equals' Bug**

- **Narrative Hook:** There is one bug that every single new developer makes, and it's one of the hardest to see. In this lesson, we'll teach you how to spot and fix the infamous assignment-vs-comparison bug.
- **New Concept(s):** Assignment (`=`) vs. Strict Equality (`===`)
- **Builds On:** `boolean`, `comparison operators`

**Item 2.8: The Void: Understanding `null` & `undefined`**

- **Narrative Hook:** What happens when a box is empty? In JavaScript, there are two ways to say "nothing." Learn the subtle but important difference between an intentionally empty value (`null`) and a value that was never set (`undefined`).
- **New Concept(s):** `null`, `undefined`
- **Builds On:** `let`

**Item 2.9: `code` - Milestone: The User Profile Card**

- **Narrative Hook:** You've learned to create, store, and compare data. Now it's time to put it all together. Build a simple "user profile card" by creating variables and combining them into a final output. This is your first real program.
- **New Concept(s):** _Synthesis of all module concepts_
- **Builds On:** All previous concepts in Module 2
