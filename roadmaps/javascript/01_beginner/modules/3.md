### **Module 3: A Fork in the Road: Making Decisions in Code**

**Module Theme:** This module is where the user's code comes to life. They will move beyond writing a simple list of instructions and learn to create dynamic programs that can react and behave differently based on specific conditions. We are teaching the fundamentals of logic and decision-making.

---

**Item 3.1: The First Decision: The `if` Statement**

- **Narrative Hook:** Your program can answer questions like "is the user's age greater than 18?". Now, let's teach it how to _perform an action_ only if the answer is `true`. This is the first step to creating intelligent code.
- **New Concept(s):** `if` statement, code blocks `{}`
- **Builds On:** `boolean`, Comparison Operators

**Item 3.2: The "Otherwise" Path: Adding `else`**

- **Narrative Hook:** What happens when a condition is false? Right now, nothing. An `if` statement is a one-way street. Let's learn how to provide an alternative path for our program to follow when the answer is 'no'.
- **New Concept(s):** `else` statement
- **Builds On:** `if` statement

**Item 3.3: Multiple Choices: Chaining with `else if`**

- **Narrative Hook:** Life is rarely a simple yes/no choice. Often, there are many possible outcomes. Let's upgrade our decision-making skills to handle a chain of conditions, from most important to least.
- **New Concept(s):** `else if` statement
- **Builds On:** `if`/`else`

**Item 3.4: Combining Conditions: The `&&` (AND) Operator**

- **Narrative Hook:** To make truly smart decisions, you often need to check if multiple things are true at once. "Is the user logged in AND are they a premium subscriber?" Let's learn how to combine questions.
- **New Concept(s):** Logical AND (`&&`)
- **Builds On:** `if`/`else`

**Item 3.5: Providing Alternatives: The `||` (OR) Operator**

- **Narrative Hook:** Sometimes, you only need _one_ of several conditions to be true. "Does the user have a coupon OR is it a holiday sale?" Learn to give your program more flexibility by checking for multiple possibilities.
- **New Concept(s):** Logical OR (`||`)
- **Builds On:** Logical AND (`&&`)

**Item 3.6: Opposite Day: The `!` (NOT) Operator**

- **Narrative Hook:** Sometimes it's much easier to describe what you _don't_ want. "If the user is NOT an admin...". Learn how to instantly flip any `true` to `false` (and vice-versa) with this powerful logical tool.
- **New Concept(s):** Logical NOT (`!`)
- **Builds On:** `boolean`, `&&`, `||`

**Item 3.7: A Cleaner Choice: The `switch` Statement**

- **Narrative Hook:** A long chain of `else if` statements all checking the same variable can look messy. Let's learn about the `switch` statement, a special tool designed to elegantly handle exactly this kind of situation.
- **New Concept(s):** `switch`, `case`, `break`, `default`
- **Builds On:** `if`/`else if`

**Item 3.8: `code` - Milestone: The Grade Calculator**

- **Narrative Hook:** You have mastered the art of making decisions in code. Now, prove your skills. Build a program that takes a student's numerical score and correctly assigns them a letter grade (A, B, C, D, or F) based on standard grading rules.
- **New Concept(s):** _Synthesis of all module concepts_
- **Builds On:** All previous items in Module 3.
