### **Module 5: The Power of Lists: Arrays and Loops**

**Module Theme:** Programs rarely deal with just one piece of information. This module unlocks the ability to work with collections of data. The user will learn how to store lists of items in Arrays and how to perform actions on every item in that list using the power of Loops, a cornerstone of automation.

---

**Item 5.1: The Shopping List: Introduction to Arrays**

- **Narrative Hook:** How would you store a list of your ten favorite movies? Creating ten different variables is a nightmare. Let's learn about Arrays, the JavaScript tool for storing ordered lists of data in a single variable.
- **New Concept(s):** Array literal syntax (`[]`), storing mixed data types.
- **Builds On:** `let`, `const`, all data types.

**Item 5.2: Finding an Item: Accessing Array Elements**

- **Narrative Hook:** You have a list, but how do you get just the first item? Or the third? Learn the secret of "zero-based indexing" to pinpoint and retrieve any element from your array with precision.
- **New Concept(s):** Bracket notation (`array[0]`), zero-based indexing, `.length` property.
- **Builds On:** Arrays.

**Item 5.3: Changing Your List: Adding & Removing Items**

- **Narrative Hook:** Your lists are not set in stone. They need to grow and shrink. Let's learn the simplest ways to add a new item to the end of your list and remove the last one, making your data dynamic.
- **New Concept(s):** `.push()` method, `.pop()` method.
- **Builds On:** Arrays, accessing elements.

**Item 5.4: Groundhog Day: The Classic `for` Loop**

- **Narrative Hook:** Imagine you need to print "Hello!" five times. Copying and pasting is not the programmer's way. Let's learn about the classic `for` loop, a powerful machine for running a block of code a specific number of times.
- **New Concept(s):** `for` loop syntax (initializer, condition, incrementer).
- **Builds On:** `let`, comparison operators.

**Item 5.5: The Assembly Line: Looping Through an Array**

- **Narrative Hook:** This is the moment it all comes together. We have a list (Array) and a repetition machine (Loop). Let's combine them to build an "assembly line" that processes every single item in an array, one by one. This is one of the most common tasks in all of programming.
- **New Concept(s):** Using a `for` loop with `array.length` to iterate through an array.
- **Builds On:** Arrays, `for` loops.

**Item 5.6: The Modern Way: A Simpler Loop with `for...of`**

- **Narrative Hook:** The classic `for` loop is powerful, but for the simple task of getting each item from a list, there's a much cleaner, more modern way. Let's learn the `for...of` loop to make your code more readable.
- **New Concept(s):** `for...of` loop syntax.
- **Builds On:** Arrays, understanding the concept of looping.

**Item 5.7: `code` - Milestone: Find the Biggest Number**

- **Narrative Hook:** You've learned how to store and process lists. Now, put that knowledge to the test. Write a function that takes an array of numbers and loops through it to find and return the single largest number in the list.
- **New Concept(s):** _Synthesis of all module concepts._
- **Builds On:** All previous items in Module 5, Functions.
