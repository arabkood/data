### **Module 7: Bringing Pages to Life: The Document Object Model (DOM)**

**Module Theme:** This module is the bridge between the invisible world of JavaScript data and the visible world of a web page. The user will learn how to take control of the HTML document, finding elements, changing their content and style, and, most importantly, reacting to user actions like clicks. This is where their code becomes truly interactive.

---

**Item 7.1: The Page as an Object: What is the DOM?**

- **Narrative Hook:** Every web page you see can be understood by JavaScript as a giant, structured object called the Document Object Model, or DOM. Let's learn how to access this special `document` object, which is our gateway to controlling everything on the page.
- **New Concept(s):** The concept of the DOM, the global `document` object.
- **Builds On:** HTML (from Module 1), Objects.

**Item 7.2: Finding Your Target: Selecting Elements**

- **Narrative Hook:** Before you can change an element, you need to find it. Let's learn the programmer's tools for selecting any HTML element on the page, whether by its unique ID or by using CSS-style selectors.
- **New Concept(s):** `document.getElementById()`, `document.querySelector()`.
- **Builds On:** The `document` object.

**Item 7.3: Changing the Message: Manipulating Text and HTML**

- **Narrative Hook:** You've selected an element. Now for the fun part. Learn how to read and, more importantly, change the text inside that element, providing instant visual feedback to your user.
- **New Concept(s):** `.textContent`, `.innerHTML` (and a note on its security implications).
- **Builds On:** Element selection.

**Item 7.4: A Splash of Color: Changing Element Styles**

- **Narrative Hook:** Changing text is one thing, but what about changing the look and feel? Let's tap into the element's `style` object to dynamically change colors, sizes, and visibility, directly connecting our JavaScript logic to CSS.
- **New Concept(s):** The `.style` property, converting CSS properties to `camelCase` (e.g., `backgroundColor`).
- **Builds On:** Element selection.

**Item 7.5: The Magic Moment: Listening for User Clicks**

- **Narrative Hook:** This is the key to interactivity. Instead of running code immediately, let's make it wait for the user to do something. We'll attach an "event listener" to a button that executes a function only when the user clicks it.
- **New Concept(s):** `addEventListener()`, the `'click'` event, the concept of a Callback Function.
- **Builds On:** Element selection, Functions.

**Item 7.6: Reading the User's Mind: Getting Value from Inputs**

- **Narrative Hook:** Interaction is a two-way street. We can show things to the user, but how can they give us information? Let's learn how to read the text that a user types into an input field, opening the door to forms and user-driven apps.
- **New Concept(s):** The `.value` property of input elements.
- **Builds On:** Element selection, Events.

**Item 7.7: `code` - Milestone: The Simple Counter**

- **Narrative Hook:** You've learned how to find, change, and listen to elements. Now, build a classic web utility: a counter. The page will have a number displayed and two buttons, "Increment" and "Decrement". Your job is to write the JavaScript that makes them work.
- **New Concept(s):** _Synthesis of all module concepts._
- **Builds On:** All previous items in Module 7.
