```markdown
# تحدي: باب المغامرة الذكي

حان الوقت لتطبيق كل ما تعلمته عن اتخاذ القرارات في تحدٍ ممتع! ستقوم ببناء لعبة مغامرات نصية بسيطة جداً حيث يعتمد مصير اللاعب على اختياراته.

## الهدف

كتابة برنامج يأخذ اللاعب في رحلة قصيرة بناءً على قراراته. البرنامج سيطرح أسئلة، وبناءً على إجابات اللاعب، سيحدد النتيجة النهائية.

## متطلبات البرنامج

يجب على برنامجك اتباع التسلسل المنطقي التالي بدقة:

1.  **السؤال الأول:** ابدأ بسؤال اللاعب عن الباب الذي يختاره. يجب أن يكون النص الدقيق للسؤال هو:
    ```
    أمامك بابان، باب أحمر وباب أزرق. أي واحد تختار؟ (أحمر/أزرق)
    ```

2.  **مسار الباب الأحمر:** إذا اختار اللاعب `"أحمر"`:
    *   يجب أن تسأله عن كمية الذهب التي يمتلكها. النص الدقيق للسؤال هو:
        ```
        كم لديك من الذهب؟
        ```
    *   إذا كان لديه 50 قطعة ذهب أو أكثر, اطبع الرسالة التالية:
        ```
        لقد قمت برشوة الحارس ومررت بأمان!
        ```
    *   إذا كان لديه أقل من 50 قطعة ذهب، اطبع الرسالة التالية:
        ```
        الحارس يضحك منك ويلقيك في الزنزانة.
        ```

3.  **مسار الباب الأزرق:** إذا اختار اللاعب `"أزرق"`:
    *   يجب أن تسأله عن اليوم من أيام الأسبوع. النص الدقيق للسؤال هو:
        ```
        ما هو اليوم من أيام الأسبوع؟
        ```
    *   إذا كانت الإجابة هي `"الثلاثاء"`, اطبع الرسالة التالية:
        ```
        الباب السحري يفتح لك!
        ```
    *   لأي يوم آخر، اطبع الرسالة التالية:
        ```
        الباب يبقى مغلقاً بإحكام.
        ```

4.  **الاختيار غير الصالح:** إذا كانت إجابة اللاعب على السؤال الأول ليست `"أحمر"` ولا `"أزرق"`, اطبع الرسالة التالية:
    ```
    لقد ترددت طويلاً وتحولت إلى حجر.
    ```

## نصائح

*   ستحتاج إلى استخدام عدة جمل `if` منفصلة للتعامل مع كل حالة رئيسية (الباب الأحمر، الباب الأزرق، الاختيار الخاطئ).
*   داخل بعض هذه الجمل، ستحتاج إلى استخدام `if` مرة أخرى (جمل `if` متداخلة) لاتخاذ قرار ثانٍ.
*   لتحقيق سلوك مشابه لـ `else`، يمكنك استخدام جملة `if` أخرى مع شرط معاكس. على سبيل المثال، بعد التحقق من `gold >= 50`، يمكنك استخدام جملة `if` أخرى للتحقق من `gold < 50`.
*   تذكر استخدام `input()` و `int()`.
*   انتبه جيداً لنصوص المخرجات والمطالبات، يجب أن تكون متطابقة تمامًا مع ما هو مطلوب أعلاه لتنجح في الاختبارات.

بالتوفيق أيها المغامر!
```

### solution.py

```python
# تحدي: باب المغامرة الذكي
# اكتب الكود الخاص بك هنا باستخدام جمل if فقط

# الخطوة 1: اسأل المستخدم عن اختياره للباب
door_choice = input("أمامك بابان، باب أحمر وباب أزرق. أي واحد تختار؟ (أحمر/أزرق)")

# الخطوة 2: مسار الباب الأحمر
if door_choice == "أحمر":
    gold_amount = int(input("كم لديك من الذهب؟"))
    if gold_amount >= 50:
        print("لقد قمت برشوة الحارس ومررت بأمان!")
    if gold_amount < 50:
        print("الحارس يضحك منك ويلقيك في الزنزانة.")

# الخطوة 3: مسار الباب الأزرق
if door_choice == "أزرق":
    day_of_week = input("ما هو اليوم من أيام الأسبوع؟")
    if day_of_week == "الثلاثاء":
        print("الباب السحري يفتح لك!")
    if day_of_week != "الثلاثاء":
        print("الباب يبقى مغلقاً بإحكام.")

# الخطوة 4: مسار الاختيار غير الصالح
if door_choice != "أحمر" and door_choice != "أزرق":
    print("لقد ترددت طويلاً وتحولت إلى حجر.")
```

```python
import unittest
import subprocess
import sys
import os

class TestAdventureDoor(unittest.TestCase):
    """Test suite for the Adventure Door Challenge."""

    @classmethod
    def setUpClass(cls):
        """Check if solution.py exists."""
        if not os.path.exists("solution.py"):
            raise FileNotFoundError("solution.py not found. Please create your solution file.")

    def run_script(self, inputs):
        """Run the solution with a list of inputs and return the output."""
        input_data = "\n".join(map(str, inputs))
        try:
            result = subprocess.run(
                [sys.executable, "solution.py"],
                input=input_data,
                capture_output=True,
                text=True,
                timeout=5,
                encoding="utf-8",
            )
            if result.returncode != 0:
                self.fail(f"Program crashed with error:\n{result.stderr}")
            return result.stdout.strip()
        except subprocess.TimeoutExpired:
            self.fail("Program took too long to run (possible infinite loop).")

    def test_red_door_success(self):
        """Test: Red door with enough gold."""
        output = self.run_script(["أحمر", "100"])
        self.assertIn("لقد قمت برشوة الحارس ومررت بأمان!", output, 
                      "Failed on Red Door with enough gold. Check your logic and output message.")

    def test_red_door_fail(self):
        """Test: Red door with insufficient gold."""
        output = self.run_script(["أحمر", "10"])
        self.assertIn("الحارس يضحك منك ويلقيك في الزنزانة.", output,
                      "Failed on Red Door with insufficient gold. Check your logic and output message.")

    def test_red_door_exact_gold(self):
        """Test: Red door with exactly 50 gold."""
        output = self.run_script(["أحمر", "50"])
        self.assertIn("لقد قمت برشوة الحارس ومررت بأمان!", output,
                      "Failed on Red Door with exactly 50 gold. Remember the condition is >= 50.")

    def test_blue_door_success(self):
        """Test: Blue door on the correct day."""
        output = self.run_script(["أزرق", "الثلاثاء"])
        self.assertIn("الباب السحري يفتح لك!", output,
                      "Failed on Blue Door on Tuesday. Check your logic and output message.")

    def test_blue_door_fail(self):
        """Test: Blue door on the wrong day."""
        output = self.run_script(["أزرق", "الأحد"])
        self.assertIn("الباب يبقى مغلقاً بإحكام.", output,
                      "Failed on Blue Door on a day other than Tuesday. Check your logic and output message.")

        """Test: Invalid door choice."""

        self.assertIn("لقد ترددت طويلاً وتحولت إلى حجر.", output,
                      "Failed on invalid door choice. Check your final if condition for the first choice.")

        self.assertIn("كم لديك من الذهب؟", output_red)

        # Test blue door prompts
        output_blue = self.run_script(["أزرق", "الاثنين"])
        self.assertIn("أمامك بابان، باب أحمر وباب أزرق. أي واحد تختار؟ (أحمر/أزرق)", output_blue)
```
