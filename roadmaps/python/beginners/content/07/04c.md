## Instructions.md

# تحدي مدير عربة التسوق 🛒

## الهدف

اكتب برنامجاً لإدارة عربة تسوق بسيطة. البرنامج يجب أن يسمح للمستخدم بإضافة المنتجات، إزالتها، عرض محتويات العربة، وحساب السعر الإجمالي.

## المطلوب منك

### 1. قائمة المنتجات المتاحة

```python
products = {
    "تفاح": 5.0,
    "موز": 3.0,
    "برتقال": 4.0,
    "خبز": 2.5,
    "حليب": 6.0,
    "جبن": 15.0,
    "بيض": 8.0,
    "أرز": 12.0
}
```

### 2. الوظائف المطلوبة

#### `display_products()`

- تطبع قائمة بجميع المنتجات المتاحة وأسعارها
- التنسيق: `"المنتج - السعر ريال"`

#### `add_to_cart(cart, products)`

- تطلب من المستخدم إدخال اسم المنتج
- تتحقق من وجود المنتج في قائمة المنتجات
- تضيف المنتج للعربة إذا كان متاحاً
- تطبع رسالة نجاح أو فشل

#### `remove_from_cart(cart)`

- تطلب من المستخدم إدخال اسم المنتج المراد إزالته
- تزيل المنتج من العربة إذا كان موجوداً
- تطبع رسالة نجاح أو فشل

#### `display_cart(cart, products)`

- تعرض محتويات العربة (أسماء المنتجات وأسعارها)
- إذا كانت العربة فارغة، تطبع "العربة فارغة"
- التنسيق: `"المنتج - السعر ريال"`

#### `calculate_total(cart, products)`

- تحسب السعر الإجمالي لجميع المنتجات في العربة
- ترجع القيمة الإجمالية

### 3. البرنامج الرئيسي

اكتب برنامجاً رئيسياً يعرض قائمة خيارات للمستخدم:

```
=== مدير عربة التسوق ===
1. عرض المنتجات المتاحة
2. إضافة منتج للعربة
3. إزالة منتج من العربة  
4. عرض العربة
5. حساب الإجمالي
6. خروج
```

## ملاحظات مهمة

- استخدم قائمة `cart = []` لتخزين أسماء المنتجات في العربة
- تأكد من التعامل مع الحالات الخاصة (عربة فارغة، منتج غير موجود)
- استخدم حلقة `while True` للقائمة الرئيسية مع `break` للخروج

## إذا كنت عالقاً، إليك بعض النصائح

### 1. هيكل الدوال الأساسية

#### `display_products()`

```python
def display_products():
    print("المنتجات المتاحة:")
    for product, price in products.items():
        print(f"{product} - {price} ريال")
```

#### `add_to_cart()` - الهيكل الأساسي

```python
def add_to_cart(cart, products):
    product_name = input("أدخل اسم المنتج: ")
    if product_name in products:
        cart.append(product_name)
        print(f"تم إضافة {product_name} للعربة بنجاح!")
    else:
        print("هذا المنتج غير متاح")
```

### 2. التعامل مع القوائم

__إضافة عنصر للقائمة:__

```python
cart.append(product_name)
```

__إزالة عنصر من القائمة:__

```python
if product_name in cart:
    cart.remove(product_name)
```

__التحقق من وجود عنصر:__

```python
if product_name in products:
    # المنتج موجود
```

### 3. حساب الإجمالي

```python
def calculate_total(cart, products):
    total = 0
    for item in cart:
        total += products[item]
    return total
```

### 4. القائمة الرئيسية

```python
def main():
    cart = []
    
    while True:
        # طباعة القائمة
        choice = input("اختر رقماً (1-6): ")
        
        if choice == "1":
            display_products()
        elif choice == "2":
            add_to_cart(cart, products)
        # ... باقي الخيارات
        elif choice == "6":
            print("شكراً لاستخدام مدير عربة التسوق!")
            break
```

### 5. نصائح مهمة

- __استخدم `products.items()`__ للتنقل عبر المنتجات وأسعارها
- __تحقق دائماً من وجود المنتج__ قبل إضافته أو إزالته  
- __استخدم `len(cart)`__ للتحقق من العربة الفارغة
- __لا تنسَ `break`__ للخروج من حلقة `while True`

### 6. رسائل الخطأ الشائعة

__إذا واجهت "KeyError":__

- تحقق من وجود المنتج في القاموس قبل الوصول لسعره

__إذا واجهت "ValueError" في `remove()`:__

- تحقق من وجود المنتج في العربة قبل إزالته

__إذا كانت الحلقة لا تتوقف:__

- تأكد من وجود `break` في خيار الخروج
