# مدير جهات الاتصال

## المطلوب

اكتب برنامج لإدارة جهات الاتصال باستخدام القواميس.

### الخطوات:

1. أنشئ قاموس فارغ اسمه `contacts`
2. اطلب من المستخدم إدخال اسم جهة الاتصال
3. اطلب من المستخدم إدخال رقم الهاتف
4. أضف جهة الاتصال للقاموس (الاسم كمفتاح، الرقم كقيمة)
5. كرر الخطوات 2-4 لإضافة جهة اتصال ثانية
6. اطبع عدد جهات الاتصال باستخدام `len()`
7. اطبع جميع جهات الاتصال (الاسم والرقم) باستخدام حلقة

### مثال على المخرجات:

```
أدخل اسم جهة الاتصال: أحمد
أدخل رقم الهاتف: 0551234567
أدخل اسم جهة الاتصال: سارة
أدخل رقم الهاتف: 0559876543
عدد جهات الاتصال: 2
أحمد: 0551234567
سارة: 0559876543
```

### ملاحظات:
- استخدم `input()` للحصول على البيانات
- استخدم حلقة `for` مع `.items()` لطباعة جهات الاتصال
