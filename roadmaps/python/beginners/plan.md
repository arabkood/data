## MODULE 1: First Steps in Python

   1. Writing Code
      description: A straight to coding lesson introduction, it will teach only one line of code print("text") and print(number). It will be focused on practice with very little theory and explanation.
      goal: Motivate the user, introduce data types, introduce debug tool (print) early
      concepts: "print", "()", "string", "number"

   2. Memory & Variables
      description: Explain variables and why do we even need them, keep the explanation very little and practice driven learning more, start with analogy and a media showing it but stop there and continue with real practical explanation. Like always 90% should be practice, and learn through practice.
      goal: Introduce the simplest form of variables in python in theory and practice and syntax.
      concepts: "variable name", "variable assignment", "variable value", "string", "number"
      takeaways: Computer programs use variables to remember important information, A variable has a name and a value, You can create a variable by connecting the name and the value with an equal sign =

   3. Strings in python
      description: Explain & practice strings deeper than the lessons before, connect it with variables, teach about single and double quotanions, create as many variables as you like, start teach about statements, remind about print
      takeaways: A piece of text is called a string, Strings require quotation marks, The print() statement is used to send a value to the screen.

   4. Numbers in python
      description: teach about numbers data types similar to lesson before, include previous lesson also in practice, include some practice about print again, introduce simple math operations and math symbols, printing variable through his name.
      takeaways: Numerical values can be stored in variables, You can access the value stored in a variable by calling its name, Numerical data should not be surrounded by quotation marks.

   5. Practice Game (Code runner)
      description: A very simple unit tested challenge using everything we learned so far, use a fun real example.

   6. Working with Variables
      description: more very simple theory info on variables and how to work on it, but majority is practice, such as using variables in print to multiply them, variety of code he see is key, show and practice updating variables data, practice the order of code.
      takeaways: You can run calculations using the values stored in variables, You can store the result of a calculation in a variable, You can update the value of a variable.

   7. Last Review
      description: Gather the trickiest questions from last lessons into one, and include some new common mistakes, to help user spot them.

## MODULE 2: Let's Go Deeper


   1. Advanced Print Techniques
      description: Expand familiar print() function through practice. Learn multiple arguments, create formatted output, combine with variables from previous lessons. Practice-driven with real examples.
      goal: Master print() functionality for better program output
      concepts: "multiple arguments", "print formatting", "output control"
      takeaways: print() can display multiple values at once, You can combine text and variables in print(), Commas separate multiple items in print()

   2. String Operations
      description: Build on existing string knowledge with hands-on manipulation. Practice string concatenation, repetition, and combining with variables. Connect to real-world applications through examples.
      goal: Combine and manipulate strings effectively in practical scenarios
      concepts: "string concatenation", "string repetition", "string operators", "+"
      takeaways: Strings can be joined together using +, Strings can be repeated using *, You can combine variables and text to create dynamic messages

   3. Practice Game (String Master)
      description: A fun multi step lesson with mostly practice about everything learned so far Real-world scenario combining all concepts learned so far.

   4. Comments & Code Documentation
      description: We've been using comments in our examples before, but now we'll introduce what they are to the user. Learn single-line comments, when to use them, and how they help. Practice commenting existing code from previous lessons. Also introduce multi-line comments quickly (not in depth).
      goal: Understand why and how to comment.
      concepts: "comments", "#", "code documentation", "readability"
      takeaways: Comments explain what code does, Comments start with #, Comments make code easier to understand later

   7. Last Review
      description: Gather the trickiest questions from the first module (first steps) and (let's dig deeper) into one, and include some new common mistakes with print, variables, statements, strings, and comments to help user spot them.

   8. Module Challenge
      description: A code runner challenge, where we give the user a code (related to what they learned so far) full of bugs including indentation errors, missing comments, and string operation mistakes, and they have to fix it to pass.

   9. A helpful shortcut for strings

## Let's Go Even Deeper

   1. Python Statements & Expressions
      description: Let users see the code as it really is, give them the engineer glasses. Show difference between commands and expressions using familiar examples. Show them visuals a lot. Ask them to tell which are statements vs expressions. Ask them for the meaning and more practice statement execution order building on lesson 6's foundation. 90% practice with minimal theory.
      goal: Help users distinguish between doing something vs evaluating something through hands-on experience
      concepts: "statement", "expression", "execution order", "evaluation"
      takeaways: Statements do something, expressions evaluate to something, Code runs line by line from top to bottom


   3. Python Syntax & Indentation
      description: Essential foundation through visual examples and immediate practice. Show hierarchy with images, practice fixing indentation errors, connect to variables and print statements. Very little theory, maximum hands-on practice.
      goal: Master Python's indentation structure through practical application
      concepts: "indentation", "code blocks", "syntax rules", "whitespace"
      takeaways: Python uses indentation to organize code, Proper indentation is required for code to work, Consistent spacing creates readable code

- **Separator control:** `print("A", "B", "C", sep="-")`
- **Basic string methods:** `.upper()`, `.lower()`, `.strip()`
